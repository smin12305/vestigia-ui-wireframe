## 레거시 버전

- 결과 중심 UI 개편 전 버전은 `도구/레거시/전투 프로토타입_2026-08-16_적위협UI_v1`에 보존한다.

쿼리도 슈팅의 전투 개편 규칙과 핵심 전투 루프를 검증하는 `6×6` 브라우저 프로토타입입니다.

이 게임은 캐릭터를 하나씩 즉시 움직이는 일반적인 전술 게임이 아닙니다. 한 턴의 행동 순서·이동 경로·공격 또는 스킬을 먼저 설계하고, 현재 → 미래 → 과거로 자동 순환하는 시간 효과를 읽은 뒤 잠긴 계획을 빠르게 실행하는 **턴 설계형 난투 게임**입니다.

## 실행

`전투 프로토타입 실행.bat`을 더블클릭합니다. `index.html`을 직접 열면 모듈이 실행되지 않아 빈 화면이 나타납니다.

다른 사람에게 전달할 때는 `standalone/index.html` 단일 파일을 사용합니다. 이 파일은 코드·스타일·캐릭터 이미지를 모두 포함하므로 Node.js 설치나 서버 실행 없이 더블클릭만으로 오프라인 플레이할 수 있습니다. 개발 원본의 루트 `index.html`과 혼동하지 않도록 배포판은 `standalone` 폴더에 생성합니다.

Windows 환경에서 단일 HTML 호환성 문제가 있거나 가장 안정적인 전달본이 필요하면 `portable` 폴더 전체를 전달합니다. 받은 사람은 폴더 구조를 유지한 채 압축을 풀고 루트의 `index.html`을 더블클릭합니다. `assets` 폴더의 이름이나 위치를 바꾸면 안 됩니다. 이 배포판은 배치 파일·명령 프롬프트·Node.js를 사용하지 않습니다.

단일 파일 배포판을 새로 생성하려면 다음 명령을 실행합니다.

```powershell
npm run build:standalone
```

안정형 폴더 배포판은 다음 명령으로 생성합니다.

```powershell
npm run build:portable
```

터미널에서는 다음처럼 실행할 수 있습니다.

```powershell
npm install
npm run dev -- --host 127.0.0.1 --port 5174
```

## 한 턴의 흐름

1. 적군은 기존 중립 구역을 포함한 위쪽 빨간 6행, 아군은 아래쪽 파란 3행에 초기 배치합니다.
2. 전투 시작 시 동전 던지기로 첫 선공 진영을 정합니다.
3. 선공 진영부터 아군·적군 행동 슬롯이 교차로 생성됩니다.
4. 행동 슬롯을 선택하고 캐릭터 순서, 이동 경로, 일반 공격 또는 스킬을 설계합니다.
5. 적군 슬롯은 간단한 AI가 현재 전투판을 기준으로 자동 계획하며, 이동 경로·타겟·스킬을 플레이어에게 공개합니다.
6. 이번 턴의 시간대를 선택합니다.
7. `시간대 잠금 · 계획 실행`을 누르면 모든 행동이 번호 순서로 빠르게 실행됩니다.
8. 행동 전에 밀치기·당기기로 좌표가 바뀌면, 바뀐 위치를 새 시작점으로 삼아 그려둔 경로의 방향과 모양을 그대로 재생합니다.
9. 이동한 경로가 전투판 밖으로 나가거나 다음 셀이 점유되어 있으면 중단하고, 해당 캐릭터의 후속 공격·스킬은 취소됩니다.
10. 모든 행동 후 선공 진영을 교대하고 다음 턴을 설계합니다.

## 구현된 전투 규칙

- 상하좌우 마우스 경로, 대각선 이동 불가
- 행동 순서 `이동 → 일반 공격/스킬`
- 대상·셀·설치 방식은 거리 제한 없이 먼저 지정하며, 공격·스킬의 실제 시전 사거리는 계획한 이동 경로의 마지막 셀을 기준으로 표시·판정
- 지정점 연결선은 시전 가능 시 파란 실선, 사거리 밖이면 주황 점선으로 표시하고 경로 변경에 따라 융합/파괴 연출로 전환
- 계획이 입력된 연결선은 다른 캐릭터를 선택해도 유지하며, 현재 선택한 행동의 선만 선명하게 강조
- 범위 내 캐릭터 대상형과 상하좌우 방향형 공격
- 밀치기·당기기의 셀 단위 강제 이동과 점유 충돌
- 행동 전 강제 이동 시 계획 경로의 방향 배열을 현재 좌표에서 재생하며, 실행 대기 경로도 강제 이동한 만큼 평행 이동해 표시
- 이동 경로 마지막 셀에는 전용 SD 홀로그램을 표시한다. 아군은 파란색, 적군은 빨간색 반투명 잔상이며 같은 도착 셀을 선택한 캐릭터는 조금씩 어긋나게 겹쳐 표시한다.
- 도착지 SD 홀로그램은 실제 캐릭터와 같은 클릭 대상으로 취급한다. 타겟형 공격·스킬을 선택한 상태에서 홀로그램을 누르면 해당 캐릭터가 타겟으로 연결된다.
- 적군 AI의 이동·일반 공격·스킬 후보 점수 계산, 도착 셀 예약, 상위 3개 후보 가중 선택
- 시간 파편은 `0/50`에서 시작하며 아군의 유효 공격 `+20`, 상태 콤보 추가 `+30`, 턴 경과 `+10`으로 충전
- 파편 획득 시 전투판에 떨어진 파편이 왼쪽 회중시계로 흡수되는 수집 연출 표시
- 시간은 현재 → 미래 → 과거 순서로 각 2턴씩 자동 순환합니다.
- 시간 파편이 가득 차면 다음 턴 종료의 시간 진행을 한 번 억제할 수 있습니다. 연속 억제 시 내부 필요량과 최대 시간 파편이 5씩 증가하고, 쉬는 턴에는 5씩 감소하며 최소치는 50입니다. 억제된 추가 턴은 같은 시간대의 연속 체류로 계산합니다.
- 적군 AI 슬롯 잠금과 계획 공개, 테스트용 `다시 계획` 버튼 및 선택 이유 로그
- 적 머리 위 `행동 번호 · 행동명`, 대상 옆 예상 피해·상태·강제이동 결과 칩, 우측 `적 위협` 카드로 적 행동과 결과를 한 화면에 표시
- 적 위협 카드는 현재 턴을 행동 순서대로 모의 실행해 선행 이동·피해·기절·강제이동을 반영하며, 클릭하면 해당 적 계획만 강조
- 계획 단계 기본 보기는 `턴 종료 예상`이며 적 이동 발자국·스킬 공격과 함께 아군별 `현재 HP → 예상 HP`, 상태이상, 강제이동, 공격자 행동 번호를 합산 표시
- 상단 행동 순서의 `턴 결과`를 누르면 결과 요약, 아군 행동을 누르면 계획 편집, 적 행동을 누르면 시전자→행동→대상→결과 상세 화면으로 전환
- 기본 화면에서는 아군 계획만 숨기고 적 이동·스킬은 유지한다. `모든 계획`은 양 진영 계획을 함께 보는 검증용 보기이며 공격선 위 긴 설명은 제거하고 범위 밖 취소만 직접 표시한다.
- 아군 캐릭터를 선택해 이동 경로·공격·스킬을 편집하는 동안에도 모든 적의 예상 이동, 스킬 범위, 목표 결과 칩과 다른 아군의 계획은 사라지지 않는다. 선택한 아군 계획만 선명하게, 나머지 아군 계획은 흐리게 겹쳐 표시한다.
- 캐릭터 선택 정보에는 기본공격과 스킬의 타겟 방식, 사거리, 범위 패턴, 스킬 쿨타임을 함께 표시한다.
- 오른쪽 보조 영역의 `전투 도움말`에서 스킬 정보·기본 파라미터·시간 활용·기본 전투법을 버튼으로 열어볼 수 있다. 긴 설명은 선택했을 때만 펼쳐 전투판을 가리지 않는다.
- 대상형 공격을 계획한 적을 클릭하면 적의 예상 시전 위치를 중심으로 `마름모/사각형/직선` 사거리 셀을 붉게 표시한다.
- 대상 캐릭터가 공격자보다 먼저 행동하면 연결선은 대상의 계획 경로 종점을 따라간다. 종점이 사거리 밖으로 나가는 순간 주황 점선과 `취소 · 범위 밖`으로 전환하고 연결 파괴 연출을 표시한다.
- 대상 캐릭터가 공격자보다 나중에 행동하면 해당 공격 시점에는 아직 이동 전이므로 연결선은 현재 위치를 사용한다.
- 띄워짐 대상에 대한 일반 공격 치명타
- 기절한 캐릭터의 현재 턴 행동 슬롯 패스
- 피해·치명타·상태이상·면역 결과를 대상 위에 떠오르는 글씨로 표시
- 공격 실행은 `실제 시전 위치에서 공격/스킬 범위 순간 표시 → 행동명과 간단한 휘두르기·적중 섬광 → 피해 및 상태 결과 적용` 순서로 재생한다. 계획 단계의 예상 범위와 구분되도록 실행 중에만 선명하게 짧게 표시한다.
- 방향형 행동의 공격선과 강제이동 결과를 분리 표시: 공격은 진영색 `공격` 선, 밀치기는 노란 굵은 화살표, 당기기는 보라 점선·꺾쇠
- 강제이동 도착 셀에는 대상 잔상과 `이동/요청 거리`를 표시하고, 점유·전투판 경계로 덜 이동하면 `충돌` 및 `✕`, 면역이면 `면역` 표시
- 대상형 연결선은 아군 계획이면 파란색, 적 AI 계획이면 빨간색과 `적 공격 대상` 라벨로 표시하며, 범위 밖은 양쪽 모두 주황 점선으로 표시
- 대상형 연결선은 계획 실행 중에도 유지한다. 현재 행동은 실제 이동 위치에서 목표까지 선명하게, 대기 행동은 흐리게 표시하고 완료·취소된 행동은 제거한다.
- 띄워짐·기절이 유지되는 동안 캐릭터 오른쪽 위에 상태 이름을 계속 표시

## 캐릭터 문법

콘텐츠 작업실에서는 진영·타입·AI 유형·공격 방식·상태 면역을 선택식으로 편집할 수 있습니다. `연결 스킬`도 현재 저장된 스킬 목록에서 고르면 되며, 선택 결과는 아래의 문법 원문에 자동 반영됩니다. 이름이나 수치처럼 자유 입력이 필요한 항목만 원문에서 직접 수정합니다.

```text
캐릭터: 여명검 라온
ID: raon
진영: 아군
타입: 계승자
AI유형: 공통형
최대체력: 34
공격력: 4
이동력: 4
치명타피해율: 150
일반공격: 검격
공격방식: 대상
공격사거리: 1
공격범위패턴: 마름모_1
스킬: shield_crash
색상: #55c7e8
상태면역: 없음
```

- 진영: `아군`, `적군`
- 타입: `계승자`, `각성자`, `기술자`
- AI유형: `공통형`, `돌격형`, `방벽형`, `저격형`. 아군은 현재 이 값을 사용하지 않습니다.
- 공격방식: `대상`, `방향`
- 공격범위패턴: `마름모_N`, `사각형_N`, `직선_N`. `사각형_1`은 자기중심 3×3 범위입니다.
- 상태면역: `없음` 또는 `밀치기, 당기기, 띄우기, 기절`
- 스킬에는 연결할 스킬의 `ID`를 적습니다.

기본 적군 편성은 `신성 창병(돌격형)`, `신성 방패병(방벽형)`, `철탑 방위병(저격형)`입니다. 세 캐릭터 모두 상태 면역은 없습니다. 기본공격은 공격력·방식·사거리·범위 패턴만 사용하며 밀치기나 치명타 제한 같은 부가 설정은 스킬에만 작성합니다.

## 스킬 문법

방식·치명타·범위 패턴·영향 셀 패턴·효과 종류·적용 범위·대상 진영은 선택식입니다. 설치 환경 ID만 직접 입력하며, 효과마다 적용 범위와 대상 진영을 따로 지정할 수 있습니다.

```text
스킬: 방패 충각
ID: shield_crash
설명: 직선의 대상을 타격하고 뒤로 밀어냅니다.
방식: 방향
사거리: 2
범위패턴: 직선_2
영향셀패턴: 직선_2
쿨타임: 2
치명타: 불가
효과: 피해 | 적용: 영향셀 | 대상: 적군 | 수치: 3
효과: 밀치기 | 적용: 영향셀 | 대상: 모두 | 거리: 2
```

- 방식: `대상`, `셀`, `설치`, `방향`
- 적용: `선택대상`, `선택셀`, `영향셀`, `자신`
- 각 효과의 대상: `아군`, `적군`, `모두`
- 치명타: `가능`, `불가`
- 효과: `피해`, `밀치기`, `당기기`, `띄우기`, `기절`, `설치`
- `영향셀` 효과는 영향 셀 패턴이 필요하며, 설치 효과에는 환경 요소 ID가 필요합니다.
- 효과는 위에서 아래 순서로 처리되며 여러 줄을 조합할 수 있습니다.
- 밀치기·당기기를 포함한 스킬은 `방식: 방향`이어야 합니다.
- 밀치기·당기기의 대상 진영은 항상 `모두`로 정규화됩니다. 영향 범위 안의 적군과 아군 모두 강제이동하지만, 같은 진영 캐릭터는 해당 스킬의 피해 효과를 받지 않습니다.

## 유물 문법과 장착

초기 배치 화면에서 아군 캐릭터를 선택한 뒤 해당 캐릭터의 유물을 최대 3개 장착합니다. 효과는 장착자 자신에게만 적용됩니다. 아래 보유 유물 목록을 누르면 첫 번째 빈칸에 추가되고, 장착칸을 누르면 해제됩니다. 하나의 유물은 한 캐릭터만 장착할 수 있습니다.

```text
유물: 맥동하는 심핵
ID: beating_heart_core
등급: 일반
설명: 장착자의 최대체력을 높입니다.
효과: 최대체력 +10
```

- 등급: `일반`, `희귀`, `전설`
- 효과 능력치: `최대체력`, `공격력`, `이동력`, `치명타피해율`
- 치명타 피해율 보정은 모두 `%p`로 합산합니다. `150% +30%p = 180%`입니다.
- 계산 도중 소수점이 발생하면 최종 결과에서 반올림해 정수로 적용합니다.
- 효과 줄은 여러 개 조합할 수 있고 음수 보정도 허용합니다.
- 장착한 유물 효과는 장착자 자신에게만 합산되며 캐릭터 원본 문법은 변경하지 않습니다.
- 자세한 작성 규칙은 `유물_문법.md`에 정리합니다.
