# 전투 프로토타입 UI 정리 문서

## 2026-08-21 모바일 전투 UI·조작 개편 종합

### 화면 구성과 표시 품질

- 기준 화면을 1920×1080 가로형 16:9로 두고, 9×9 쿼터뷰 전투판을 화면 중심의 핵심 영역으로 재배치했다.
- 전투판을 계획 단계 1.5배, 실행 단계 1.56배로 확대하되 상단 행동 순서, 좌측 시간 시계·캐릭터 카드와 우측 행동 버튼 크기는 유지했다.
- 내부 캔버스를 1920×1360으로 높이고 표시 비율을 `960:680`으로 고정해 SD의 화질 저하와 세로 눌림을 해결했다.
- 캐릭터 SD, 발판, 그림자, 체력바, 도착 홀로그램과 타일 입력 좌표를 같은 셀 중심에 맞췄다. 타일 원점 오류로 우측 하단 한 칸만큼 어긋나 보이던 문제도 수정했다.
- 좌측 하단 캐릭터 카드 전체를 눌러 상세 정보를 열고 닫을 수 있다. 기본 공격·스킬의 지정 방식, 사거리, 범위 패턴, 설명, 치명타 가능 여부와 쿨타임을 함께 표시한다.

### 이동 경로와 선택 조작

- 이동 경로의 시작점·중간 셀·도착 셀 또는 도착지 홀로그램을 잡으면 선택 지점 이전 경로는 유지하고 그 이후만 다시 그릴 수 있다.
- 선택한 캐릭터 본체를 다시 누르면 이동 발자국, 경로선과 도착 홀로그램을 시작 위치로 초기화한다. 공격·스킬 계획은 유지하고 새 위치에서 사거리를 다시 계산한다.
- 빈 타일을 누르면 캐릭터 선택이 풀리고 카드가 안내 상태로 바뀌며 행동 버튼이 비활성화된다. 기존 계획은 전체 계획용 흐린 표시로 남는다.
- 이동 표시는 경로 타일마다 왼발·오른발 한 쌍을 번갈아 새긴 형태로 통일했다. 직진은 진행 방향, 꺾임은 회전 방향의 중간 각도인 45도를 향한다.
- 발자국은 타일에 각인된 것처럼 낮은 투명도와 얇은 테두리를 사용하며, 기본 크기를 약 14%, 선택 경로는 약 20% 키웠다. 선택한 계획에만 발자국 위로 경로선을 추가한다.
- 아군과 적군 도착지는 각각 파란색·빨간색 반투명 SD 홀로그램으로 표시하고, 홀로그램도 캐릭터 선택과 타겟 지정 입력을 받는다.

### 행동 계획 UI

- 우측 하단은 위쪽에 안내 문구와 `취소`·`확정`, 아래쪽에 `공격`·`스킬`을 배치하는 두 줄 구조로 정리했다.
- 공격·스킬은 첫 입력에서 대상·방향·셀을 미리 보고, `확정` 또는 같은 입력의 두 번째 탭으로 확정한다.
- `취소`는 편집 전 행동을 복원하지 않는다. 해당 캐릭터의 공격·스킬 지정과 확정 상태를 완전히 지우고 이동 후 대기로 바꾸며 이동 경로만 유지한다.
- 일부 아군만 행동을 설정해도 계획을 실행할 수 있다. 미설정 캐릭터는 현재 위치 또는 이동 도착지에서 대기하며 실행 버튼에 `설정 수/전체 수 · 미설정은 대기`를 표시한다.
- `계획 실행` 아래에 `계획 초기화`를 추가했다. 누르면 모든 아군의 이동·공격·스킬 계획만 초기화하며 적 AI 계획과 행동 순서는 보존한다.
- 계획 단계 전투판의 이동 번호, 예상 HP, 공격자 번호, 사거리 제목과 반복 안내 문구는 제거했다. 실제 시전 예정 위치 위에만 작은 `일반공격` 또는 `스킬 · 스킬명` 라벨을 표시한다.
- 타겟 실선·점선, 강제이동 화살표, 막힘 기호는 유지한다. 실행 중 피해·치명타·상태이상, 기절·띄워짐과 연결 융합·파괴 결과도 중요한 피드백이므로 유지한다.

### 적 계획과 범위 읽기

- 적 캐릭터를 누르면 해당 적의 이동 발자국, 도착 홀로그램, 공격 범위, 타겟 연결선과 예상 결과만 선명하게 남기는 단일 위협 집중 보기로 전환한다.
- 타겟형 적은 예상 시전 위치를 기준으로 전체 사거리 셀을 붉은 반투명 영역으로 보여준다. 방향형 강제이동 스킬은 공격 범위의 모든 셀에 실제 밀치기·당기기 방향 화살표를 표시한다.
- 타겟형 연결선의 끝은 대상 캐릭터의 계획된 이동 도착지를 따라간다. 이동 결과가 사거리 안이면 실선과 융합 연출, 밖이면 주황 점선과 연결 파괴 연출로 즉시 전환한다.
- 적 집중 보기 중 빈 타일을 누르면 캐릭터 선택을 해제하고 `모든 계획`으로 돌아간다. 이전 입력 모드보다 집중 보기 종료를 먼저 처리하며 기존 계획은 변경하지 않는다.
- 집중 보기를 종료하면 선택한 적 전용 사거리 셀을 즉시 제거하고 전투판 전체를 다시 그린다. 모든 적의 방향 범위와 연결선은 비교 가능한 낮은 투명도로 복원해 단독 집중 상태와 구분한다.
- 캐릭터가 선택되지 않은 전체 계획 상태에서도 턴 결과와 적 위협 정보가 정상적으로 다시 구성되도록 패널 표시 순서를 정리했다.

### 시간대 UI

- 왼쪽 시계를 누르면 과거·현재·미래 선택 창이 열린다. 시간대 카드를 처음 누르면 금색 테두리와 `한 번 더 눌러 변경` 안내가 나타난다.
- 같은 시간대를 두 번째로 누르면 예정 시간대가 확정되고 창이 닫힌다. 계획 중 시계와 전투판 색은 확정한 예정 시간대를 즉시 미리 보여준다.
- 시간 포인트 차감과 체류 턴 시작은 시간대를 고른 순간이 아니라 계획 실행 시 처리한다. 포인트가 부족한 시간대는 선택할 수 없다.
- X 버튼, 창 바깥, Esc 키 또는 시계 버튼으로 닫으면 첫 클릭 선택 상태도 취소한다.

### 실행 단계와 피드백

- 계획 실행이 시작되면 모든 예정 경로·홀로그램·공격선을 지우고 현재 행동자와 직접 관련된 이동, 공격 범위, 연결선과 피격 표시만 남긴다.
- 현재 행동 캐릭터와 상단 행동 카드만 선명하게 강조하며 행동이 끝나면 다음 행동자의 표시로 교체한다.
- 공격 직전 실제 시전 위치 기준 범위를 순간 점멸하고 휘두르기·적중 섬광 뒤 피해와 상태를 적용한다. 치명타일 때만 약한 카메라 흔들림을 사용한다.
- 계획 예고용 스킬명과 예상 결과 글씨는 축소해 캐릭터와 경로를 덜 가리게 하고, 실행 중 실제 피해·상태 결과 글씨 크기는 유지한다.
- 스킬 사용이 실패하면 성공 연출을 재생하지 않고 별도의 실패 이펙트를 표시해야 한다. 시전자 주변에 짧은 붉은 균열 또는 소멸 연출을 보여주고 `시전 실패`와 실패 원인을 작은 글씨로 함께 표시한다.
- 실패 원인은 최소한 `범위 밖`, `대상 소실`, `이동 경로 충돌`, `기절`, `시전자 전투불능`으로 구분한다. 타겟 연결선이 있으면 끊어지는 연출과 동시에 제거해 공격이 적용되지 않았음을 명확히 전달한다.
- 실패 이펙트가 끝난 뒤에는 피해·상태이상·시간 포인트 획득 같은 성공 결과를 표시하지 않고 다음 행동으로 넘어간다. 이 항목은 현재 미구현이며 후속 구현 및 플레이테스트 대상이다.

### 구현·검증 상태

- 설정과 일시정지 버튼은 위치와 외형만 구현되어 있으며 실제 메뉴와 일시정지 기능은 후속 구현 대상이다.
- 단일 HTML 배포판을 1920×1080 브라우저에서 반복 검증했다. 좌표·비율, 경로 부분 수정, 발자국, 공격·스킬 확정과 취소, 부분 계획 실행, 시간대 이중 확인, 적 집중 보기와 범위 복원, 실행 단계 현재 행동 표시를 확인했다.
- TypeScript 및 Vite 프로덕션 빌드를 통과했고 검증 중 런타임 오류는 발견되지 않았다.

## 2026-08-18 유물 UI 반영

- 초기 배치 오른쪽 패널에 유물 장착 3칸과 20종 보유 목록을 유지한다.
- 목록에는 자연어로 풀어 쓴 설명을 먼저 표시하고, 그 아래에 `시간대 · 발동 조건 · 효과 종류 · 수치` 규칙 요약을 함께 표시한다.
- 장착 슬롯에도 자연어 설명을 표시하며 마우스를 올리면 전체 설명과 규칙 요약을 확인할 수 있다.
- 콘텐츠 공방은 효과 종류, 발동, 시간대, 수치, 선택적 HP 조건을 선택식으로 제공한다.
- 계획 단계 캐릭터 정보는 선택한 시간대의 유물 보정 공격력·이동력·치명타 피해율을 표시한다.
- 적 위협 패널의 예상 피해는 선택 시간대와 장착 유물의 피해·받는 피해 보정을 포함한다.

## 단일 파일 배포 UI

- `standalone/index.html`은 개발 서버 UI와 같은 화면·조작을 제공한다.
- 코드·CSS·SD 이미지를 HTML 내부에 포함하며, 파일을 직접 열어도 빈 화면이 발생하지 않는다.
- 저장 데이터는 해당 브라우저의 로컬 저장소에 보관되므로 다른 컴퓨터로 HTML을 복사할 때 기존 저장 데이터까지 함께 이동하지는 않는다.
- 다른 PC 전달 시에는 `portable/index.html`과 `portable/assets`를 함께 유지하는 폴더 배포판을 우선한다. 배치 파일이나 로컬 서버 없이 일반 스크립트로 실행해 Windows 명령 프롬프트 인코딩 문제를 피한다.

## 공격 실행 피드백

- 행동 실행 순간에는 현재 시전 좌표를 기준으로 일반 공격 또는 스킬의 유효 범위를 선명하게 한 번 점멸한다.
- 일반 공격은 시전자 진영색, 스킬은 보라색으로 구분하고 시전자 위에 행동명을 짧게 표시한다.
- 범위 점멸과 휘두르기·적중 섬광이 먼저 나온 뒤 피해 글씨와 HP 변화를 적용해 원인과 결과를 순서대로 읽게 한다.
- 치명타 피해 글씨가 발생할 때만 전투판 카메라를 `105ms`, 강도 `0.0025`로 짧고 약하게 흔든다. 일반 피해와 상태이상에는 카메라 흔들림을 적용하지 않는다.
- 이 표시는 실행 중에만 나타나는 순간 연출이며 계획 단계의 지속 노출 범위와 겹쳐 정보 밀도를 높이지 않는다.

## 목적

누적된 기능을 모두 같은 강도로 노출하지 않고, 플레이어가 현재 해야 할 일과 전투 결과를 먼저 읽도록 화면 계층을 통일한다. 전투 규칙은 바꾸지 않으며 표시와 조작 구조만 정리한다.

## 화면 우선순위

1. 전투판의 현재 위치, 이동 경로, 공격 대상과 강제이동 결과
2. 행동 순서와 현재 계획·실행 슬롯
3. 선택 캐릭터와 행동 입력
4. 시간 파편과 시간대 선택
5. 전투 로그, 연출 속도, AI 재계획 같은 검증 도구

## 전체 화면 구조

- 상단 헤더: 게임명, 현재 단계·턴, 콘텐츠 공방만 표시한다.
- 행동 순서: 높이를 줄인 가로 슬롯으로 유지한다. 계획 중 선택 슬롯과 실행 중 현재 슬롯을 동시에 강조하지 않는다.
- 중앙: 전투판을 가장 큰 면적으로 유지하고 위에는 범례·표시 필터, 아래에는 현재 상태 한 줄만 둔다.
- 왼쪽: 시간 파편, 시간대 선택, 파편 획득 규칙, AI 재계획을 배치한다.
- 시간 포인트 바로 아래에는 `타겟형`, `방향형`, `셀형`, `설치형`의 지정 방식과 시전 시점 판정을 짧은 상시 범례로 표시한다.
- 오른쪽 계획 단계: 선택 캐릭터, 현재 계획 요약, 행동 입력, 실행 버튼, 로그 순서로 배치한다.
- 오른쪽 실행 단계: 편집 버튼을 숨기고 현재 행동 캐릭터·행동·결과와 로그만 표시한다.
- 콘텐츠 공방: 전투 화면과 분리된 모달을 유지한다.

## 캐릭터 선택 정보와 전투 도움말

- 왼쪽 공격 지정 방식 범례는 `타겟형: 캐릭터 지정 후 시전 순간 사거리 판정`, `방향형: 이동 후 위치에서 선택 방향으로 시전`, `셀형: 칸 지정 후 시전 순간 사거리 판정`, `설치형: 지정한 칸에 설치물 생성`으로 통일한다.
- 캐릭터 선택 카드에는 HP·공격·이동·치명타·타입뿐 아니라 기본공격과 스킬의 `타겟형/방향형/셀 지정형/설치형`, 사거리, 범위 패턴, 스킬 쿨타임을 표시한다.
- 오른쪽 패널의 보조 영역에는 `스킬 정보`, `기본 파라미터`, `시간 활용`, `기본 전투법` 버튼을 둔다.
- 스킬 정보는 현재 선택한 캐릭터를 기준으로 설명·방식·사거리·패턴·쿨타임·치명타 가능 여부·효과 순서를 보여준다. 태그 값만 나열하지 않고 각 태그가 실제 판정에서 뜻하는 내용을 바로 아래에 풀어쓴다.
- 효과 태그는 `효과 종류·수치`, `적용 범위`, `대상 진영`을 분리해 표시한다. `적군`은 시전자 기준 상대 진영, `아군`은 시전자와 같은 진영이라는 의미도 함께 안내한다.
- 기본 파라미터는 각 수치가 실제 전투에서 무엇을 바꾸는지 설명하고, 시간 활용은 현재 설정된 전환 비용과 체류 턴을 반영한다.
- 기본 전투법은 적 계획 읽기 → 행동 순서 → 경로 → 공격 계획 → 결과 검증 순서의 짧은 튜토리얼로 제공한다.
- 긴 안내문은 버튼을 눌렀을 때만 펼쳐 전투판과 핵심 명령의 가시 영역을 보호한다.

## 유물 장착 UI

- 초기 배치 단계의 오른쪽 `BATTLE ENTRY` 영역에 현재 선택한 아군 캐릭터의 유물 장착칸 3개를 표시한다.
- 장착칸 아래에는 저장된 유물 목록을 세로 스크롤 목록으로 배치한다. 유물을 누르면 첫 번째 빈칸에 장착되고, 장착된 유물칸을 누르면 해제된다.
- 같은 유물은 중복 장착할 수 없으며 3칸이 모두 찬 상태에서는 기존 유물을 먼저 해제하도록 안내한다.
- 유물 카드는 이름·등급·효과 요약을 표시하고 `일반/희귀/전설` 등급은 아이콘 색으로 보조 구분한다.
- 장착 효과는 캐릭터 원본 문법을 수정하지 않고 장착한 캐릭터 자신에게만 합산한다. 유물을 해제하면 해당 캐릭터의 원래 능력치에서 다시 계산한다.
- 장착 목록은 브라우저 로컬 저장소에 저장하며, 유물 자체는 콘텐츠 공방의 `유물` 탭에서 문법으로 추가·수정·삭제한다.

## 전투판 표시 의미

| 표시 | 의미 |
|---|---|
| 이동 방향을 향한 파란 발자국 | 아군 이동 경로 |
| 이동 방향을 향한 빨간 발자국 | 적 이동 경로 |
| 파란 실선 | 실행 가능한 아군 대상 연결 |
| 빨간 실선·영역 | 적 공격 범위 또는 적 대상 연결 |
| 주황 점선 | 실행 시점 기준 범위 밖 |
| 노란 굵은 화살표 | 밀치기 방향과 도착점 |
| 보라 점선·꺾쇠 | 당기기 방향과 도착점 |
| 반투명 캐릭터 글자 | 강제이동 후 예상 도착 셀 |
| 파란·빨간 반투명 SD | 아군·적군 이동 경로의 예상 도착 셀 |
| `✕`, `충돌` | 점유 셀이나 전투판 경계로 요청 거리만큼 이동하지 못함 |
| 원형 테두리와 `면역` | 강제이동이 적용되지 않음 |

색만으로 구분하지 않는다. 공격에는 `공격`, 적 연결에는 `적 공격 대상`, 강제이동에는 종류와 `실제/요청 거리`를 글자로 함께 표시한다.

- 아군과 적군 이동 경로는 선 대신 좌우가 번갈아 찍힌 정적인 파란색·빨간색 발자국으로 표시한다. 발자국은 경로 전체 누적 거리를 기준으로 같은 간격을 유지하며, 넓은 발끝이 현재 구간의 도착 방향을 향한다. 꺾이는 지점에서도 간격 계산을 다시 시작하지 않고 이동 애니메이션은 사용하지 않는다.
- 발자국은 넓어진 앞코와 분리된 뒤꿈치로 구성한 신발 자국 실루엣을 사용한다. 캐릭터나 행동을 선택하지 않았을 때는 발자국만 표시하고, 선택한 계획에는 발자국 위로 해당 진영색 경로선을 추가해 현재 편집 대상을 강조한다.

## 계획선 표시 필터

- 기본값은 `턴 결과`다. 아군 계획은 숨기지만 적 이동 발자국과 스킬 공격은 유지하고, 아군별 예상 HP·상태·강제이동·공격자 번호를 함께 표시한다.
- 아군 또는 적 행동 슬롯을 누르면 해당 행동의 선과 결과만 표시한다.
- 단, 아군 행동을 편집할 때는 모든 적의 이동·스킬·결과 예고를 계속 유지하고 선택한 아군 계획만 추가 강조한다. 적 예고를 읽으며 안전 위치와 예상 위치 공격을 함께 계획할 수 있어야 한다.
- 대상형 공격을 가진 적 행동을 선택하면 예상 시전 위치 중심의 전체 사거리 셀을 붉은 반투명 영역으로 표시한다. 연결선만 보고 거리 규칙을 역산하게 하지 않는다.
- 공격자보다 먼저 행동하는 대상의 경로가 바뀌면 연결선 끝과 대상 링을 경로 종점으로 이동한다. 사거리 경계를 넘는 프레임에서 실선이 주황 점선으로 바뀌고 `연결 파괴` 연출을 재생한다.
- 이동 경로가 한 칸 이상이면 마지막 셀에 진영색 SD 홀로그램과 행동 슬롯 번호를 표시한다. 같은 셀에 여러 도착 계획이 있으면 홀로그램을 좌우로 조금씩 벌려 겹치고, 중첩 부분이 더 밝게 보이도록 한다.
- 도착지 홀로그램에도 실제 말과 같은 클릭 영역을 둔다. 타겟형 행동을 선택하고 홀로그램을 클릭하면 해당 캐릭터 ID가 타겟으로 지정된다.
- 계획 단계에서는 다른 아군을 선택해도 이미 작성한 모든 아군 경로·공격·홀로그램을 낮은 투명도로 유지한다. 현재 선택한 아군 계획만 선명하게 표시한다. 적 행동 집중 보기에서는 선택한 적의 계획만 남기고 다른 아군·적 계획은 숨긴다.
- 홀로그램 뒤의 장식용 가로 스캔라인은 의미 없는 정보로 오인될 수 있어 제거한다. 진영색 반투명 SD와 슬롯 번호만 사용한다.
- 행동 순서상 대상 이동이 공격 뒤라면 연결선은 현재 위치에 유지해 실제 시전 타이밍과 표시가 어긋나지 않게 한다.
- `모든 계획`은 겹침을 비교하는 검증용 보기로만 유지한다.
- 실행 단계에서는 현재 실행 슬롯만 선명하고 미래 슬롯은 흐리다.
- 완료·충돌·취소된 슬롯의 연결선은 제거한다.

## 행동 순서 상태

- 선택: 금색 테두리
- 실행 중: 금색 발광
- 완료·기절: 낮은 불투명도
- 충돌·취소: 주황 테두리와 결과 글자
- 적 AI 슬롯: 어두운 적색 바탕과 `AI` 표시

## 우측 패널 상태 전환

### 계획

- `턴 결과`에서는 아군별 예상 결과 → 계획 수정 진입 → 실행 → 적 행동 목록 순서다.
- 아군 행동을 선택하면 캐릭터 정보 → 이동·후속 행동 요약 → 행동 버튼 → 맥락 안내 → 초기화·실행 순서로 전환한다.
- 적 행동을 선택하면 아군 편집 UI를 함께 노출하지 않고 적 이름·스킬·대상·예상 결과만 표시한다.
- 대상형은 무제한으로 지정할 수 있다는 안내와 실행 가능 여부를 함께 표시한다.
- 방향형은 노란 밀치기와 보라 당기기 표시를 안내한다.
- 실행 버튼 아래 `적 위협` 카드를 항상 노출한다. 카드 한 장은 `행동 번호 · 적 이름 · 스킬명 · 대상 · 예상 결과`를 한 묶음으로 표시한다.
- 위협 카드를 누르면 해당 적 행동의 이동 경로, 공격선, 대상 결과 칩만 선명하게 남긴다. 다시 전체 계획 보기로 돌아갈 수 있다.

## 적 행동·결과 예고

- 적 머리 위에는 `행동 번호 · 행동명`을 붙여 전투판과 행동 순서를 연결한다.
- 실제 대상 옆에는 `행동 번호 피해량 · 상태이상 · 밀치기/당기기 실제 거리` 결과 칩을 표시한다.
- 우측 위협 카드는 `적중 예상`, `취소 예상`, `대상 없음`, `이동·대기`를 색과 글자로 함께 구분한다.
- 예상 결과는 현재 계획 전체를 행동 번호 순서로 모의 실행한 값이다. 선행 행동의 이동, 피해, 전투불능, 기절, 밀치기·당기기로 달라진 좌표를 후속 행동에 반영한다.
- 밀치기·당기기 미리보기는 피아를 가리지 않고 범위 안의 모든 캐릭터에 표시한다. 같은 진영 대상에는 강제이동 결과만 표시하고 피해 결과는 표시하지 않는다.
- 경로 충돌, 시전자 기절·전투불능, 시전 시점 사거리 밖은 피해 수치 대신 취소 이유를 표시한다.
- 이 표시는 확정 결과가 아니다. 플레이어가 경로나 행동을 바꾸면 즉시 다시 계산되며, 확률 요소나 이후 추가될 환경 규칙이 있다면 `예상`이라는 표현을 유지한다.

## 결과 중심 UI v2

- 상단 행동 순서 맨 앞에 `턴 결과` 슬롯을 추가한다.
- 기본 화면에서는 아군 계획선만 숨긴다. 적 이동은 붉은 발자국과 `#행동번호 이동`, 적 스킬은 붉은 실선·범위로 항상 보여 원인과 결과가 끊기지 않게 한다.
- 피해받는 아군 옆에는 `HP 60→52 · 기절`, 그 아래에는 `공격자 #3`처럼 최종 결과와 원인을 분리한다.
- 우측 결과 카드에서도 같은 HP 변화와 상태를 사용해 전투판과 문법을 통일한다.
- 적 행동 번호를 선택하면 전투판에는 해당 행동만 남기고, 우측 전체 패널을 `시전자 → 행동 → 결과` 상세로 전환한다.
- 공격선 중앙의 `적 공격 대상`, `공격` 같은 반복 문구는 제거한다. 방향은 화살표, 범위 밖은 `취소 · 범위 밖`으로만 표시한다.
- 전체 선이 필요한 경우에만 `모든 계획`을 선택한다.

### 실행

- 계획 편집 버튼과 방향 입력을 숨긴다.
- 현재 슬롯 번호, 진영, 캐릭터, 행동 종류, 대상·방향, 처리 결과만 표시한다.
- 하단 상태 줄도 `N번 실행 · 캐릭터 · 행동`으로 바뀐다.

## 반응형 기준

- 넓은 화면: 시간대 / 전투판 / 명령의 3열.
- 중간 화면: 시간대와 전투판 2열, 명령 패널은 아래 전체 폭.
- 작은 화면: 전투판 → 시간대 → 명령 순서의 1열.
- 모바일에서도 전투판 범례와 표시 필터를 먼저 유지하며, 로그 높이를 제한한다.

- 일반 시간 진행 시 새 위치로 즉시 바꾸지 않는다. 시침이 이전 눈금에서 다음 눈금까지 시계 방향으로 30도 회전하고, 목표점을 조금 지나친 뒤 짧은 반동을 거쳐 정확히 멈춘다. 12번째 눈금에서 첫 눈금으로 넘어갈 때도 330도에서 360도로 계속 전진해 역회전처럼 보이지 않게 한다.

- 연계 표시는 실제 공격 성공이 확인된 직후의 좌표를 기준으로 계산한다. 두 SD 머리 사이에 굵은 금색 곡선, 양 끝 에너지 발광, 이동 입자와 `⚡ 연계` 배지를 전장 레이어에 약 1.5초만 표시한다.
- 일반공격·스킬의 타겟 또는 방향을 고르는 중에는 말판의 적 클릭을 행동 스냅샷 선택으로 해석하지 않는다. 기존 공격 대상·방향 입력만 처리하고 현재 행동 카드 강조를 유지한다.
- 적 행동 결과로 HP가 줄면 체력바에서 사라지는 구간만 황적색으로 짧게 점멸시켜 손실량을 바로 읽게 한다.
- 방향형·셀형 공격 예고는 시전자와 대상을 붉은 선으로 잇지 않는다. 실제 피해를 받는 타일만 붉게 반복 점멸한다.
- 아군 행동 카드를 보는 동안에는 스냅샷 SD를 경로마다 움직이지 않고, 원본 계획 화면의 이동 경로와 도착지 홀로그램을 사용한다.
- 스킬 타겟팅 상태는 행동 스냅샷 선택과 분리한다. 대상·방향 선택 중에는 원본 범위 하이라이트와 확정 입력이 우선하며, 확정·취소 뒤에만 스냅샷 탐색으로 복귀한다.
- `계획 실행`을 누르는 순간 행동 스냅샷의 임시 좌표·연출 레이어를 먼저 제거하고 초기 보드 상태를 다시 그린 뒤 원본 전투 실행을 시작한다.
- 공격·범위 타일의 점멸은 원본 보드 컨테이너 안에서 일반 타일 다음, 첫 SD 이전에 삽입한다. 타일 표현 중에는 가장 높지만 SD·발판·체력바는 절대 덮지 않는다.
- HP 손실 잔상은 원본 체력바의 정확한 좌표 `K+20`, 높이 `4`, 내부 폭 `48`을 그대로 사용한다. 해당 진영의 기존 체력바 색으로 사라진 길이만 반투명 점멸하며, 해당 적 행동을 선택한 동안 유지한다.
- 피해 수치 텍스트는 짧게 표시한 뒤 완전히 사라진다.
- 아군 SD 클릭 시 복제된 스냅샷 객체가 아니라 실제 캐릭터 데이터를 선택하고, 해당 행동 이전까지 완료된 다른 캐릭터의 위치를 적용한 보드를 표시한다.
