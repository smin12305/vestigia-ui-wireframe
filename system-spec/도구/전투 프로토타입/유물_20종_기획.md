# 시간대 유물 20종 기획

> 상태: `[사용 중단]` · 아래 목록은 유물 고유 시간대 태그를 사용한 기존 참고안이므로 신규 콘텐츠 기준으로 사용하지 않는다.
> 신규 제작 문법: `제안/시스템/Waredo_2.0_가방_유물_시스템_기획서.md` 4-4
> 아래 목록은 기존 시간대 설계를 바탕으로 한 참고안이며, `확정/시스템/Waredo_2.0_시간대_전환_시스템_기획서.md`의 규칙을 덮어쓰지 않는다.
> 기존 목록의 `시간 포인트` 효과는 새 확정 규칙과 충돌하므로 `[보류]`로 취급한다. 유물 시간 조건은 공통 `timeTag` 체계와 `도구/전투 프로토타입/유물_문법.md`를 따른다.

## 수치 표기 기준

- `치명타 피해율 +50%p`: 기존 수치에 50을 합산한다. `150% → 200%`.
- 치명타 피해율의 모든 증가·감소는 배율을 사용하지 않고 `%p`로 합산한다. 예: `150% +30%p → 180%`.
- 피해·회복·능력치 계산에서 소수점이 발생하면 모든 보정을 적용한 최종 단계에서 반올림해 정수로 표시하고 적용한다.
- 시간대 상시 효과는 해당 시간대에 머무는 동안만 적용하며, 시간대를 벗어나면 원래 수치로 복귀한다.
- 시간대 진입 효과는 시간대가 실제로 바뀐 순간 한 번만 발동한다. 같은 시간대를 다시 선택하거나 턴이 지나가는 것만으로 재발동하지 않는다.
- 현재는 전투 시작부터 적용된다. 시간대 변경 비용·체류·기본 파편 획득은 시간대 전환 시스템 단일 원본을 따른다. 이 제안의 밸런스 수치는 별도 검토 전까지 확정하지 않는다.
- 현재 프로토타입은 아래 20종과 `발동`, `시간대`, `체력이하` 조건을 구현했다. 전투 계산과 적 위협 예측에도 장착 효과를 함께 반영한다.
