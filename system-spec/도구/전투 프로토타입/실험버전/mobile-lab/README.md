# Waredo 모바일 전투 실험

상태: UI·인터랙션 제안. 기존 v5와 확정 기획을 대체하지 않는 독립 실험이다. Figma 상태 전환이 아니라 피해와 턴을 계산하는 브라우저 프로토타입이다.

## 실행

- 이 폴더에서 `npm start` 후 `http://localhost:5186/mobile-lab/` 접속.
- `npm run build`로 만든 `standalone/index.html`은 서버 없이 열 수 있다. 캐릭터와 배경도 포함한다.
- `npm test`로 순수 전투 모델 테스트 실행.
- 가로 모바일 우선, 세로에서는 전장 아래로 조작 패널을 재배치한다.

## 조작

1. 아군 → 이동 → 파란 도착지 선택. 잔상과 경로가 표시된다.
2. 일반 공격 또는 스킬 → 방향/목표 선택 → 행동 확정. 자기 중심 스킬은 방향 선택이 없다.
3. 우측 이름 옆 화살표로 아군 순서를 조절한다. 적 순서 슬롯은 유지된다.
4. 계획 실행으로 아군·적 이동과 공격을 순차 처리한다. 미설정 캐릭터는 대기한다.
5. 적을 선택하거나 적 예고를 켜서 예정 이동과 범위를 본다. 앞선 행동에 따라 예고 결과는 달라질 수 있다.
6. 파편 100이면 왼쪽 과거/미래를 눌러 즉시 전환한다. 명령 작성 중에도 별도 창 없이 가능하다.
7. 일시정지 메뉴의 시간 전환 연습은 파편 100으로 재시작한다. 일반 시작은 0이다.

## 구현 범위

- 6×6 플랫 보드, 아군 3명/적 3명, v5 SD 이미지, 경로·도착 잔상·직선·주변·착탄·반격 범위.
- HP, 일반 공격, 스킬, 공유 쿨다운, 띄워짐·기절·밀치기·반격, 적 AI, 승패, 기록, 배속·일시정지.
- 현재에서 적 공격/처치/턴 종료로 파편 획득. 100 소모, 2턴 유지, 현재 복귀. 과거 아군 이동 +1, 미래 아군 일반 공격 +3, 시간 성향에 따른 스킬 강화.
- 초기 배치와 단일 전투 시나리오는 실험용 가정이다. 턴마다 선공 진영이 교대한다.
- 독립 간소화 모델: 유물·배치 편성·캠페인·지형 효과·아군 오사·전체 v5 규칙 동등성은 구현하지 않았다. 배경은 장식이며 장애물로 취급하지 않는다.
- 지속 상태는 이 실험에서 턴 종료에 정리한다. 확정 시스템의 다음 행동 기반 지속 시점까지 동일하게 구현한 것은 아니다. 피해 안내는 기본 피해이며 상태 치명타와 선행 행동으로 실제 결과가 달라진다.

## 레퍼런스 적용

- [명일방주 공식](https://www.arknights.global/)과 사용자가 첨부한 전투 스크린샷: 가장자리 HUD, SD 유닛과 HP, 각진 반투명 패널, 밝은 핵심 행동 버튼, 배속·정지. 맵의 쿼터뷰는 가져오지 않았다.
- [Into the Breach 모바일 리뷰](https://toucharcade.com/2022/07/21/into-the-breach-mobile-review-controller-support-icloud-save-cross-progress-netflix-games-download-android/): 전장 중심의 터치 조작과 적 행동 예측을 참고했다. 구체적인 UI는 Waredo 전투 계획 구조에 맞춘 제안이다.
- 실제 시간 수치와 캐릭터 자산은 프로젝트 확정 시간 시스템 및 v5를 참고했다. 외부 게임 이미지를 재배포하지 않는다.

## 검증

- 모델 자동 테스트 11개: 파편·시간 복귀, 범위, 경로 검증, 공격 보너스, 쿨다운, 반격, 순서, 치명타·승패, AI 완주/유닛 중첩 검사.
- 브라우저 실제 입력: 아이작 이동→지진→실행 후 창병 HP 50→42, 재사용 2턴, 다음 턴 진입 확인.
- 실제 기기 테스트와 게임 규칙 전체 대조 검수는 남아 있다.
