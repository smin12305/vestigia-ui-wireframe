# 림버스식 행동 예측 UX 실험판

공식 프로토타입을 대체하지 않는 별도 실험 버전입니다.

## 실험 목표

- 전투 진입 직후 적 3명의 이번 턴 행동을 실제 행동 번호 순서로 먼저 보여줍니다.
- 행동 카드 N번을 누르면 `1~N-1번 행동이 끝난 직후`의 실제 SD 배치 상태로 말판을 바꿉니다.
- 행동 하나를 선택하면 다른 행동 예고는 숨기고, 그 행동의 이동 경로와 도착 위치 기준 공격 범위를 계속 보여줍니다.
- 아군 행동은 해당 행동의 이동이 끝난 위치만 정적으로 표시하며 이전 위치의 SD는 남기지 않습니다.
- 적 행동은 필터 없이 직전 상태에서 이동 경로를 따라 움직인 뒤 공격·스킬 연출까지 재생합니다.
- 행동 순서 오른쪽 끝의 `적 전체 예고`로 언제든 초기 전체 예고 화면에 돌아갑니다.
- 밀치기는 이동 효과와 함께 `띄워짐`을 부여해 후속 공격의 연계 조건이 됩니다.
- 앞 캐릭터가 적을 띄운 뒤 다른 캐릭터의 타겟팅 중 같은 적을 누르면, 적중 가능한 치명타 공격일 때 연계로 판정합니다. 타겟을 누르는 순간 화면이 짧게 흔들리고 두 아군 SD 사이에 금색 에너지 곡선과 `연계!` 표시가 나타납니다.
- 별도의 오른쪽 행동 예고 패널은 사용하지 않습니다.
- 각 SD 머리 오른쪽 위의 작은 원형 배지로 실제 행동 번호를 확인할 수 있습니다.
- 말판의 캐릭터를 직접 눌러도 같은 번호의 행동 카드가 선택·강조됩니다.
- 시뮬레이션 중 사망한 적은 회색으로 남고 더 이상 선택할 수 없습니다.
- 이동 애니메이션은 계획 경로의 타일을 하나씩 따라가며, 꺾인 경로도 실제 꺾이는 지점을 통과합니다.
- 적 공격 이후 피해량, 변경된 HP, 밀치기·당기기 거리와 최종 좌표가 행동 스냅샷에 적용됩니다.
- 연계선은 타겟을 고르는 동안만 유지되며 다른 타겟 선택·취소·행동 확정 시 사라집니다. 실행 중에는 자동으로 나타나지 않고, 상태이상 적용자와 후속 공격자가 같은 경우에도 표시되지 않습니다.
- 타겟팅 중에도 아군의 도착 위치 홀로그램과 행동 라벨은 유지합니다. 홀로그램은 시각 안내만 담당하고 클릭 판정은 끄므로, 대상 선택과 연계선은 앞선 행동이 반영된 실제 SD를 기준으로 처리합니다.
- 앞선 행동에서 밀치기·당기기를 당한 캐릭터는 직전 행동 완료 스냅샷의 강제이동 위치를 새 경로 시작점으로 사용합니다.
- 공격 대상이나 방향을 선택하는 중 적을 눌러도 행동 카드 선택이 적 행동으로 바뀌지 않습니다.
- 적에게 피해가 적용되면 체력바에서 실제로 줄어드는 구간만 잠깐 깜빡입니다.
- 방향형·셀형 공격은 붉은 연결선 대신 실제 피해 타일을 붉게 점멸합니다.
- 아군 행동 설계 중에는 캐릭터 본체를 매번 옮기지 않고 이동 완료 지점에 홀로그램을 표시합니다.
- 스킬 대상·방향 선택과 행동 스냅샷 입력을 분리해 타겟 확정이 끊기지 않습니다.
- `계획 실행`을 누르면 스냅샷을 종료하고 턴 시작 시점의 보드에서 실제 실행 연출을 진행합니다.
- 공격 타일 점멸은 타일 표현 중 가장 위이면서 SD·발판·체력바보다 아래에서 표시됩니다.
- HP 손실 구간은 원본 체력바와 동일한 좌표·높이·폭에 같은 색의 반투명 잔상으로 겹치며, 해당 적 행동을 선택하고 있는 동안 계속 깜빡입니다. 피해 숫자는 잠시 뒤 사라집니다.
- 아군 SD를 누르면 그 행동 직전까지 완료된 위치가 반영되고, 실제 아군 선택 카드도 함께 전환됩니다.

## 조작

1. 전투를 시작하고 아군을 배치합니다.
2. 처음 공개되는 `적 전체 행동 예고`로 위험한 행동 번호를 확인합니다.
3. 설계할 아군 행동 카드를 누릅니다.
4. 말판에서 직전 행동까지 반영된 위치, 선택 행동의 이동 경로와 도착 후 공격 범위를 확인합니다.
5. 이동, 공격, 스킬을 기존 방식으로 설정합니다.
