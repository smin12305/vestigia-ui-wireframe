# 전투 시스템 실험버전 v3

> 결정 상태: `[실험]`  
> 기준: `확정/시스템/Waredo_2.0_시간대_전환_시스템_기획서.md`를 실행 가능한 형태로 검증하는 현재 활성 실험본이다. 수치와 규칙의 최종 원본은 `확정/` 문서다.

## 실행

```powershell
npm run dev
```

배포용 단일 HTML은 `npm run build:standalone`으로 생성한다.

## 실험 규칙

- 공격과 스킬의 지정 방식은 `방향 선택형`, `자기 기준형`, `자가 버프형`만 사용한다.
- 방향 선택형은 상하좌우 중 한 방향을 고른 뒤 확정한다.
- 자기 기준형은 이동 완료 위치를 중심으로 범위를 표시하며, 범위를 다시 클릭해 확정한다.
- 자가 버프형은 자신을 다시 클릭해 확정한다.
- 공격·스킬 버튼을 누르면 먼저 지정 범위를 표시한다. 범위나 해당 캐릭터를 다시 클릭하는 빠른 확정과 별도로, 한 번 지정한 뒤 `행동 확정` 버튼을 눌러도 확정된다.
- 확정하지 않은 공격·스킬이 남아 있으면 전체 계획 실행 버튼을 비활성화한다.
- 직사는 선택 방향으로 투사체를 발사한다. 비관통 공격은 첫 캐릭터에서 멈추며 아군도 투사체를 막고 피해를 받을 수 있다.
- 곡사는 사거리 안의 타일 하나를 고른다. 계획에는 절대 타일이 아니라 시전자 기준 상대 위치가 저장되며, 곡선 궤적과 착탄 범위를 표시한다.
- 적의 미래 결과나 체력 변화는 예측하지 않는다. 적마다 현재 행동 예고만 고정해 표시하며 행동 순서를 바꿔도 예고는 변하지 않는다.
- 적 초상화를 클릭하면 고정된 행동 예고를 가상 이동·공격 애니메이션으로 재생한다.
- 전장 또는 상단 행동 순서의 적 캐릭터를 클릭하면 왼쪽 아래 캐릭터 카드가 해당 적의 체력·능력치·공격·스킬 정보로 변경된다.

## 반격

- `반격` 상태 캐릭터의 현재 위치 기준 3×3 안에서 적이 행동하면 즉시 일반 공격 피해로 반격한다.
- 적이 범위 안에서 이동을 시작하거나, 범위에 진입하거나, 범위 안에서 행동할 때 발동한다.
- 일반 이동은 이동 칸마다 검사하고, 강제 이동은 이동 완료 위치에서만 검사한다.
- 같은 반격자가 같은 대상을 한 턴에 두 번 공격하지 않는다. 반격자가 강제 이동돼도 상태와 대상 기록은 유지된다.
- 기절 또는 에어본 상태에서는 반격할 수 없다. 반격 피해로 대상이 전투 불능이 되면 남은 이동과 행동을 취소한다.
- 여러 반격자가 동시에 조건을 만족하면 순서를 무작위로 정한다. 반격 시 반격자의 돌진과 피격 지점 충격을 재생한다.
- 반격은 적에게 일반 공격 피해 1건만 준다. 반격 피해로 적을 쓰러뜨리면 사살 파편 +30을 얻으며, 반격 자체는 적 일반 공격 파편을 생성하지 않는다. 반격 범위에서 피해를 한 번 받은 대상은 같은 반격 상태의 추가 대상에서 제외된다.

## 시간대 전환

- 전투는 현재 시간대에서 시작한다. 계획 단계에서만 시간대 변경 버튼을 사용할 수 있으며, 버튼을 누르는 순간 즉시 적용된다.
- 시간 파편은 현재에서만 획득한다. 적 일반 공격 `+10`, 적 치명타 공격 `+30`, 사살 `+30`, 턴 종료 `+10`이며 최대 100까지만 저장한다. 과거나 미래에서는 어떤 원천으로도 파편을 얻지 않는다.
- 파편이 100이면 과거 또는 미래로 이동할 수 있고, 이동 시 파편 100을 소모하며 배경·시간대 버프·캐릭터 궁극기 활성 상태를 함께 갱신한다.
- 과거에서는 아군 이동력 `+1`, 미래에서는 아군 일반 공격력 `+3`을 적용한다. 해당 시간대의 `timeTag`를 가진 아군은 일반 스킬 대신 궁극기를 사용한다. 일반 스킬과 궁극기는 같은 쿨타임을 공유하며 전환 시 남은 쿨타임을 유지한다.
- 과거 또는 미래에는 2턴 머문 뒤 현재로 자동 복귀한다. 시간대 태그에는 상성이 없으며 피해 배율도 만들지 않는다.
- 캐릭터 `timeTag`는 `과거` 또는 `미래`를 사용하고, 유물은 같은 공통 태그 체계의 `시간대` 조건을 사용한다.

## 역동적 전투 연출

- 공격과 스킬은 준비 동작, 공격 방향 돌진, 캐릭터 잔상, 범위 점멸, 투사체 또는 곡사 궤적, 적중 충격 순서로 재생한다.
- 공격·스킬 범위를 선택하는 동안 캐릭터와 범위 타일이 겹치면 범위 입력을 우선한다. 따라서 범위 안의 적을 눌러도 적 정보로 전환되지 않고 해당 공격 방향이나 스킬 셀이 먼저 지정된다.
- 공격·스킬 범위가 열린 동안 전장 전체를 하나의 화면 딤으로 덮고 그 위에 선택한 캐릭터, 선택 캐릭터의 이동 후 기준 홀로그램, 지정 가능한 범위와 범위 안 캐릭터만 다시 밝게 표시한다. 시계·행동 순서·계획·공격·스킬 버튼·캐릭터 카드 등 전투 UI는 딤 처리하지 않으며, 그 외 딤 영역의 캐릭터와 홀로그램은 클릭할 수 없다.
- 전술판 전체 시야를 고정하며 공격·스킬·반격·시간 조작 중 카메라 이동이나 확대를 사용하지 않는다.
- 피해 판정 결과를 별도 연출 이벤트로 전달해 일반 적중, 치명타, 사살, 치명타 사살, 반격 사살의 충격 크기·색·문구를 구분한다.
- 치명타 적중에는 0.23초의 짧고 날카로운 전체 화면 흔들림을 적용한다. 시간 추가 피해가 이어지면 0.28초 뒤 더 강한 흔들림이 별도로 재생된다.
- 사망 시 피해자 쓰러짐 잔상, 붉은 파편, 전투 불능 문구를 표시하고 사살자는 발밑 오라로 강조한다.
- 시간 우대 캐릭터의 피해는 기본 타격 후 0.28초 뜸을 들이고 시간 중첩 배율에서 생긴 추가분을 별도 피해로 적용한다. 이때 `시간 추가 데미지!`, 최종 추가 피해 숫자, 폭발 파편, 화면 루트에 직접 적용한 강한 타격 흔들림을 재생한다. 피해 연출에는 곱셈식이나 중첩 수를 함께 표시하지 않는다.
- 시간 조작은 가속·정지·역행별 화면 색상과 방향 파티클을 재생한다. 모션 감소 환경에서는 시간 추가 피해의 화면 흔들림과 다량 파티클을 생략하고 핵심 판정 표시는 유지한다.

## 2026-09-01 안정화 수정

- 전투 카메라의 세로 중심을 말판 중심과 동일하게 맞춰, 16:9 화면에서 격자가 경기장 아래로 밀리던 현상을 수정했다.

- 시간대가 진행되어 중첩이 증가하거나 다른 시간대의 1중첩으로 전환되면 강화 대상 캐릭터에게 확대 링, 섬광 파티클, 중첩 수 라벨을 한 번 재생한다.

- 메르칸의 `복수`를 선택하면 실제 반격 판정과 같은 자기 중심 3×3 범위를 금색 타일과 라벨로 표시한다. 자신 또는 반격 범위 타일을 다시 누르면 스킬을 확정할 수 있다.
- 확정한 아군 행동은 다른 캐릭터를 선택해도 전장에 유지한다. 이동은 발자국과 도착 홀로그램, 일반 공격·스킬은 실제 적용 범위로 표시하며 `복수`의 반격 구역은 아군색 청록 빗금으로 구분하고 메르칸이 서 있는 중심 칸은 비워 둔다.
- 일반 공격·스킬·반격에 실제 캐릭터 동작 연출을 추가했다.
- 모든 피해 경로에서 전투 불능을 즉시 처리하며, 반격으로 사망하면 남은 이동·행동을 취소하고 승패를 판정한다.
- DOM 보드와 Phaser 논리 캔버스의 비율을 `1920:893`으로 통일해 비등방 확대를 막았다.

## 2026-09-03 기존 v3 UI 재정비

- 별도 신규 프로토타입을 기준으로 삼지 않고 기존 v3의 엔진·입력·연출을 유지한 채 UI 표시만 교체했다.
- 새 고원지대 배경과 Phaser 캔버스를 같은 화면 평면에 고정해 전체화면에서도 동일한 중심·축척·크롭을 사용한다.
- 6×6에서는 기존 9×9 면적 유지용 `1.5` 배율과 과도하게 작았던 `1.0` 사이의 전용 배율 `1.32`를 사용한다.
- 기본 격자는 투명 내부와 회색 선, 아군 이동 범위는 투명 내부와 파란 최외곽선, 공격 가능 범위는 연한 하늘색, 확정 범위는 진한 파랑으로 구분한다.
- 적 캐릭터 포커스에서는 이동 가능 범위를 빨간 최외곽선, 최대 공격 범위를 연한 빨강, 선택된 공격 범위를 진한 빨강으로 표시한다.
- 반격 구역은 기준 캐릭터 칸을 제외한 파란 빗금으로 표시한다. 밀치기 거리는 1·2·3개의 화살표 배열로 구분한다.
- 상단 행동 슬롯은 진영색 원형으로 표시하고 계획 완료·적 계획 공개 오라, 실행 슬롯 확대를 적용했다. 아군 원형을 1초간 누른 뒤 다른 아군 원형으로 끌면 순서를 교체한다.
- 계획 진입 시 적 행동을 순서대로 한 번씩 가상 재생하고 공개된 적 원형의 빨간 하이라이트를 유지한다.
- 메인 화면에서 6×6 전투로 바로 진입하며 모바일 모드와 9×9 선택 화면을 제거했다. 유물 장착·편집 UI도 표시하지 않는다.
- 공격·스킬은 배경 패널 없는 원형 버튼으로 표시하고 확정 버튼을 위에 둔다. 모든 아군 계획이 준비되면 `작전 개시!`로 표시하며 실행 순간 가벼운 화면 진동을 재생한다.

### 2026-09-06 전투 연출·안내 정리

- 발사체 도착과 공격 예고의 명중 시점을 실제 피해 경계에 연결했다. 피해 시 HP 갱신·피격 섬광·숫자·효과음을 발생시키며 치명타·궁극기는 짧은 타격 정지와 제한된 화면 충격을 사용한다.
- 아이작의 스킬은 상승 충격, 안젤리카는 조준선·투사체, 메르칸은 반격선과 명중 충격을 사용한다. 이동을 짧게 보간하고 띄워짐은 SD 높이, 기절은 머리 위 표식으로 구분한다.
- 시간 이동은 시계 회전 → 필터·진입 문구 → 캐릭터별 랜덤 순차 각성 → 입력 재개 순서다. 각성은 별도 클로즈업이며 보드·배경 카메라를 움직이지 않는다.

### 2026-09-06 유물 가방 조작

- 장착 효과 요약은 상시·시간대 진입·턴 시작·공격 적중 시 제목별로 묶고 각 제목 아래에 효과 합계를 표시한다.

- 왼쪽 정보 패널, 위쪽 시간대별 2×2 장착 칸, 아래쪽 보유 유물 목록으로 구성한다. 칸에는 아이콘만 표시한다.
- 유물 클릭은 정보 확인, 드래그는 장착·이동이다. 장착 칸끼리는 교환하며, 보유 유물을 채워진 칸에 놓으면 기존 유물은 보유 목록으로 돌아간다.
- 보유 목록으로 드래그하거나 정보 패널의 해제 버튼으로 장착을 해제한다. 유물 선택 후 빈칸 클릭도 지원한다.
- 빈칸의 위치를 저장하며 유물 창에서 배경 전장 입력 차단을 유지한다.

이 절의 규칙이 위의 이전 시간 조작·시간대 중첩 피해·시계 과열 설명보다 우선한다.

- 시간 파편 최대치와 시간대 이동 비용은 모두 100이다. 파편은 회중시계 외곽의 파란 원형 링이 12시 방향부터 시계 방향으로 채워지는 방식으로 표시하며, 처음 100에 도달하면 화면이 흔들리고 시계판의 기존 색은 유지한 채 외곽에 붉은 오라가 생긴다. 완충 시에도 시계판에 과거·미래 분할색을 표시하지 않는다.
- 파편이 100에 도달하면 턴 시작의 적 행동 예고가 모두 끝난 뒤 시계 뒤에서 오른쪽으로 시간 선택 서랍이 자동으로 열린다. 영문 보조 표기 없이 노란색 `과거로 회귀`와 파란색 `미래로 도약`만 표시하며, 버튼을 누르면 확인 창 없이 파편을 소모하고 즉시 해당 시간대로 이동한다.
- 시간 선택 서랍은 시계 오른쪽 바깥에서 글자가 가려지지 않는 짧은 폭으로 표시한다.
- 시간대 변경으로 궁극기가 활성화되는 캐릭터가 여러 명이면 대상 순서를 매번 무작위로 섞고, 한 명씩 `각성` 문구·카메라 확대·파동을 재생한 뒤 다음 캐릭터로 넘어간다. 확대는 대상 캐릭터 전용 보조 카메라에서만 수행하며, 캐릭터·배경·격자 좌표에는 흔들림을 적용하지 않는다.
- 시간대를 확정하고 조작 창이 닫히면 시침이 과거는 반시계 방향, 미래는 시계 방향으로 약 10바퀴 빠르게 회전한다. 정지 후 시계 옆에 `과거로 회귀` 또는 `미래로 도약`이 잠시 표시되며, 소모된 외곽 게이지는 회색으로 꺼지고 시계 아래에는 해당 시간대의 남은 2턴·1턴이 표시된다.
- 현재·과거·미래 시간대는 각각 옅은 녹색·황금색·푸른색 필터를 배경과 전장 전체에 적용한다.
- 시간 파편은 현재 시간대에서만 획득한다. 적 일반 공격은 10, 적 치명타 공격은 30, 사살은 30, 턴 종료는 10을 더하며 100을 넘는 부분은 저장하지 않는다. 과거·미래 체류 중에는 공격·반격·턴 경과·유물 효과로 시간 파편을 얻지 않는다.
- 전투의 첫 선공은 항상 플레이어 아군이다. 첫 행동 이후에는 상단 행동 순서대로 아군·적군이 교차 진행하고, 다음 라운드부터는 기존 선공 교대 규칙을 유지한다.
- 시간대는 현재에서 과거 또는 미래로만 이동한다. 선택한 시간대는 2턴 유지된 뒤 현재로 자동 복귀한다.
- 과거에서는 아군 이동력만 1 증가한다. 미래에서는 아군 일반 공격력만 3 증가한다. 적군은 시간대 보너스를 받지 않는다.
- 시간대 중첩과 시간 추가 피해는 제거했다.
- 캐릭터 타입을 제거하고 아군만 과거·미래 `timeTag`를 갖는다. 아이작과 안젤리카는 과거, 메르칸은 미래 태그다. 유물 시간 조건도 같은 태그 체계를 사용한다.
- 왼쪽 아래 선택 캐릭터 카드는 캐릭터의 시간대 태그를 따라 과거는 금색, 미래는 파란색의 테두리·배경 광택·초상화 테두리·체력바 포인트로 구분한다. 태그가 없는 적 캐릭터는 기존 카드 색을 유지한다.
