# Waredo 전투 프로토타입 2.0

누적된 실험 UI를 걷어내고 전장 좌표계와 렌더 레이어를 다시 구성한 데스크톱 전용 6×6 프로토타입입니다.

## 유지한 흐름

- 메인 화면 → 아군 배치 → 계획 전투 → 승리·패배 → 다시하기
- 이동 후 일반공격·스킬 실행
- 반격, 밀치기, 띄워짐, 기절, 치명타, 사망 처리
- 현재·미래·과거 시간대와 가속·정지·역행
- 기존 회중시계 형태와 시간 파편

## 제거한 시스템

- 모바일 모드와 모바일 전용 CSS·입력
- 9×9 말판과 말판 크기 설정
- 유물 데이터·장착·효과·편집 UI

## 구조 원칙

- `1920×1080` 단일 Phaser 좌표계를 사용합니다.
- 고원지대 배경, 6×6 격자, 범위, SD, 전투 효과가 같은 카메라에서 렌더링됩니다.
- 캐릭터는 `UnitView` 하나만 유지하며 매 상태 변경마다 복제하지 않습니다.
- 기본 격자·계획 범위·캐릭터·딤·선택 범위·전투 효과의 깊이 구간을 분리했습니다.
- Phaser 입력은 화면 좌표를 셀로 변환하는 단일 경로만 사용합니다.
- 상단 행동 순서에는 공통 반투명 배경을 사용하지 않습니다.

## 실행

```powershell
npm install
npm run dev
```

단일 실행 파일 생성:

```powershell
npm run build:standalone
```
