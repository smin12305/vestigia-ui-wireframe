# 모바일 전투 화면·조작 개선 구현

기준일: 2026-08-21  
기준 화면: 1920×1080, 가로형 16:9 모바일 전투 화면

## 화면 구성

- 9×9 말판은 화면 중앙에 왼쪽으로 기울어진 쿼터뷰 마름모 타일로 표시한다.
- 행동 순서는 화면 위쪽의 세로형 SD 카드 서랍으로 항상 표시한다.
- 시간 포인트는 왼쪽의 작은 시계와 게이지로 압축한다.
- 선택 캐릭터의 체력·공격력·이동력·상태는 왼쪽 아래에 표시한다.
- 일반 공격과 스킬은 오른쪽 아래, 설정·일시정지와 계획 실행은 오른쪽 위에 둔다.
- 실행 중에는 계획 입력 UI를 숨기고 말판을 조금 확대한다. 행동 순서·시간 시계·설정·일시정지는 유지한다.

## 행동 순서 카드

- 아군 카드를 누르면 순서 교환 모드에 진입한다.
- 선택한 아군은 크게, 교환 가능한 아군은 조금 크게, 적군은 작게 표시하고 나머지 화면은 어둡게 한다.
- 다른 아군 카드를 누르면 두 행동 슬롯과 기존 계획을 함께 교환한다.
- 같은 카드를 다시 누르거나 카드 바깥을 누르면 교환을 취소한다.
- 실행 중 현재 행동 카드를 확대·강조하고 나머지는 축소한다.
- 사망 캐릭터 카드는 해당 턴에 회색 처리하고 다음 턴 행동 순서에서는 제거한다.
- 상태이상은 카드 오른쪽 위 아이콘 하나와 추가 개수로 압축한다.

## 시간 UI

- 시계를 누르면 과거·현재·미래 3개 선택지가 팝업으로 열린다.
- 각 선택지에는 해당 시간대의 사용 가능 여부, 비용과 현재 선택 여부를 표시한다.
- 시간대 선택 후 팝업은 닫히며 시계 색과 화면 테마가 선택 시간대로 바뀐다.

## 캐릭터 선택과 행동 입력

- 말판의 아군 또는 도착지 홀로그램을 누르면 캐릭터를 선택하고 이동 가능 범위를 표시한다.
- 이동은 캐릭터가 있는 셀에서 드래그해 상하좌우 경로를 그린다.
- 단순 선택만으로 기존 경로는 지우지 않는다. 실제로 새 드래그가 인접 셀로 진입한 시점에 기존 경로를 새 경로로 교체한다.
- 일반 공격과 스킬은 서로 배타적이다. 버튼을 바꾸면 공격 행동만 초기화하고 이동 경로는 유지한다.
- 대상형은 대상, 방향형은 방향, 셀·설치형은 셀을 첫 탭에서 미리보기로 설정한다.
- 별도 확정 버튼으로 행동을 확정할 수 있으며, 같은 대상·방향·셀을 두 번째로 누르면 빠르게 확정한다.
- 모든 생존 아군의 행동이 확정된 뒤에만 계획 실행 버튼이 활성화된다.
- 캐릭터 초상화를 누르면 기본 공격과 스킬의 타겟 방식, 범위 패턴, 사거리, 피해, 치명타, 쿨타임과 효과 태그를 펼쳐 본다.
- 적군을 선택해도 같은 정보 UI를 사용하며, 대상형 공격의 범위를 말판에 표시한다.

## 적 행동 의도 표시

- 적의 이동 발자국, 이동 도착지 홀로그램, 공격 연결선과 방향형 공격 범위는 다른 캐릭터를 선택해도 계속 남는다.
- 적 공격의 사거리 판정 원점은 현재 위치가 아니라 적이 계획한 이동 도착지다.
- 대상형 연결선은 시전 시 사거리 안이면 파란 실선, 밖이면 주황 점선으로 표시한다.
- 방향형 공격은 맞을 셀을 붉은 타일로 표시한다.
- 밀치기·당기기는 대상 셀 위 화살표로 방향만 보여주며 예상 도착지는 미리 확정해 표시하지 않는다.
- 앞 행동에서 발생할 수 있는 밀치기·기절을 뒤 행동의 의도 원점에 연쇄 반영하지 않는다. 공개 정보는 각 캐릭터가 현재 계획한 행동 자체를 기준으로 한다.

## 실행 연출

- 공격 직전에 해당 일반 공격 또는 스킬의 실제 범위를 잠깐 밝힌다.
- 휘두르기 연출 뒤 피해·상태이상·강제 이동을 적용한다.
- 실행 단계에서는 계획 입력 장식을 숨겨 행동 결과에 집중하게 한다.

- 실제 원인은 캐릭터 좌표가 아니라 마름모 타일의 로컬 점을 음수 좌표로 만든 것이었다. 화면 엔진이 도형 중심을 다시 계산하면서 타일만 좌측 상단으로 반 너비·반 높이 이동하고 있었다.
- 화면에 배치하는 타일은 `0~타일 크기` 범위의 로컬 좌표를 사용하고, 범위 그래픽은 셀 중심 기준 좌표를 사용하도록 두 계산을 분리했다.
- 수정 후 선택 금색 타일, 캐릭터 발판, 이동 가능 셀과 포인터 입력이 동일한 셀 중심에서 일치하는 것을 스크린샷으로 확인했다.

## 2026-08-21 경로 부분 수정과 SD 화질 개선

- 이미 그린 이동 경로의 시작점, 중간 셀 또는 도착 셀을 누른 채 다시 드래그할 수 있다.

- 경로 위를 단순히 누르고 놓으면 기존 경로를 변경하지 않는다.
- 도착지 홀로그램을 잡아도 도착 셀부터 경로를 이어서 수정할 수 있다.
- 전투 캔버스 내부 해상도를 기존 960×680에서 1920×1360으로 높이고, 카메라는 기존 960×680 논리 좌표계를 그대로 보여주도록 설정했다.
- SD 원본을 낮은 해상도의 캔버스에서 확대하던 방식을 없애고 2배 해상도로 렌더링한 뒤 화면에 축소해 윤곽선과 세부 묘사를 개선했다.
- 자동 검증에서 3칸 경로의 중간 셀부터 다른 방향으로 재작성해 앞부분 유지와 새 도착점 반영을 확인했다. 이후 공격 미리보기와 두 번째 탭 확정도 정상 작동했다.

- 계획·실행 단계의 전투 영역을 높이 기준으로 계산하고 `960:680` 비율을 고정해 실제 표시 비율을 1.412로 맞췄다.
- 모든 SD 원본은 120×160, 비율 0.75이므로 고정 가로·세로 크기를 강제로 넣지 않고 원본 비율을 유지한 채 최대 영역 안에 맞추도록 변경했다.
- 수정 뒤 캔버스 실제 크기 1235.7×875.3, 비율 1.412를 확인했다. 경로 중간 재작성과 공격 입력 회귀 테스트도 통과했다.

## 2026-08-21 타일 각인형 발자국

- 한 타일 안에 왼발과 오른발을 앞뒤로 놓으며 다음 타일에서는 먼저 나가는 발을 반대로 교대해 걸어가는 리듬을 표현한다.
- 발바닥 안쪽 굴곡을 좌우 반전해 왼발과 오른발의 모양을 구분한다.
- 직진 셀은 진행 방향을 향하고, 경로가 꺾이는 셀은 이전 방향과 다음 방향의 중간 방향을 향한다. 직교 경로에서는 꺾이는 쪽으로 45도 돌아가는 전환 자세가 된다.

- 전투 실행 중 나타나는 피해·치명타·상태이상 결과, 유지 중인 기절·띄워짐 상태와 연결 융합·파괴 연출 글자는 중요한 전투 피드백이므로 유지한다.
- 1920×1080 실제 화면에서 행동 라벨이 시전 위치를 따라가고 불필요한 계획 글자가 사라진 것을 확인했다. 전체 회귀 검증도 통과했으며 런타임 오류는 없었다.

## 2026-08-21 시간대 두 번 눌러 변경

- 시간 변경 창에서 시간대 카드를 처음 누르면 선택 대기 상태로 표시한다.
- 선택된 카드에 금색 강조와 `한 번 더 눌러 변경` 안내를 표시한다.
- 같은 카드를 다시 누르면 예정 시간대를 확정하고 시간 변경 창을 닫는다.
- 계획 중 시계와 전투판 색은 확정한 예정 시간대를 즉시 미리보기로 반영한다.
- 시간 포인트 차감과 해당 시간대 체류 턴 시작은 기존처럼 계획 실행 시 처리한다.
- 포인트가 부족한 시간대는 기존처럼 선택할 수 없다.
- X 버튼, 창 바깥 영역, Esc 키 또는 시계 버튼으로 창을 닫으면 첫 클릭 선택 상태를 취소한다.
- 실제 브라우저에서 첫 클릭 시 선택 유지, 두 번째 클릭 시 확정과 창 닫힘을 확인했다. 전체 회귀 검증도 통과했으며 런타임 오류는 없었다.

## 2026-08-21 공격·스킬 취소 규칙 변경

- 공격 또는 스킬 설정 중 `취소`를 누르면 편집 전 행동으로 되돌리지 않고 해당 캐릭터의 후속 행동을 완전히 취소한다.
- 이미 확정한 공격·스킬을 다시 편집하다가 취소한 경우에도 행동은 `없음`으로 바뀌며 캐릭터는 이동 후 대기한다.
- 취소 후 공격·스킬 선택 상태, 대상·방향·셀 지정과 행동 확정 상태를 모두 지우고 이동 조작으로 돌아간다.
- 이동 경로는 유지하므로 후속 행동만 다시 선택할 수 있다.
- 실제 브라우저에서 확정 행동 편집 후 취소 시 행동 설정 수가 `1/3`에서 `0/3`으로 변경되는 것을 확인했다.

## 2026-08-21 적 집중 보기 빈 타일 종료 보강

- 종료 시 캐릭터 선택을 해제하고 이동 조작으로 돌아가며 모든 캐릭터의 예정 행동을 다시 표시한다.
