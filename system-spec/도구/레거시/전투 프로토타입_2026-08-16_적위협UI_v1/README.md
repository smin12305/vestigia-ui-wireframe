# 쿼리도 슈팅 전투 개편 시스템 프로토타입

## 문서 관리 원칙

- 프로토타입 구현 및 수정 내역은 이 폴더 안의 문서에 기록한다.
- 조작법·구현 규칙·문법 변경은 `README.md`에 반영한다.
- 플레이 감각·검증 결과·추후 기획 검토 사항은 `플레이_경험_문서.md`에 반영한다.
- 간단한 적군 AI의 판단 규칙과 플레이테스트 항목은 `적군_AI_기획.md`에 반영한다.
- 화면 정보 계층·색상 범례·계획과 실행 단계의 UI 규칙은 `UI_정리_문서.md`에 반영한다.
- 별도 요청이 없다면 프로토타입 수정만으로 폴더 밖의 GDD나 기획 문서는 변경하지 않는다.

쿼리도 슈팅의 전투 개편 규칙과 핵심 전투 루프를 검증하는 9×9 브라우저 프로토타입입니다.

이 게임은 캐릭터를 하나씩 즉시 움직이는 일반적인 전술 게임이 아닙니다. 한 턴의 행동 순서·이동 경로·공격 또는 스킬을 먼저 설계하고, 과거·현재·미래 중 시간대를 선택한 뒤 잠긴 계획을 빠르게 실행하는 **턴 설계형 난투 게임**입니다.

## 실행

`전투 프로토타입 실행.bat`을 더블클릭합니다. `index.html`을 직접 열면 모듈이 실행되지 않아 빈 화면이 나타납니다.

터미널에서는 다음처럼 실행할 수 있습니다.

```powershell
npm install
npm run dev -- --host 127.0.0.1 --port 5174
```

## 한 턴의 흐름

1. 적군은 기존 중립 구역을 포함한 위쪽 빨간 6행, 아군은 아래쪽 파란 3행에 초기 배치합니다.
2. 전투 시작 시 동전 던지기로 첫 선공 진영을 정합니다.
3. 선공 진영부터 아군·적군 행동 슬롯이 교차로 생성됩니다.
4. 행동 슬롯을 선택하고 캐릭터 순서, 이동 경로, 일반 공격 또는 스킬을 설계합니다.
5. 적군 슬롯은 간단한 AI가 현재 전투판을 기준으로 자동 계획하며, 이동 경로·타겟·스킬을 플레이어에게 공개합니다.
6. 이번 턴의 시간대를 선택합니다.
7. `시간대 잠금 · 계획 실행`을 누르면 모든 행동이 번호 순서로 빠르게 실행됩니다.
8. 행동 전에 밀치기·당기기로 좌표가 바뀌면, 바뀐 위치를 새 시작점으로 삼아 그려둔 경로의 방향과 모양을 그대로 재생합니다.
9. 이동한 경로가 전투판 밖으로 나가거나 다음 셀이 점유되어 있으면 중단하고, 해당 캐릭터의 후속 공격·스킬은 취소됩니다.
10. 모든 행동 후 선공 진영을 교대하고 다음 턴을 설계합니다.

## 구현된 전투 규칙

- 상하좌우 마우스 경로, 대각선 이동 불가
- 행동 순서 `이동 → 일반 공격/스킬`
- 대상·셀·설치 방식은 거리 제한 없이 먼저 지정하며, 공격·스킬의 실제 시전 사거리는 계획한 이동 경로의 마지막 셀을 기준으로 표시·판정
- 지정점 연결선은 시전 가능 시 파란 실선, 사거리 밖이면 주황 점선으로 표시하고 경로 변경에 따라 융합/파괴 연출로 전환
- 계획이 입력된 연결선은 다른 캐릭터를 선택해도 유지하며, 현재 선택한 행동의 선만 선명하게 강조
- 범위 내 캐릭터 대상형과 상하좌우 방향형 공격
- 밀치기·당기기의 셀 단위 강제 이동과 점유 충돌
- 행동 전 강제 이동 시 계획 경로의 방향 배열을 현재 좌표에서 재생하며, 실행 대기 경로도 강제 이동한 만큼 평행 이동해 표시
- 적군 AI의 이동·일반 공격·스킬 후보 점수 계산, 도착 셀 예약, 상위 3개 후보 가중 선택
- 시간 파편은 `0/100`에서 시작하며 아군의 유효 공격 `+10`, 상태 콤보 추가 `+20`, 턴 경과 `+10`으로 충전
- 파편 획득 시 전투판에 떨어진 파편이 왼쪽 회중시계로 흡수되는 수집 연출 표시
- 시간대 전환은 파편 100을 모두 소비하며, 콤보 공격은 공격 보상까지 합쳐 총 30을 획득
- 적군 AI 슬롯 잠금과 계획 공개, 테스트용 `다시 계획` 버튼 및 선택 이유 로그
- 적 머리 위 `행동 번호 · 행동명`, 대상 옆 예상 피해·상태·강제이동 결과 칩, 우측 `적 위협` 카드로 적 행동과 결과를 한 화면에 표시
- 적 위협 카드는 현재 턴을 행동 순서대로 모의 실행해 선행 이동·피해·기절·강제이동을 반영하며, 클릭하면 해당 적 계획만 강조
- 띄워짐 대상에 대한 일반 공격 치명타
- 기절한 캐릭터의 현재 턴 행동 슬롯 패스
- 피해·치명타·상태이상·면역 결과를 대상 위에 떠오르는 글씨로 표시
- 방향형 행동의 공격선과 강제이동 결과를 분리 표시: 공격은 진영색 `공격` 선, 밀치기는 노란 굵은 화살표, 당기기는 보라 점선·꺾쇠
- 강제이동 도착 셀에는 대상 잔상과 `이동/요청 거리`를 표시하고, 점유·전투판 경계로 덜 이동하면 `충돌` 및 `✕`, 면역이면 `면역` 표시
- 대상형 연결선은 아군 계획이면 파란색, 적 AI 계획이면 빨간색과 `적 공격 대상` 라벨로 표시하며, 범위 밖은 양쪽 모두 주황 점선으로 표시
- 대상형 연결선은 계획 실행 중에도 유지한다. 현재 행동은 실제 이동 위치에서 목표까지 선명하게, 대기 행동은 흐리게 표시하고 완료·취소된 행동은 제거한다.
- 띄워짐·기절이 유지되는 동안 캐릭터 오른쪽 위에 상태 이름을 계속 표시
- 스킬 턴 단위 쿨타임
- 전투 불능 즉시 점유 해제 및 승패 판정
- 아군 유효 공격·상태 콤보·턴 경과에 따른 시간 파편 획득
- 과거: 계승자 피해 +30%, 모든 최종 피해 ×2
- 현재: 각성자 피해 +30%, 치명타 피해율 +30%p
- 미래: 기술자 피해 +30%, 실행 전 생존 캐릭터 최대 체력의 7% 회복

## 캐릭터 문법

콘텐츠 작업실에서는 진영·타입·공격 방식·상태 면역을 선택식으로 편집할 수 있습니다. `연결 스킬`도 현재 저장된 스킬 목록에서 고르면 되며, 선택 결과는 아래의 문법 원문에 자동 반영됩니다. 이름이나 수치처럼 자유 입력이 필요한 항목만 원문에서 직접 수정합니다.

```text
캐릭터: 여명검 라온
ID: raon
진영: 아군
타입: 계승자
최대체력: 34
공격력: 8
이동력: 4
치명타피해율: 150
일반공격: 검격
공격방식: 대상
공격사거리: 1
공격범위패턴: 마름모_1
스킬: shield_crash
색상: #55c7e8
상태면역: 없음
```

- 진영: `아군`, `적군`
- 타입: `계승자`, `각성자`, `기술자`
- 공격방식: `대상`, `방향`
- 공격범위패턴: `마름모_N`, `사각형_N`, `직선_N`. `사각형_1`은 자기중심 3×3 범위입니다.
- 상태면역: `없음` 또는 `밀치기, 당기기, 띄우기, 기절`
- 스킬에는 연결할 스킬의 `ID`를 적습니다.

## 스킬 문법

방식·치명타·범위 패턴·영향 셀 패턴·효과 종류·적용 범위·대상 진영은 선택식입니다. 설치 환경 ID만 직접 입력하며, 효과마다 적용 범위와 대상 진영을 따로 지정할 수 있습니다.

```text
스킬: 방패 충각
ID: shield_crash
설명: 직선의 대상을 타격하고 뒤로 밀어냅니다.
방식: 방향
사거리: 2
범위패턴: 직선_2
영향셀패턴: 직선_2
쿨타임: 2
치명타: 불가
효과: 피해 | 적용: 영향셀 | 대상: 적군 | 수치: 5
효과: 밀치기 | 적용: 영향셀 | 대상: 적군 | 거리: 2
```

- 방식: `대상`, `셀`, `설치`, `방향`
- 적용: `선택대상`, `선택셀`, `영향셀`, `자신`
- 각 효과의 대상: `아군`, `적군`, `모두`
- 치명타: `가능`, `불가`
- 효과: `피해`, `밀치기`, `당기기`, `띄우기`, `기절`, `설치`
- `영향셀` 효과는 영향 셀 패턴이 필요하며, 설치 효과에는 환경 요소 ID가 필요합니다.
- 효과는 위에서 아래 순서로 처리되며 여러 줄을 조합할 수 있습니다.
- 밀치기·당기기를 포함한 스킬은 `방식: 방향`이어야 합니다.

## 실행 확인 도구

- 우측 `전투 기록`에서 최근 사건부터 확인할 수 있습니다.
- `연출 사이 시간` 슬라이더 또는 빠른 프리셋으로 행동 사이 간격을 0~1500ms 범위에서 설정할 수 있습니다.
- 연출 간격과 저장한 캐릭터·스킬은 브라우저 로컬 저장소에 유지됩니다.

## 추가 캐릭터 검증값

- 기존 아군 라온(`raon`)과 미르(`mir`)는 출전 명단에서 제거하며, 이전 브라우저 저장 데이터에서도 자동 제외합니다. 연결되어 있던 기존 스킬은 콘텐츠 공방에서 재사용할 수 있도록 유지합니다.
- 아이작: 아군 각성자, HP 60, 공격 10, 이동 3, 기본공격 `방향/직선_1`, 어퍼컷 `방향/직선_2/피해 15/띄우기/치명타 불가`
- 안젤리카: 아군 계승자, HP 30, 공격 20, 이동 3, 기본공격 `대상/마름모_3`, 저격 `대상/마름모_4/피해 20/치명타 가능`
- 메르칸: 아군 기술자, HP 50, 공격 15, 이동 3, 기본공격 `대상/사각형_1`, 빅샷건 `방향/직선_3/2칸 밀치기/치명타 불가`
- 요청에서 지정되지 않은 이동력은 3, 스킬 쿨타임은 2턴으로 통일했습니다.
- 빅샷건은 피해 수치가 지정되지 않아 피해 효과 없이 밀치기만 적용합니다.
- 브라우저에 기존 저장 콘텐츠가 있으면 보존하고, 위 캐릭터·스킬 ID가 없을 때만 자동으로 추가합니다.

## 프로토타입 임시값

GDD에서 `[작성 필요]`인 시간 파편 수량은 시스템 검증을 위해 다음 값으로만 임시 적용했습니다.

- 전투 시작 파편: 0 / 최대 100
- 시간대 변경 비용: 100
- 아군 유효 공격: +10
- 기절·띄워짐 콤보: 추가 +20
- 턴 경과: +10

기존 프로젝트의 타입 상성 관계표는 현재 저장소 문서에 없으므로 상성 배율은 적용하지 않았습니다. 시간대별 타입 강화는 적용됩니다. 이 값과 상성은 기획 확정 후 데이터 계층에 추가할 수 있게 분리되어 있습니다.
