# 쿼리도 슈팅 전투 개편 시스템 프로토타입 — 간단한 적군 AI 기획

## 문서 상태

- 단계: 프로토타입 시험 구현 v0
- 목적: 플레이어가 적군까지 직접 조작하지 않아도 한 턴을 진행할 수 있게 한다.
- 범위: 현재 9×9 전투판, 이동·일반 공격·스킬·쿨타임·상태이상만 사용한다.
- 제외: 장기 전략, 팀 조합 학습, 플레이어 성향 학습, 완전 탐색, 실행 중 자유로운 재계획

## 구현 현황

- 이동 가능 셀과 최단 경로 후보 생성: 구현
- 일반 공격·스킬 후보 생성 및 점수 계산: 구현
- 적군 예상 도착 셀 예약: 구현
- 상위 후보 70% / 20% / 10% 가중 선택: 구현
- 적군 슬롯 자동 계획 및 사용자 편집 잠금: 구현
- 이동 경로·타겟·스킬 계획 공개: 구현
- 테스트용 다시 계획 버튼과 선택 이유 로그: 구현
- 난이도별 가중치 변경: 미구현
- 플레이어의 잠긴 계획 참조: 미구현

## 핵심 방향

적군 AI는 **현재 전투판만 보고 단순한 후보 행동을 평가**한다. 플레이어가 아직 확정하지 않은 이동 경로와 타겟은 읽지 않는다. AI가 만든 이동 경로·공격 대상·방향은 플레이어 계획 전에 공개한다.

목표는 항상 최적의 적이 아니라 다음 세 조건을 만족하는 적이다.

1. 공격할 수 있으면 공격한다.
2. 공격할 수 없다면 다음 공격이 쉬워지는 위치로 이동한다.
3. 같은 상황에서 항상 완전히 같은 행동만 반복하지 않는다.

## 한 턴의 흐름

1. 행동 슬롯과 선공 진영을 결정한다.
2. 적군 AI가 적군 슬롯을 행동 순서대로 하나씩 계획한다.
3. 이미 계획한 적군의 예상 도착 셀을 예약해 적끼리 같은 셀을 선택하지 않게 한다.
4. 적 이동 경로·후속 행동·타겟·방향을 전투판에 표시한다.
5. 플레이어가 공개된 적 계획을 보고 아군 계획을 작성한다.
6. 모든 계획을 잠그고 기존 행동 순서대로 실행한다.
7. 실행 중 밀치기·당기기를 받으면 현재 프로토타입 규칙대로 이동 경로의 방향 배열을 새 좌표에서 재생한다.
8. 타겟이 전투 불능이거나 실행 시 사거리 밖이면 자동 재타겟팅 없이 행동을 취소한다.

## 행동 후보 생성

각 적 캐릭터는 다음 후보를 만든다.

- 이동하지 않고 일반 공격
- 이동 후 일반 공격
- 이동하지 않고 스킬
- 이동 후 스킬
- 공격할 수 없을 때 가장 가까운 아군에게 접근
- 유효한 행동이 없을 때 대기

이동 후보는 이동력 안에서 도달 가능한 셀을 탐색한다. 다른 캐릭터의 현재 셀과 앞서 예약한 적군 도착 셀은 이동 종료 후보에서 제외한다. 프로토타입 v0에서는 각 도착 셀까지의 최단 경로 하나만 사용한다.

## 후보 점수

| 조건 | 점수 |
|---|---:|
| 공격 또는 피해 스킬이 실제로 적중 가능 | +30 |
| 해당 공격으로 아군을 전투 불능으로 만들 수 있음 | +45 |
| 기절이 아직 행동하지 않은 아군에게 적용됨 | +35 |
| 띄우기로 후속 적군의 치명타 조건을 만들 수 있음 | +25 |
| 밀치기·당기기로 아군의 계획 경로 또는 시전 연결을 깨뜨릴 가능성이 있음 | +20 |
| 스킬 사용 후 두 명 이상에게 효과 적용 | 대상 한 명당 +15 |
| 일반 공격 가능 위치 | +10 |
| 가장 가까운 아군과의 거리가 1칸 감소 | +3 |
| 체력이 가장 낮은 아군을 유효하게 공격 | +5 |
| 다른 적군의 예약 도착 셀 또는 현재 점유 셀과 충돌 | -1000 |
| 이동 경로가 전투판 밖으로 이탈 | -1000 |
| 실행 시점에 이미 사거리 밖일 것으로 확정되는 행동 | -1000 |

점수는 초안이며 플레이테스트 후 조정한다. 특히 전투 불능·기절 점수가 지나치게 높으면 한 캐릭터만 집중 공격하는 지배 행동이 생길 수 있다.

## 행동 선택

완전히 결정적인 AI가 되지 않도록 상위 후보 중 하나를 선택한다.

- 1위 후보: 70%
- 2위 후보: 20%
- 3위 후보: 10%

단, 점수가 0 이하인 공격 후보는 제외하고 접근 또는 대기를 선택한다. 난수 결과와 선택 이유는 전투 로그에 기록해 디버깅할 수 있게 한다.

## 스킬 사용 규칙

- 쿨타임이 0인 스킬만 후보로 생성한다.
- 피해만 주는 스킬은 일반 공격보다 예상 가치가 높을 때 우선한다.
- 기절은 아직 이번 턴에 행동하지 않은 아군을 우선한다.
- 띄우기는 뒤에 행동할 적군이 해당 대상을 공격할 수 있을 때 우선한다.
- 밀치기·당기기는 대상의 경로 또는 시전 가능 상태를 바꿀 때 가점을 준다.
- 효과를 적용할 수 없는 면역 대상에게 상태이상 스킬을 사용하지 않는다.
- 스킬이 실행되지 않으면 기존 규칙대로 쿨타임을 발생시키지 않는다.

## 타겟 선택 규칙

기본 우선순위는 다음과 같다.

1. 이번 공격으로 전투 불능이 되는 아군
2. 아직 행동하지 않았고 기절시킬 수 있는 아군
3. 후속 적군과 상태 콤보가 가능한 아군
4. 현재 유효 사거리 안의 체력이 낮은 아군
5. 가장 가까운 아군

같은 우선순위라면 이동 거리가 짧은 후보를 우선하고, 그래도 같으면 난수로 선택한다.

## 플레이어에게 보여줄 정보

- 적군 이동 경로: 흐린 빨간 선
- 적군 예상 도착 셀: 빨간 테두리
- 캐릭터 타겟: 현재 연결선 규칙으로 표시
- 방향 공격: 방향 화살표와 영향 셀 표시
- 스킬 사용: 행동 슬롯에 스킬 이름 표시
- 행동 취소 예상: 주황 점선과 `사거리 밖` 표시
- AI 디버그 선택 사항: 후보 점수와 선택 이유를 로그에 표시

AI가 계획을 끝낸 뒤에는 플레이어 계획 중 임의로 계획을 바꾸지 않는다. 실행 시에는 생존 여부·현재 위치·점유·사거리만 다시 검사한다.

## 난이도 확장용 조절값

| 난이도 | 후보 선택 | 스킬 판단 | 플레이어 계획 참조 |
|---|---|---|---|
| 쉬움 | 상위 3개 중 균등 선택 | 상태 콤보 가점 없음 | 참조하지 않음 |
| 보통 | 70% / 20% / 10% | 상태 콤보 사용 | 참조하지 않음 |
| 어려움 | 대부분 1위 선택 | 경로 방해와 상태 콤보 적극 사용 | 잠긴 계획만 제한적으로 참조하는 방안 추후 검토 |

프로토타입 v0는 `보통`만 구현 대상으로 삼는다.

## 예상 플레이 경험 리스크

- 적 계획이 전부 공개되어 안전한 정답 행동이 반복될 수 있다.
- 전투 불능 점수가 높으면 모든 적이 체력이 낮은 한 캐릭터만 집중 공격할 수 있다.
- 이동 거리가 짧은 후보를 과도하게 선호하면 원거리 캐릭터가 제자리 공격만 반복할 수 있다.
- 밀치기·기절 점수가 높으면 행동 봉쇄가 지나치게 자주 발생할 수 있다.
- 상위 후보 난수가 전술적 실수보다 무작위 행동처럼 보일 수 있다.
- 적군 도착 셀만 예약하면 실행 중 밀치기로 경로가 변형될 때 적끼리 충돌할 수 있다. 이 충돌은 허용하되 자동 재계획하지 않는다.

## 우선 플레이테스트

1. AI가 3턴 이상 공격하지 못하고 접근만 반복하는 상황이 있는지 확인한다.
2. 동일한 아군에게 적 공격이 과도하게 집중되는지 확인한다.
3. 공개된 적 계획을 보고 항상 피해 없이 해결할 수 있는 정답이 생기는지 확인한다.
4. 기절·밀치기 AI가 플레이어 행동을 지나치게 자주 취소시키는지 확인한다.
5. 적의 선택 이유를 로그 없이도 이동 경로와 타겟 표시만 보고 이해할 수 있는지 확인한다.
6. 상위 후보 난수가 불합리한 실수로 보이는지, 적당한 변주로 느껴지는지 확인한다.

## 구현 우선순위

1. 이동 가능 셀과 최단 경로 후보 생성
2. 일반 공격 가능한 후보와 점수 계산
3. 적군 도착 셀 예약 및 충돌 방지
4. 적 계획 자동 입력과 전투판 예고
5. 스킬·상태이상 점수 계산
6. 상위 후보 가중치 선택
7. AI 디버그 로그
