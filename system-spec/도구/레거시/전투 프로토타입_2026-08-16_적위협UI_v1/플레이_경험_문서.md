# 쿼리도 슈팅 전투 개편 시스템 프로토타입 플레이 경험 문서

## 문서 목적

전투 프로토타입을 직접 조작하면서 확인한 플레이 감각과 이후 기획에서 검토할 사항을 기록한다. 아래 내용은 확정 규칙이 아니라 다음 프로토타입 및 적 AI 설계를 위한 우선 검토안이다.

## 1. 타겟팅 스킬의 대상 지정과 실행 조건

### 현재 느낀 문제

타겟팅 스킬의 대상 선택을 현재 사거리 안으로만 제한하면, 이동 후 위치와 실행 시점의 변화를 미리 설계하는 재미보다 입력 단계의 제약이 먼저 느껴질 수 있다. 턴 설계 단계에서는 이후 위치 변화를 예상해 먼 대상을 미리 지정할 수 있는 편이 자연스럽다.

### 권장 기획안

- 대상·셀·설치 방식은 행동 설계 단계에서 거리 제한 없이 전장의 캐릭터 또는 타일을 지정할 수 있다.
- 여기서 무제한인 것은 **대상 지정 범위**이며, 스킬의 실제 **효과 사거리**가 사라지는 것은 아니다.
- 행동 실행 시 캐릭터의 이동이 끝난 위치를 기준으로 실제 스킬 사거리를 다시 판정한다.
- 지정 대상이 실행 시점에 유효 사거리 안에 있으면 스킬을 정상 실행한다.
- 지정 대상이 사거리 밖이거나 전투 불능이면 스킬을 취소한다.
- 취소된 스킬은 다른 대상으로 자동 재타겟팅하지 않는다.
- 실행되지 않은 스킬에는 쿨타임을 적용하지 않는 방향을 유지한다.

### 필요한 UI 피드백

- 사거리 밖 대상도 선택할 수 있게 하되, 현재 계획 기준으로 `실행 가능`과 `사거리 밖 · 실행 취소 예상`을 명확히 구분한다.
- 이동 경로를 수정하면 이동 완료 위치를 기준으로 대상의 예상 사거리 판정을 즉시 다시 계산한다.
- 대상과 이동 경로 사이의 관계를 선 또는 표식으로 표시해, 어느 위치까지 이동해야 실행되는지 이해할 수 있게 한다.
- 이동 완료 예정 위치와 지정 대상은 현재 시전 사거리 안이면 **파란 실선**, 밖이면 **주황 점선**으로 연결한다.
- 경로 수정으로 `범위 안 → 범위 밖`이 되면 연결이 파편처럼 깨지는 연출을, `범위 밖 → 범위 안`이 되면 조각이 모여 선으로 융합되는 연출을 보여준다.
- 색상만으로 판정을 전달하지 않도록 연결선 중앙에 `시전 가능` 또는 `사거리 밖` 문구를 함께 표시한다.
- 실제 실행 시 사거리 밖으로 취소되면 대상 위 글씨와 전투 로그로 실패 원인을 보여준다.

## 2. 경로 계획 후 밀치기 처리 플레이테스트

### 확인이 필요한 상황

캐릭터가 이동 경로를 이미 계획한 상태에서, 자신의 행동 순서가 오기 전에 다른 행동의 밀치기 효과로 원래 위치에서 벗어날 수 있다. 이때 저장된 경로는 최초 위치를 기준으로 작성되어 있으므로 실제 위치와 경로 시작점이 어긋난다.

현재 프로토타입에는 비교 후보 중 `방향 명령 유지 방식`을 적용한다. 이는 최종 규칙 확정이 아니라 플레이 감각을 확인하기 위한 시험 구현이다.

### 현재 시험 구현

- 최초 경로를 셀 좌표가 아니라 상·하·좌·우 이동 방향의 순서로 해석한다.
- 행동 전에 밀치기·당기기로 좌표가 바뀌면 실제 위치를 새 시작점으로 삼는다.
- 새 시작점에서 기존 경로의 방향과 모양을 그대로 재생한다.
- 실행을 기다리는 경로는 강제 이동한 거리와 방향만큼 평행 이동해 표시한다.
- 평행 이동한 경로가 전투판 밖으로 나가거나 점유 셀과 충돌하면 해당 지점에서 중단한다.
- 현재 프로토타입의 기존 충돌 규칙에 따라 경로가 중단되면 후속 공격·스킬도 취소한다.

### 플레이테스트 비교 항목

- 밀쳐진 실제 위치에서 기존 경로의 다음 셀로 이동을 이어갈 수 있는지
- 기존 경로의 시작점이 달라졌으므로 이동 전체를 취소할지
- 밀쳐진 위치와 기존 경로가 인접하지 않을 때만 이동을 취소할지
- 기존 목적지는 유지하고 밀쳐진 위치에서 목적지까지 경로를 다시 계산할지
- 경로가 무효가 되어 이동을 취소하더라도 후속 공격·스킬은 실행할지
- 이동 취소와 후속 행동 취소를 각각 어떤 표식, 전투 글씨, 로그로 전달할지
- 밀치기를 이용해 상대 경로를 의도적으로 끊는 플레이가 재미있는 방해 수단인지, 지나치게 강한 행동 봉쇄인지
- 아군을 밀쳐 경로를 단축하거나 우회시키는 활용을 허용할 경우 의도하지 않은 최적화가 생기는지

### 현재 상태

- `방향 명령 유지 방식`을 프로토타입에 적용했지만 처리 규칙은 아직 확정하지 않는다.
- 경로 평행 이동의 이해도, 예측 가능성, 전략적 활용도와 후속 행동까지 취소되는 페널티를 플레이테스트한 뒤 결정한다.

## 3. 난이도와 적 AI 검토 필요

현재 프로토타입에는 `적군_AI_기획.md`의 예고형 간단 AI v0가 시험 구현되어 있다. 아래 항목은 구현된 AI를 실제로 조작하며 검증할 위험 목록으로 유지한다.

### 우려 사항

현재처럼 양 진영을 플레이어가 직접 조작하는 프로토타입에서는 최적의 이동과 공격 순서를 쉽게 만들 수 있다. 향후 적 AI가 단순하게 행동하면 플레이어가 적의 이동과 타겟을 과도하게 쉽게 예측하고 조작할 수 있어 전투 난도가 지나치게 낮아질 가능성이 있다.

특히 타겟팅 스킬의 대상을 거리 제한 없이 미리 지정할 수 있게 되면 플레이어의 계획 자유도는 높아지지만, 적이 이를 방해하거나 대응하지 못할 경우 안전한 정답 행동이 반복될 수 있다.

### 적 AI에서 검토할 항목

- 플레이어의 예정 이동 경로와 타겟팅 계획을 어느 수준까지 인식할지
- 공격 가능 위치 진입뿐 아니라 사거리 이탈, 길막, 충돌 유도 등 방해 행동을 평가할지
- 기절·띄워짐·밀치기·당기기의 위험도를 행동 순서와 함께 계산할지
- 체력이 낮은 대상만 반복 추적하지 않도록 위치 가치와 상태이상 가치를 함께 평가할지
- 항상 최적 행동을 선택하지 않고 난이도별 판단 오차나 후보 행동 가중치를 둘지
- 적 행동 예고를 유지하면서도 플레이어가 단일 정답을 쉽게 만들지 못하게 할 방법
- 플레이어가 적 계획을 변경시키거나 역이용했을 때 실행 중 재계산을 어디까지 허용할지

## 4. 다음 플레이테스트 확인 항목

1. 사거리 밖 대상을 미리 지정하는 조작이 턴 설계의 자유도를 실제로 높이는가.
2. 이동 경로 변경에 따른 `실행 가능/취소 예상` 표시를 한눈에 이해할 수 있는가.
3. 사거리 미충족으로 스킬이 취소됐을 때 플레이어가 원인을 명확히 이해하는가.
4. 단순 적 AI를 상대로 안전한 정답 루프가 반복되는가.
5. 적 AI가 위치 방해와 상태이상 위험을 고려할 때 난도가 불합리하게 상승하지 않는가.
6. 계획 경로 작성 후 밀쳐졌을 때 각 후보 처리 방식이 예측 가능하고 납득 가능한가.
7. 밀치기로 경로를 끊는 플레이가 전략적 방해로 느껴지는가, 행동을 과도하게 무력화하는가.

## 현재 결론

대상·셀·설치 타겟팅은 **지정은 거리 제한 없이 허용하고, 실제 실행은 이동 완료 위치 기준 유효 사거리 안에 있을 때만 성공**하는 구조가 현재 턴 설계형 전투에 더 어울린다. 다만 이 자유도가 전투를 과하게 쉽게 만들 수 있으므로, 적 AI의 위치 대응·방해·상태이상 위험 평가를 함께 설계하고 플레이테스트해야 한다.

## 시간 파편 100 충전안

- 시간 파편은 0에서 시작해 최대 100까지 충전한다.
- 아군이 적에게 유효한 공격을 성공시키면 10을 얻는다. 여러 대상을 맞혀도 한 행동당 1회만 계산한다.
- 공격 대상이 공격 직전 `기절` 또는 `띄워짐` 상태라면 콤보 보상 20을 추가해 총 30을 얻는다.
- 한 턴의 모든 행동이 끝나면 10을 얻는다.
- 시간대 전환은 완충된 파편 100을 소비한다.
- 획득 위치에서 파편이 낙하한 뒤 회중시계로 흡수되는 연출로 보상의 발생 원인과 충전 목적지를 연결한다. 턴 경과 보상은 전투판 상단 중앙에서 발생한다.
- 플레이테스트에서는 100까지 걸리는 평균 턴 수, 콤보 위주의 충전 속도, 전투 종료 전 시간대 전환을 실제로 몇 번 사용하는지 확인한다.

## 기본공격 범위 패턴 검증

- 캐릭터 문법에 `공격범위패턴`을 추가하고 스킬과 같은 패턴 판정 함수를 사용한다.
- `마름모_N`은 맨해튼 거리 N, `직선_N`은 상하좌우 같은 행·열 N칸, `사각형_N`은 가로·세로 각각 N칸인 자기중심 정사각형으로 판정한다.
- 따라서 `사각형_1`은 자기중심 3×3이며, 선택 단계는 기존 규칙대로 거리 제한 없이 대상을 지정하되 실행 시 해당 패턴 안인지 확인한다.
- 아이작·안젤리카·메르칸의 서로 다른 기본공격 패턴을 통해 범위 모양의 이해도와 지배적인 패턴이 생기는지 확인한다.

## 강제이동 예고 UI

- 방향형 공격의 사거리와 강제이동 결과를 하나의 화살표로 표현하지 않는다.
- 공격 범위는 시전자에서 시작하는 진영색 선과 `공격` 라벨로 표시한다.
- 밀치기는 대상에서 도착점으로 향하는 노란 굵은 실선·단일 화살촉으로 표시한다.
- 당기기는 대상에서 시전자 방향으로 향하는 보라 점선·반복 꺾쇠로 표시한다.
- 도착점에는 대상 글자를 넣은 반투명 잔상을 표시하고 `밀치기 2/2`, `당기기 1/2 · 충돌`처럼 실제 이동 가능 거리와 요청 거리를 함께 적는다.
- 전투판 경계나 점유 셀에 막히면 진행 방향 끝에 `✕`, 강제이동 면역이면 대상 위치에 원형 테두리와 `면역`을 표시한다.
- 선택한 행동은 완전한 불투명도, 다른 계획은 낮은 불투명도로 유지해 전체 계획과 현재 편집 대상을 함께 읽게 한다.
- 적 AI의 대상형 연결선은 사거리 안일 때 빨간 실선·빨간 대상 링·`적 공격 대상` 라벨을 사용한다. 아군의 파란 실행 가능 연결선과 혼동하지 않게 한다.
- 실행 단계에서도 대상 연결선을 유지한다. 현재 슬롯은 캐릭터의 실제 이동 위치를 선의 시작점으로 사용해 이동 중 사거리 변화를 갱신하고, 미래 슬롯은 강제이동으로 바뀐 현재 위치에 계획 경로를 평행 이동한 예상 종점을 사용한다. 완료·충돌·취소된 슬롯은 연결선을 제거한다.

## 적 위협 결과 예고 플레이테스트

- 적 계획을 단순히 선으로만 보여주지 않고 `누가 · 몇 번에 · 어떤 스킬로 · 누구에게 · 무슨 결과를 주는지`를 우측 카드와 전투판 결과 칩으로 함께 표시한다.
- 예상 피해와 상태이상은 현재 턴 전체 계획을 순서대로 모의 실행해 계산하므로, 선행 밀치기로 사거리에서 벗어나거나 선행 기절로 적 행동이 취소되는 변화도 표시한다.
- 위협 카드를 클릭하면 해당 적 계획만 강조해 겹친 선을 해석하는 부담을 줄인다.
- 플레이테스트에서는 카드를 읽은 뒤 실제 실행 결과를 맞힐 수 있는지, 카드가 너무 자세해 정답을 대신 제시하는지, 계획 변경 후 갱신을 알아차리는지 확인한다.
- 특히 여러 적이 같은 아군을 노릴 때 개별 피해뿐 아니라 누적 전투불능 위험이 한눈에 읽히는지 확인한다. 현재는 행동별 결과만 제공하므로 필요하면 후속 버전에서 아군별 `턴 종료 예상 HP` 요약을 비교한다.
