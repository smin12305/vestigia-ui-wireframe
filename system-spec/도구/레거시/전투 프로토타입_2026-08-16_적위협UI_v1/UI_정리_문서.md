# 전투 프로토타입 UI 정리 문서

## 목적

누적된 기능을 모두 같은 강도로 노출하지 않고, 플레이어가 현재 해야 할 일과 전투 결과를 먼저 읽도록 화면 계층을 통일한다. 전투 규칙은 바꾸지 않으며 표시와 조작 구조만 정리한다.

## 화면 우선순위

1. 전투판의 현재 위치, 이동 경로, 공격 대상과 강제이동 결과
2. 행동 순서와 현재 계획·실행 슬롯
3. 선택 캐릭터와 행동 입력
4. 시간 파편과 시간대 선택
5. 전투 로그, 연출 속도, AI 재계획 같은 검증 도구

## 전체 화면 구조

- 상단 헤더: 게임명, 현재 단계·턴, 콘텐츠 공방만 표시한다.
- 행동 순서: 높이를 줄인 가로 슬롯으로 유지한다. 계획 중 선택 슬롯과 실행 중 현재 슬롯을 동시에 강조하지 않는다.
- 중앙: 전투판을 가장 큰 면적으로 유지하고 위에는 범례·표시 필터, 아래에는 현재 상태 한 줄만 둔다.
- 왼쪽: 시간 파편, 시간대 선택, 파편 획득 규칙, AI 재계획을 배치한다.
- 오른쪽 계획 단계: 선택 캐릭터, 현재 계획 요약, 행동 입력, 실행 버튼, 로그 순서로 배치한다.
- 오른쪽 실행 단계: 편집 버튼을 숨기고 현재 행동 캐릭터·행동·결과와 로그만 표시한다.
- 콘텐츠 공방: 전투 화면과 분리된 모달을 유지한다.

## 전투판 표시 의미

| 표시 | 의미 |
|---|---|
| 파란 선 | 아군 이동 경로 또는 실행 가능한 아군 대상 연결 |
| 빨간 선 | 적 이동 경로, 공격 범위 또는 적 대상 연결 |
| 주황 점선 | 실행 시점 기준 범위 밖 |
| 노란 굵은 화살표 | 밀치기 방향과 도착점 |
| 보라 점선·꺾쇠 | 당기기 방향과 도착점 |
| 반투명 캐릭터 글자 | 강제이동 후 예상 도착 셀 |
| `✕`, `충돌` | 점유 셀이나 전투판 경계로 요청 거리만큼 이동하지 못함 |
| 원형 테두리와 `면역` | 강제이동이 적용되지 않음 |

색만으로 구분하지 않는다. 공격에는 `공격`, 적 연결에는 `적 공격 대상`, 강제이동에는 종류와 `실제/요청 거리`를 글자로 함께 표시한다.

## 계획선 표시 필터

- 기본값은 `보기 · 모든 계획`이다. 다른 캐릭터를 선택해도 기존 계획선이 유지된다.
- `보기 · 현재 행동`을 누르면 선택 중인 슬롯만 남겨 복잡한 겹침을 잠시 제거한다.
- 실행 단계에서는 현재 실행 슬롯만 선명하고 미래 슬롯은 흐리다.
- 완료·충돌·취소된 슬롯의 연결선은 제거한다.

## 행동 순서 상태

- 선택: 금색 테두리
- 실행 중: 금색 발광
- 완료·기절: 낮은 불투명도
- 충돌·취소: 주황 테두리와 결과 글자
- 적 AI 슬롯: 어두운 적색 바탕과 `AI` 표시

## 우측 패널 상태 전환

### 계획

- 캐릭터 정보 → 이동·후속 행동 요약 → 행동 버튼 → 맥락 안내 → 초기화·실행 순서다.
- 대상형은 무제한으로 지정할 수 있다는 안내와 실행 가능 여부를 함께 표시한다.
- 방향형은 노란 밀치기와 보라 당기기 표시를 안내한다.
- 실행 버튼 아래 `적 위협` 카드를 항상 노출한다. 카드 한 장은 `행동 번호 · 적 이름 · 스킬명 · 대상 · 예상 결과`를 한 묶음으로 표시한다.
- 위협 카드를 누르면 해당 적 행동의 이동 경로, 공격선, 대상 결과 칩만 선명하게 남긴다. 다시 전체 계획 보기로 돌아갈 수 있다.

## 적 행동·결과 예고

- 적 머리 위에는 `행동 번호 · 행동명`을 붙여 전투판과 행동 순서를 연결한다.
- 실제 대상 옆에는 `행동 번호 피해량 · 상태이상 · 밀치기/당기기 실제 거리` 결과 칩을 표시한다.
- 우측 위협 카드는 `적중 예상`, `취소 예상`, `대상 없음`, `이동·대기`를 색과 글자로 함께 구분한다.
- 예상 결과는 현재 계획 전체를 행동 번호 순서로 모의 실행한 값이다. 선행 행동의 이동, 피해, 전투불능, 기절, 밀치기·당기기로 달라진 좌표를 후속 행동에 반영한다.
- 경로 충돌, 시전자 기절·전투불능, 시전 시점 사거리 밖은 피해 수치 대신 취소 이유를 표시한다.
- 이 표시는 확정 결과가 아니다. 플레이어가 경로나 행동을 바꾸면 즉시 다시 계산되며, 확률 요소나 이후 추가될 환경 규칙이 있다면 `예상`이라는 표현을 유지한다.

### 실행

- 계획 편집 버튼과 방향 입력을 숨긴다.
- 현재 슬롯 번호, 진영, 캐릭터, 행동 종류, 대상·방향, 처리 결과만 표시한다.
- 하단 상태 줄도 `N번 실행 · 캐릭터 · 행동`으로 바뀐다.

## 보조 도구

- 전투 로그는 오른쪽에 항상 노출하고 최신 기록을 강조한다.
- 연출 속도는 접힌 패널에 넣어 필요할 때만 펼친다.
- AI 다시 계획은 왼쪽 하단의 작은 검증 도구로 유지한다.
- 시간 파편 획득량은 긴 설명 대신 `+10 공격`, `+20 콤보`, `+10 턴` 세 칸으로 표시한다.

## 반응형 기준

- 넓은 화면: 시간대 / 전투판 / 명령의 3열.
- 중간 화면: 시간대와 전투판 2열, 명령 패널은 아래 전체 폭.
- 작은 화면: 전투판 → 시간대 → 명령 순서의 1열.
- 모바일에서도 전투판 범례와 표시 필터를 먼저 유지하며, 로그 높이를 제한한다.

## 구현 확인

- TypeScript와 Vite 프로덕션 빌드를 통과해야 한다.
- 캔버스 표시 변경은 계획·실행 단계에서 각각 확인한다.
- 로컬 주소에 대한 자동 브라우저 캡처가 허용되지 않는 환경에서는 빌드와 코드 경로만 검증한 것으로 명시하고, 실제 화면은 수동 플레이테스트로 확인한다.
