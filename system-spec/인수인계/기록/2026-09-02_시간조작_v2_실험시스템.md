# 시간 조작 v2 실험 시스템 구현·문서화

> 기록일: 2026-09-02 (Asia/Seoul)
> 기준 브랜치: `main`
> 작업 성격: 독립 프로토타입 구현·실험 시스템 문서화·GitHub 업로드
> 결정 상태: `[제안]` 실험본

## 목표

시간대 영향력이 낮고 파편 사용 유인이 부족하다는 기존 QA를 바탕으로, 시간 억제 대신 시간 가속·정지·역행을 직접 선택하는 v2 실험본을 만들고 구현 규칙을 별도 문서로 보존한다.

## 사용자 결정

- v2 실험본을 기존 프로토타입과 분리한다.
- 최대 시간 파편은 80으로 둔다.
- 시간 억제를 제거한다.
- 전투 HUD에는 시계와 파편량만 표시한다.
- 시계 클릭 시 배경을 어둡게 하고 중앙에 확대 시계를 표시한다.
- 시간 가속·정지·역행 선택 시 가상 시침으로 결과를 미리 보여준다.
- 확정을 누르는 순간 실제 시간을 변경한다.
- 조작 선택 시 가벼운 흔들림, 확정 시 마법 오라를 사용한다.
- 구현 내용을 `실험 시스템` 폴더에 문서화해 업로드한다.

## 구현 결과

- 구현 위치: `도구/전투 프로토타입/실험버전/v2/`
- 시간 파편: 시작 0, 최대 80, 유효 공격 +20, 콤보 추가 +30, 턴 종료 +10
- 조작 비용: 최초 50, 확정할 때마다 다음 비용 +5
- 사용 제한: 계획 단계, 한 턴 한 번, 비용과 보유 파편 조건 충족 시 사용
- 가속: 확정 즉시 시침 한 칸 전진
- 정지: 현재 시침 유지 및 해당 턴 종료의 자동 진행 차단
- 역행: 확정 즉시 시침 한 칸 후진
- UI: 시계·파편량 축소 HUD, 전체 딤, 중앙 확대 시계, 가상 시침과 도착 시간대, 조작 버튼과 확정
- 연출: 선택 흔들림, 확정 마법 오라, 동작 감소 환경 대응
- 배포: `standalone/index.html` 생성

## 문서화 결과

- `제안/실험 시스템/Waredo_2.0_시간_조작_v2_실험_시스템.md`를 생성했다.
- 실제 구현 규칙, UI, 연출, 제외 기능, 현재 한계와 실험 판정 기준을 기록했다.
- `확정/Waredo_2.0_전체_기획_관리.md`에 실험 문서의 상태와 경로를 추가했다.

## 주의사항

- v2는 기존 프로토타입과 확정 기획에 적용되지 않은 `[제안]` 실험본이다.
- 문서 관리 및 검수 규칙도 현재 `[제안]` 상태다.
- 같은 저장소의 v3 전투 시스템 실험본은 이번 작업에서 수정하지 않았다.
