# 2026-09-06 캐릭터·전투 규칙 문서 개편

## 목표

전투 프로토타입의 상대 타일 지정과 시간대 궁극기 교체 구조를 참고해 캐릭터·전투 확정 문서를 최신 사용자 결정에 맞추고 전체 기획 관리 문서를 함께 갱신한다.

## 사용자 결정

- 일반 공격은 방향성, 자기 기준, 타일 선택 세 종류를 사용하고 스킬은 자가 버프형을 추가로 허용한다.
- 방향성은 상·하·좌·우 중 한 방향을 고른다.
- 자기 기준 공격은 실행 시점의 자신을 중심으로 정해진 범위에 피해를 준다.
- 타일 선택은 절대 좌표가 아니라 시전자 기준 방향과 거리를 기억하며, 시전자가 이동하면 목표 위치도 함께 이동한다.
- 캐릭터는 일반 스킬과 궁극기를 한 쌍으로 보유한다. 자신의 시간대 태그와 현재 시간대가 일치하면 일반 스킬이 궁극기로 교체되며 쿨타임은 유지된다.
- 기존 타입 상성과 시간대 태그 상성은 사용하지 않는다. 아군 시간대 태그는 과거 또는 미래다.
- 전투판 규격은 `6×6`으로 확정하고 양 축 좌표 범위는 `0~5`로 사용한다.
- `12. 아웃게임·대화 시나리오 시스템`은 별도 신규 기획 없이 `[기존 유지]`로 관리한다.
- 시간대 전환 시스템을 사용한다. 게임 시작 시간대는 현재다.
- 시간 파편은 현재에서만 수집하며 적 일반 공격 +10, 적 치명타 공격 +30, 사살 +30, 턴 종료 +10을 얻고 100까지만 저장한다. 프로토타입 기준 과거·미래 이동 시 100을 소모한다.
- 파편이 100이면 계획 단계에서 과거 또는 미래 버튼을 누르는 즉시 배경과 시간대 상태를 바꾼다. 과거는 아군 이동력 +1, 미래는 아군 일반 공격력 +3이며 2턴 뒤 현재로 복귀한다.
- 캐릭터 `timeTag`는 과거 또는 미래만 허용한다. 유물은 같은 공통 태그 체계의 `relicTimeTags`로 과거·현재·미래 조건을 사용한다. 태그 상성은 없다.
- 스킬은 자가 버프형을 추가로 사용할 수 있다. 자가 버프형은 시전자 자신에게 효과를 적용한다.
- 반격은 자가 버프로 상태를 얻은 뒤 적이 반격 범위 안의 타일을 점유하거나 범위 안에서 행동할 때 반응한다. 일반·강제 이동 모두 셀 점유 순간을 판정한다.

## 반영 결과

- 캐릭터 시스템의 기존 `characterType`, `typeMatchupTable`, `typeMatchupMultiplier`와 상성 계산·표를 제거했다.
- 아군의 `timeTag`, `characterSkillId`, `characterUltimateSkillId`, 파생 `activeSkillId`와 공유 `cooldownRemaining` 계약을 추가했다.
- 타일 선택 계획은 `relativeTargetOffset = (targetX - originX, targetY - originY)`을 저장하고 실행 시점 위치에 더하도록 정의했다.
- 전투 플랜과 일반 공격·스킬 실행 규칙에서 직접 대상 ID 및 절대 타일 좌표 저장을 제거했다.
- 전체 기획 관리의 시스템 구조, 단일 원본, 캐릭터·시간대 콘텐츠 항목을 갱신했다.
- 전체 기획 관리의 `12. 아웃게임·대화 시나리오 시스템` 상태를 `[작성 전]`에서 `[기존 유지]`로 변경했으며, 별도 신규 문서는 생성하지 않았다.
- 캐릭터 시스템에 `SelfBuff`와 `Counter` 효과 문법을 추가했다.
- 전투 시스템에 반격 상태·3×3 기본 범위·피해 후 대상 제외·다중 반격 무작위 순서·일반 공격 피해 1건·선택적 기절·기절/전투불능 시 행동 취소를 정의한 반격 모듈을 추가했다. 반격 피해만으로는 남은 행동을 취소하지 않는다.
- 시간대 전환 단일 원본을 `확정/시스템/Waredo_2.0_시간대_전환_시스템_기획서.md`로 작성했다. 작성 프롬프트의 구조에 맞춰 시간대 상태, 파편 원천·상한, 계획 단계 즉시 전환, 2턴 체류, 시간대 버프, 캐릭터·유물 공통 태그 연결을 정리했다.
- 전체 기획 관리의 `6. 시간대 전환 시스템`을 `[제안]`에서 `[확정]`으로 갱신하고 새 단일 원본 경로를 등록했다.
- 활성 프로토타입 v3에서 적 일반 공격·치명타 공격·사살·턴 종료 파편 보상, 미래 일반 공격력 +3, 즉시 전환 버튼, 유물 `relicTimeTags` 조건을 반영했다. 기존 아군 공격·콤보·유물 시간포인트 파편 지급은 제거했다.
