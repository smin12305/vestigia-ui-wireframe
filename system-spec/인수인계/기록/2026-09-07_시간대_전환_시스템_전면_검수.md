# 시간대 전환 시스템 전면 검수

- 검수일: 2026-09-07
- 검수 대상: 시간대 전환 확정 기획서, 연결된 캐릭터·전투·전체 기획 관리 문서, 전투 프로토타입 안내 문서와 활성 실험 버전 v3
- 판정: **FAIL**
- 심각도 집계: 높음 6건, 중간 6건, 낮음 1건
- 적용한 검수 규칙: `제안/문서관리/Waredo_2.0_문서_관리_및_검수_규칙.md`의 `[제안]` 기준을 참고함

## 핵심 결과

### 높음

1. 시간 전환 상위 흐름에서 `timePeriodChanged`를 발행한 뒤 `timeStayRemainingTurns = 2`를 설정하도록 읽혀, 구독자가 불완전한 상태를 볼 수 있다.
2. 상태 흐름도가 현재 시간대의 턴 종료도 `남은 체류 1턴`으로 연결해 상세 규칙과 충돌한다.
3. 활성 프로토타입 v3의 유물이 여전히 `relicTimeTags`를 직접 보유하고 해당 태그로 효과를 필터링한다.
4. 프로토타입 루트 README가 자동 시간 순환, 과거 규칙 수치, 양 진영 버프 등 폐기된 규칙을 현재 안내처럼 설명한다.
5. v3는 구형 시간 이벤트 payload를 유지하고 실제 시간대가 바뀌지 않은 첫 체류 턴에도 `time-advance`를 발행한다.
6. 캐릭터 확정 문서 일부가 시간대 치명타 보정을 참조해, 같은 문서의 `시간대 치명타 없음` 규칙과 충돌한다.

### 중간

1. 시간대 전환 문서 일부가 payload 없는 `timePeriodChanged`와 달리 변경 시간·남은 턴 전달 또는 별도 복귀 이벤트를 암시한다.
2. `timeShard`의 전투 시작 초기값과 새 전투·재시작 시 초기화 범위가 명시되지 않았다.
3. 여러 대상을 동시에 공격할 때 일부만 치명타인 경우 +10/+30 판정 기준이 없다.
4. 대상이 없거나 피해가 0인 적 일반 공격도 파편을 주는지 정의되지 않았으며 v3는 행동만 실행하면 지급할 수 있다.
5. 현재 자동 검증에는 비용 100, 2턴 복귀, 비현재 파편 수집 금지, 아군 전용 버프, 유물 슬롯 규칙 회귀 검사가 없다.
6. 시간대 문서가 위임하는 가방·유물 시스템 단일 원본 문서가 아직 `[작성 전]`이다.

### 낮음

1. 시간대 문서가 `[확정]`이면서 검수 상태는 `[초안]`이고 담당자·검수자가 비어 있다. 현재 상태 표시는 솔직하지만 완료 문서로 보기는 어렵다.
