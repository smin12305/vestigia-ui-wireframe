# v3 시간대·유물 개편

> 기록일: 2026-09-04
> 상태: `[실험]` 로컬 구현 완료, 사용자 플레이 테스트 대기

## 사용자 결정

- 시간 파편 최대치와 시간 조작 비용은 100이다.
- 시간대는 과거·미래만 선택하며 2턴 뒤 현재로 복귀한다.
- 과거는 아군 이동력 +1, 미래는 아군 치명타 피해율 +20%p다.
- 캐릭터 타입과 시간 추가 피해를 제거하고 아군에게만 과거·미래 태그를 둔다.
- 태그 일치 시간대에서는 캐릭터 스킬이 지정 궁극기로 바뀐다.
- 배치 전에 과거·현재·미래 각 4칸의 유물 가방을 구성하며 유물은 배치 시간대에만 적용한다.

## 완료

- 상단 캐릭터가 캔버스 경계에서 잘리지 않도록 논리·표시 캔버스를 `1920×1080`으로 확장했다. 기존 카메라 중심과 확대율을 유지해 보드의 화면상 위치는 바꾸지 않았다.
- 시계를 좌측 과거·중앙 현재·우측 미래 표시로 단순화하고, 활성 시간대 방향 바늘의 빠른 상하 떨림과 용두의 남은 턴 숫자를 추가했다.
- 각 시간대의 4개 가방 슬롯과 6개 유물 선택 목록을 각각 2열로 재배치하고, 유물 카드 높이·여백·설명 줄바꿈을 조정해 설명이 잘리지 않도록 했다.
- 엔진의 시간 이동·복귀·보너스·파편 상한을 새 규칙으로 교체했다.
- 아이작·안젤리카·메르칸의 시간대 태그와 궁극기 데이터·판정을 연결했다.
- 왼쪽 아래 선택 캐릭터 카드는 캐릭터 태그 기준으로 과거 캐릭터를 금색, 미래 캐릭터를 파란색으로 구분하고 카드 배경·테두리·초상화·체력바 포인트에 같은 색을 적용했다. 태그 없는 적 카드는 기존 표현을 유지한다.
- 메르칸 강화 반격의 즉시 기절과 이동 중단, 반격 피해의 파편 획득을 연결했다.
- 시간 추가 피해 계산과 연출 이벤트를 제거했다.
- 파편 100 도달 진동·붉은 시계, 시간대 공명 오라, 궁극기 준비·충격 연출을 추가했다.
- 시간 파편 게이지를 상단 시계 왼쪽의 세로형으로 바꾸고 아래에서 위로 채워지게 했다. 파편이 100인 동안 시계 전체가 계속 떨린다.
- 빈 가방 슬롯은 유물 아이콘 없이 `빈칸`만 표시한다. 과거 UI는 노랑, 미래 UI는 파랑으로 통일하고 시계판도 중앙 기준 좌측 노랑·우측 파랑으로 분할했다.
- 캔버스 높이 확장 후 어긋난 6×6 격자의 세로 투영값과 중심 위치를 새 캔버스 기준으로 다시 보정했다.
- 시간 파편 HUD는 왼쪽 패널 상단에 시계를 두고 그 아래에 긴 세로 게이지가 이어지는 형태로 재배치했다.
- 격자 세로 투영값 `59.7`은 타일 각도를 왜곡해 폐기했다. 격자 중심은 유지하고 세로 투영값을 `49.4`로 복원했다.
- 유물 선택 중에는 배경 전장과 상단 시스템 입력을 차단하고 유물 가방만 조작하도록 변경했다.
- 제공된 6개 유물 아이콘과 명칭을 연결하고 쿨타임 감소·턴 회복·추가 피해·치명타 피해·최대 체력·이동력 효과를 임시 배정했다.
- 유물 가방을 황동 회중시계 재질로 변경하고, 상단 회중시계에는 아래로 열린 뚜껑과 내부 원형 시간 파편 링, 최대 충전 시 붉은 중앙 점등을 추가했다.
- 유물 선택 UI 아래의 격자 타일이 포인터 입력을 가로채던 문제를 막기 위해 유물 선택 동안 Phaser 입력을 끄고 배치 단계 전환 시 다시 켜도록 수정했다.
- 시간 파편 원형 게이지는 시계판이 아니라 열린 뚜껑 자체가 채워지도록 변경했다. 최대 충전 표현도 시계 내부 적색 점등에서 본체 색을 유지하는 외곽 적색 오라로 교체했다.
- 과거와 현재 시간대의 전장 필터를 다시 표시하도록 레이어 우선순위를 복원했다. 필터는 배경·전투판에만 적용하고 HUD에는 적용하지 않는다.
- 시간 파편은 현재 시간대에서만 획득한다. 과거·미래에서는 중앙 획득 함수가 공격·반격·콤보·턴 경과·유물 효과의 파편 획득을 모두 차단한다.
- 회중시계 뚜껑과 과거·미래 눈금을 제거하고, 시간 파편을 시계 외곽에서 시계 방향으로 채워지는 원형 링으로 변경했다. 충전 구간에는 은은한 맥동과 선두 반짝임을 추가했다. 시간 이동 확정 후 창이 닫히면 과거는 반시계, 미래는 시계 방향으로 시침이 약 10바퀴 회전한 뒤 진입 문구를 표시하며, 시계 아래에 남은 체류 턴을 표시한다.
- 현재·과거·미래 시간대 필터를 각각 옅은 녹색·황금색·푸른색으로 전장 전체에 다시 연결했다.
- 회귀 캐릭터의 SD 바로 뒤에 시간대 색상의 움직이는 불꽃 오라를 추가하고, 범위보다 위·SD와 체력바보다 아래 순서로 고정했다. 선택 캐릭터가 회귀 상태이면 스킬 버튼을 붉은색 `궁극기` 버튼으로 바꾸고, 별도 불꽃 요소를 버튼보다 뒤쪽 레이어에 배치한다.
- 시간 파편 외곽 게이지를 파란색으로 통일하고, 완충 시 시계판에 나타나던 과거·미래 노랑·파랑 분할 배경을 제거했다.
- 최초 선공을 플레이어 아군으로 고정했다. 첫 라운드는 아군부터 행동 순서대로 진행하며 다음 라운드부터 기존 선공 교대를 유지한다. 시작 안내도 랜덤 동전 결과 대신 플레이어 선공을 표시한다.
- 시간 파편 완충 시 시계 클릭으로 조작 창을 여는 방식을 제거했다. 턴 시작의 적 행동 예고가 모두 끝난 뒤 시계 뒤에서 오른쪽으로 서랍이 자동 전개되며, 영문 없이 노란색 `과거로 회귀`와 파란색 `미래로 도약` 버튼만 표시한다. 선택하면 확인 창 없이 즉시 해당 시간대로 이동한다.
- 시간 선택 서랍이 시계에 가려지지 않도록 최종 위치를 오른쪽으로 이동하고 버튼 폭과 내부 여백을 축소했다.
- 시간 선택 서랍의 왼쪽 가장자리까지 시계 패널 바깥에서 시작하도록 추가 이동했다.
- 시간대 변경 시 궁극기 활성 대상의 순서를 무작위로 섞어 한 명씩 `각성` 문구, 파동, 카메라 펀치인 확대를 재생한다. 대상 캐릭터가 흔들리지 않도록 임시 보조 카메라의 흔들림과 캐릭터 세로 이동을 제거하고, 보드·배경·캐릭터 좌표를 고정했다.
- 3개 시간대 12칸 가방과 6개 유물 선택 UI를 캐릭터 배치 앞에 추가했다.
- 단일 실행 파일을 다시 생성했다.
- 선택 캐릭터 카드의 과거·미래 태그 색상 분기 추가 후 `npm.cmd run build:standalone`을 통과해 단일 실행 파일을 다시 생성했다. 사용자 결정에 따라 게임 플레이 테스트는 수행하지 않았다.

## 검증과 남은 일

- `npm.cmd run build:standalone`: 통과.
- 시간 선택 서랍 추가 후 `npm.cmd run build:standalone`: 통과, 단일 실행 파일 갱신.
- 즉시 시간 이동과 적 행동 예고 완료 후 서랍 노출 변경 후 `npm.cmd run build:standalone`: 통과, 단일 실행 파일 갱신.
- 시간 선택 서랍 위치와 순차 각성 보조 카메라 연출 추가 후 `npm.cmd run build:standalone`: 통과, 단일 실행 파일 갱신.
- `git diff --check`: 오류 없음. 줄바꿈 변환 경고만 존재한다.
- 사용자가 게임 플레이 테스트를 직접 진행하기로 결정했으므로 브라우저 시나리오 테스트는 수행하지 않았다.
- 구현은 v3 실험본과 인수인계에만 있으며 커밋·푸시하지 않았다.
