# 전투 시스템 v3 실험안 구현 기록

> 기록일: 2026-09-01  
> 상태: `[실험]` 구현 및 안정화 플레이테스트 완료

## 목표

기존 전투 프로토타입을 보존한 채 지정 방식을 세 종류로 단순화하고, 직사·곡사 투사체와 반격을 실제 조작으로 검증하는 독립 실험본을 만든다.

## 결정과 구현 근거

- 타겟형·셀 선택형을 제거하고 방향 선택형·자기 기준형·자가 버프형만 남겼다. 플레이어가 행동을 고른 뒤 판 위에서 한 번 더 확정하는 흐름을 공통화하기 위한 결정이다.
- 곡사는 절대 착탄 타일이 아니라 시전자 기준 상대 좌표를 저장한다. 계획 이후 위치가 바뀌어도 같은 방향과 거리로 발사한다는 사용자 규칙을 구현하기 위해서다.
- 적 행동 예고는 고정 정보로 분리했다. 행동 순서 버튼이 미래 결과를 재계산하지 않으며, 초상화 가상 재생도 실제 전투 상태를 바꾸지 않는다.
- 반격은 일반 턴 순서 바깥의 인터럽트로 처리한다. 일반 이동은 각 칸, 강제 이동은 최종 칸에서만 검사하고 대상별 발동 기록은 턴 종료까지 유지한다.
- 메르칸의 `복수`를 선택하는 동안 실제 반격 판정과 같은 자기 중심 3×3 범위를 보여 준다. 자신 또는 반격 범위 타일을 다시 눌러 스킬을 확정할 수 있다.

## 주요 구현

- 새 타기팅·궤적·계획 데이터 모델과 파서
- 직사 첫 충돌·비관통 및 관통 공격
- 곡선 투사체와 상대 좌표 기반 착탄·광역 범위
- 자기 기준·자가 버프의 2단계 확정 입력
- 반격 상태, 다중 반격 무작위 처리, 슬로 모션 연출, 처치 시 남은 행동 취소
- 고정 적 행동 예고와 초상화 클릭 가상 이동·공격
- 지진·복수·저격 및 세 적 캐릭터의 실험용 공격·스킬
- v3 전용 저장 키와 실행 문서, standalone 빌드

## 안정화 수정

- 시간대 스택 오라가 일반 실행 소스에서도 항상 표시되도록 복원했다. 스택 단계별 색은 1/2/3/4 이상에 노랑/파랑/보라/빨강을 사용한다.
- 자기 기준형은 범위의 같은 칸, 자가 버프형은 자신을 두 번 클릭해야 확정되도록 첫 선택 지점을 계획 데이터에 저장했다.
- 일반 공격·스킬에 캐릭터 동작을 추가하고 반격에는 반격자 돌진·피격 충격을 적용했다.
- 피해로 HP가 0이 되는 모든 경로에서 상태 제거, 남은 행동 취소, 전투 불능 표시, 승패 판정을 즉시 수행하도록 사망 처리를 중앙화했다.
- Phaser 캔버스를 `1920:893` 비율로 맞춰 보드의 비등방 확대를 막았다.
- 카메라 세로 중심을 말판 중심 `425.25`와 일치시켜 격자가 경기장 아래로 밀리던 현상을 수정했다.
- 배치 단계의 전용 `56.3%` 위치 보정과 별도 래퍼 비율을 제거하고, 인게임과 같은 16:9 전체 전장 컨테이너에 배경과 Phaser 캔버스를 함께 배치했다. 전체화면에서는 캔버스가 1920px에 고정되지 않고 전장 폭 100%로 배경과 함께 확대되도록 수정했다.
- 전장 또는 상단 행동 순서에서 적 캐릭터를 클릭하면 적 행동 포커스를 설정하고 왼쪽 아래 캐릭터 카드가 해당 적의 정보로 변경되도록 연결했다.
- 반격 자가 버프 스킬 모드에서 시전자 기준 Chebyshev 거리 1의 3×3 타일을 금색으로 표시하고 `반격 범위 · 3×3` 라벨을 추가했다. 메르칸 자신 또는 이 범위 타일을 다시 누르면 확정된다.
- 시간대가 진행되어 중첩이 증가하거나 다른 시간대의 1중첩으로 전환될 때 `time-advance` 이벤트 80ms 뒤 강화 대상에게 스택 색상의 확대 링·외곽 링·파티클 10개·중첩 수 라벨을 한 번 재생하도록 순간 강화 이펙트를 정식 v3 소스에 복원했다. 모션 감소 환경에서는 파티클을 생략하고 짧은 페이드만 사용하며 상시 오라는 계속 별도로 표시한다.
- 아군별 확정 상태를 별도로 관리해 다른 캐릭터를 선택해도 확정한 이동의 발자국·도착 홀로그램과 공격·스킬 범위를 전장에 유지한다. 확정된 자기 기준 범위는 일반 스킬과 같은 청록색 타일, `복수`의 반격 구역은 메르칸 중심 칸을 제외한 아군색 청록 빗금으로 표시하며 `행동 없음`·계획 초기화 시 확정 상태를 제거한다.
- GitHub에서 복원한 시간 조작 v2를 v3에 통합했다. 기존 시간 억제를 회중시계 UI의 `가속`·`정지`·`역행`으로 교체하고, 턴당 1회·최초 비용 50·사용 시 다음 비용 5 증가·시간 파편 최대 80 규칙을 적용했다.
- `가속`과 `역행`은 시간대를 즉시 한 칸 이동시키고, `정지`는 현재 시간대를 유지하면서 턴 종료의 자연 진행을 한 번 막는다. 기존 공격·반격·사망 처리 흐름은 그대로 유지했다.
- 공격·스킬의 준비·돌진·잔상·범위·투사체·적중 연출을 연결했다. 결과 이벤트로 치명타·사살·치명타 사살·반격 사살의 문구, 충격파, 파편, 사망 잔상과 사살자 오라를 구분한다. 전술 카메라 패닝·확대·추적은 사용자 요청에 따라 모두 제거했다.
- 시간 우대 피해를 즉시 피해와 시간 중첩 배율로 생긴 추가 피해로 분리했다. 기본 타격 0.28초 뒤 `시간 추가 데미지!` 문구, 중첩별 색상, 폭발 파편, 최종 추가 피해 숫자, 전체 화면 흔들림을 재생하고 그때 실제 추가 피해 및 사망 판정을 적용한다. 피해 연출에서는 계산식과 중첩 수를 숨긴다.
- 시간 추가 피해의 흔들림을 화면 루트 Web Animations 재생으로 교체해 배경·보드·HUD가 함께 확실히 흔들리도록 했다.
- 치명타 적중에도 0.23초의 짧은 화면 흔들림을 연결하고, 시간 추가 피해의 0.42초 흔들림과 강도를 구분했다.
- 공격·스킬 범위 안의 캐릭터를 누르면 캐릭터 선택보다 범위 입력을 우선하고, 같은 포인터 이벤트가 두 번 계획을 확정하지 않도록 전파를 차단했다.
- 공격·스킬 범위 선택 중 UI를 제외한 전장 전체에 단일 딤을 적용하고 선택 캐릭터·지정 가능 범위·범위 안 캐릭터만 위에 다시 밝게 표시한다. 범위 밖 캐릭터와 예정 홀로그램 입력은 차단한다.
- 선택 캐릭터의 이동 후 도착 홀로그램은 공격·스킬의 기준점이므로 딤 위에 다시 밝게 표시하고, 자기 기준 입력이 가능한 경우 홀로그램 클릭을 범위 입력으로 연결한다.
- 아군 반격도 일반공격 유효 타격으로 집계해 공격 시간 파편, 상태 콤보 파편, `유효공격` 유물의 시간 파편 보너스를 지급한다.
- 시간 조작에는 가속·정지·역행별 화면 색상·방향 파티클을 유지하고 카메라 이동은 제거했다. 모션 감소 환경에서는 시간 추가 피해의 화면 흔들림과 다량 파티클을 생략한다.
- 공격·스킬 버튼으로 범위를 연 뒤 범위 또는 캐릭터 재클릭으로 빠르게 확정하는 기존 방식과, 첫 지정 후 `행동 확정` 버튼으로 확정하는 방식을 함께 지원한다. 미확정 행동이 남으면 계획 실행을 막는다.

## 남은 검증과 한계

- 전장 장애물이 없어 직사와 장애물의 차단·관통 상호작용은 미검증이다.
- 반격 무작위 순서를 재현하는 시드 고정 기능이 없다.
- 브라우저 1차 시나리오 검증이며 다수 전투·밸런스 통계는 수집하지 않았다.
- 반격 사망 처리 코드는 모든 피해 경로에 연결했으나, 낮은 HP를 강제로 만든 전용 브라우저 시나리오는 별도로 반복하지 않았다.
- 시간 파편 50개 이상을 모은 실제 전투에서 `가속`·`정지`·`역행` 각각의 장시간 회귀 플레이테스트는 남아 있다.
- 치명타 사살과 반격 사살 전용 연출의 실제 조건별 반복 플레이테스트는 남아 있다.
- 시간 우대 캐릭터의 실제 공격에서 0.28초 지연, 추가 피해 문구·흔들림·사망 판정의 브라우저 플레이테스트는 남아 있다.
- 시간 조작 v2는 v3 실험본에만 적용했고 별도 v2 원본과 제안·확정 문서는 변경하지 않았다.
- v3를 루트 프로토타입 및 확정 기획에 반영할지는 미결정이다.
