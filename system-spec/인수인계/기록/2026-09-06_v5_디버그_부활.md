# v5 디버그·부활 변경

## 결정

- v4를 보존한 v5 분리본에서 후속 변경을 진행한다.
- 디버그 창에 현재 스테이지 즉시 승리를 제공한다.
- 2스테이지부터 승리 보상으로 유물, 생존 아군 20% 회복, 사망 캐릭터 1명 부활 중 선택한다.
- 복수 사망자는 SD 선택 화면으로 고른다. 부활 HP는 최대 체력 50%이며 부활 시 다른 캐릭터는 회복하지 않는다.
- 안젤리카 일반 스킬 `저격` 피해는 10이다.

## 검증

- v5 타입 검사·Vite 빌드·standalone 생성 성공.
- 기존 `scripts/check-campaign.ts`에 디버그 승리, 부활, 안젤리카 피해 검증을 추가했다.
- 검증 실행은 자동 승인 사용 한도 초과로 차단되어 결과를 만들지 못했다. 사용자가 실제 플레이 테스트를 진행한다.
