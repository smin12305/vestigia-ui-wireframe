# v3 유물 가방 UI

- 결정: 제공한 참고 이미지처럼 위쪽 장착 칸·아래쪽 보유 유물에는 아이콘만 표시하고, 왼쪽 패널에서 클릭한 유물 정보를 확인한다. 드래그 앤 드롭으로 배치한다.
- 구현: 과거·현재·미래 각 2×2 칸 유지. 칸 사이 이동·교환, 보유 목록으로 반환, 정보 패널 해제 버튼, 선택 후 빈칸 클릭을 지원한다.
- 저장: 빈칸 위치를 유지하고 재로딩 시 유효한 유물 ID와 중복 여부를 검사한다.
- 배경 전장 입력 차단 유지. 게임 플레이 테스트는 사용자 담당이다.
- 변경 파일: v3/src/main.ts, v3/src/stable-v3-ui.css, v3/README.md, v3/standalone/index.html (v3는 도구/전투 프로토타입/실험버전/v3).
- Git: 기존 로컬 미커밋 변경을 보존. 커밋·푸시하지 않음.
- 검증: TypeScript 검사·Vite 빌드·단일 HTML 생성 통과. 브라우저 플레이 테스트는 수행하지 않음.
- 다음: 사용자 플레이 피드백으로 가방 크기와 드래그 조작을 조정한다.
- 추가 결정·반영: 유물칸 효과를 상시·시간대 진입·턴 시작·공격 적중 시로 묶고 제목 아래 효과 합계를 표시한다. 치명타 피해율의 단위는 %p로 표시한다.
