# 2026-09-14 개발팀 1차 피드백 반영

## 최신 후속 결정

- 피드백 문서는 최상위 `피드백/Waredo_2.0_개발팀_1차_피드백.md`로 이동했다. `확정/`·`프롬프트/`와 같은 단계이며 내부·참조 링크를 갱신했다. 검수 문서 보류 보관 및 기능 결정 상태는 유지했다.

- 표시 보완: 피드백 원문 각 항목 바로 아래에 수정한 문서 링크·수정 절·변경 내용을 작성했다. 미처리 항목은 시스템 문서를 수정한 것처럼 표현하지 않고 검수 기록만 남겼음을 구분했다.

- 해결 완료 문서 정리: 검수표 9·18·25는 완료 기록으로 분리하고 남은 목록·해결안에서는 제거했다. 원문 9장 ‘문서 공통 정리’는 검수표 25번이라는 번호 대응과 바로가기 추가. 실제 남은 피드백은 6·16·17·24다.

- 16은 추후 수정. 18은 효과별 발동당 1중첩, 최대중첩 상한, 시간대 이탈 초기화로 승인·반영했다. maxStackCount 문법·효과표·자료형 연결 완료, 개별 수치는 콘텐츠 작성 대상이다.
- 17은 Instant 신규 작성·사용 보류를 제거하고 적용·소비·종료 상세는 FSM 이후 확정한다.
- 원문 9장(검수표 25)의 문서 공통 정리 완료: 기존 승인 상태 복원, 현행 충돌·연산 안내 통일, 과거 검수·연결성 검토 이력 구분. 에이전트 없이 처리했다.
- 아래 미결정·제안 설명은 이 후속 결정 이전 이력이다. 로컬 미커밋·미푸시 유지.
