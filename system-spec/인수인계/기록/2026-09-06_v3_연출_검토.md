# v3 전체·연출 코드 검토

- 요청: 현재 게임의 부족한 부분을 연출 포함 검토. 게임 코드 수정은 요청하지 않음.
- 범위: main.ts, BattleScene.ts, engine.ts, stable-v3-ui.css 및 현재 기록. 실제 플레이 테스트 미수행.
- 확인: 궁극기 흔들림 예약 330ms, 실제 피해 계산 대기 920ms. 일반 시전의 선행 충격은 90ms 뒤 시작하고 투사체는 전체 시간의 55%/72%에 도착하지만 피해는 전체 시간이 지난 뒤 처리된다.
- 확인: 시계 회전 1800ms와 별개로 각성이 이벤트 후 약 80ms부터 900ms 간격으로 시작된다. 각성은 별도 SD 복제와 카메라 확대 및 복제 이미지 배율을 함께 사용한다.
- 확인: 공통 공격 연출이 잔상·베기·원형 충격을 공유한다. 기본 이동은 좌표 변경 후 재렌더, 강제 이동은 최종 좌표로 변경된다. 상태는 텍스트 배지로 표시한다.
- 확인: src 검색에서 사운드 재생·오디오 파일·hitstop/timeScale 사용을 찾지 못했다. 취소 버튼은 CSS에서 숨김. 도움말에는 이전 시간 순환·타입·과열 규칙이 남아 있다.
- 제안: 타격 시점 동기화 → 시간 이동/각성 순서 통합 → 캐릭터별 공격·상태 표현 → 사운드 → 반복 예고 속도·취소·도움말 정리. 수치·순서 변경은 사용자 승인 후 구현.
- 검증: 읽기 기반 검토만 수행. 체감·현재 화면 재현 및 밸런스 평가는 미검증.
- Git: 게임 코드 변경 및 커밋·푸시 없음. 기존 미커밋 작업 보존.
