# ID 정수화 및 자료형 검토

- 사용자 결정: 캐릭터 ID를 포함해 ID는 int로 작성하고 변수 전반을 검토한다. main에서 작업한다.
- 변경 이유: 기존 영문 ID와 CHR/ATK/SKL 조회 번호가 이중 관리되고, 시스템 표는 ID·정수·수치·비율로 혼용돼 있었다.
- 완료: 확정 문서 17개에 자료형·ID·참조 기준을 반영했다. 시스템 변수 116종을 대조하고 캐릭터 5·공격 5·스킬 10·범위 패턴 8개의 실제 정수 ID를 등록했다.
- 기준 문서: `확정/문서관리/Waredo_2.0_기획_조정값_통합표.md`, `확정/콘텐츠/Waredo_2.0_캐릭터_콘텐츠_인덱스.md`.
- 정리: 정의 ID와 전투 개체 ID를 구별했다. 계획·상태·반격·점유는 개체를 참조한다. ID의 의도적인 없음은 0, 미정은 [작성 필요]다. enum 태그의 NONE과 ID의 0을 구별한다.
- 검증: 캐릭터 표와 문법의 참조 일치, ID·패턴 토큰을 제외한 5종 문법과 효과 순서 보존, 공통 자료형 대조, git diff --check 통과.
- 미결정: 개별 콘텐츠의 동작 미정·패턴 상세 좌표·유물 실제 ID와 반복 트리거 누적 정책은 유지했다. 신규 밸런스 값은 부여하지 않았다.
- 주의: 프로토타입의 문자열 ID 구현은 이번 문서 변경 범위 밖이다. 구현 시 새 정수 정의와 개체 ID를 연결해야 한다. 기존 확정 이미지 2개(대각선 충돌 정지·전투판 좌표) 누락은 별도 후속 항목이다.
- 자체 검토이며 에이전트 연결 없음. 참고한 문서 관리·검수 규칙은 [제안] 상태다.
- Git: main에서 문서와 인수인계를 함께 커밋·푸시한다. 결과는 Git 이력과 현재 main을 확인한다.
