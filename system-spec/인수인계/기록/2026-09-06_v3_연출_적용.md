# v3 연출·전반 개선 적용

- 결정: 사용자가 전반 검토와 연출 정리안을 합쳐 적용하도록 승인했다.
- 완료: 명중 시점에 HP 변경·피격 효과·피해 숫자·합성 사운드 연결. 궁극기의 시전 중 조기 흔들림 제거. 다중 타격 화면 충격 제한과 짧은 타격 정지.
- 완료: 아이작 상승 충격, 안젤리카 조준선, 메르칸 반격 시점 정리. 이동 보간·먼지, 띄워짐 SD 높이, 기절 표식. 기존 보드 좌표 유지.
- 완료: 시계 회전 후 필터·진입 문구, 랜덤 순차 각성 클로즈업, 입력 잠금/복구. 보드·배경 확대 및 캐릭터 반복 흔들림 없음.
- 완료: 사망 후 예정 행동 취소·결과 화면 지연. 피해/치명타/반격/궁극기 요약. 합성 임시 사운드와 음소거 설정.
- 완료: 취소 버튼·Esc, 적 예고 속도·건너뛰기, 유물 시간대별 효과 합계, 현재 규칙 도움말.
- 변경 파일: v3/src/main.ts, src/phaser/BattleScene.ts, src/game/engine.ts, src/presentation.ts, src/presentation.css, scripts/check-presentation.mjs, README.md, standalone/index.html. v3 기준 경로는 도구/전투 프로토타입/실험버전/v3.
- 검증: 코드 회귀 6건 통과(일반·궁극기 4종 명중/HP, 강화 반격 기절, 사망/결과 경계). 첫 실행은 로컬 읽기 제한으로 실패했고 승인된 재실행에서 통과했다. 브라우저 플레이 테스트는 사용자 결정에 따라 수행하지 않았다.
- 제한: 효과음은 임시 합성음이며 실제 체감·화면은 사용자 피드백 대기. 고유 다중 프레임 SD 자산은 추가하지 않았다.
- 최종 빌드: TypeScript·Vite·단일 HTML 생성 통과. 번들 크기 경고는 남아 있다. git diff --check로 공백 오류를 확인했다.
- Git: 기존 미커밋 작업 보존, 커밋·푸시 없음. 다음 작업은 사용자 플레이 피드백에 따른 연출 강도·속도 조정.
