# 2026-09-06 v4 시간 이동 연출 순서

## 결정

- 기존 `실험버전/v3`는 보존하고, v3를 복사한 `실험버전/v4`에만 후속 연출을 적용한다.
- 회중시계 연출은 시계·보드·배경을 이동시키지 않고 시계 요소의 확대와 시침 회전만 사용한다.

## 적용 내용

- 시간 이동 확정 후 회중시계가 왼쪽에서 살짝 커지며 시침이 회전한다.
- 회전 완료 뒤 `과거로 이동` 또는 `미래로 이동` 문구를 표시한다.
- 문구 뒤 해당 시간대 태그 캐릭터가 무작위 순서로 한 명씩 `각성!`을 표시한다.
- 과거 이동 문구는 금색, 미래 이동 문구는 파란색을 사용한다.

## 검증

- v4 standalone 빌드 결과를 확인한다.
- 사용자가 게임 플레이 테스트를 수행하므로 자동 브라우저 플레이 테스트는 하지 않는다.
- GitHub에는 아직 동기화하지 않는다.
