## 목표와 사용자 결정

- 결정: ChatGPT [게임 설정과 배경 정리](https://chatgpt.com/c/6aae34fa-1468-83e8-98f2-03c9e6f556bc)에 정리한 캐릭터별 의도를 각 캐릭터 콘텐츠에 모두 넣는다.
- 반영 범위: 아이작·안젤리카·아르제나·클로이·야나 5명의 포지션, 핵심 플레이 경험, 스킬·궁극기 의도, 성장·메타 방향과 핵심 기획 방향. 클로이의 일반 공격 의도와 야나의 행동 순서·위험 비용도 포함한다.
- 출처의 플레이 경험 목표를 현행 수치나 새로운 전투 규칙의 승인으로 확장하지 않는다. 대화 전문은 보관하지 않는다.

## 완료한 일

- 각 확정 캐릭터 콘텐츠의 1.1절에 기획 의도와 출처를 추가하고 최근 수정일 및 6장 변경 기록을 갱신했다.
- 현행 콘텐츠 적용 메모를 통해 목표 경험과 실제 판정의 관계를 명시했다. 아르제나의 반격·시간 파편 조건, 클로이 일반 공격의 비관통, 야나의 아군 행동 슬롯 우선 배정과 재이동 비보장, 안젤리카의 조건부 6회 충돌을 구분했다.
- 아이작은 오사 위험과 치명타 피해율 강화 수단을 5장의 `[논의 필요]`로 기록하고 문서 검수 상태에 잔여 논의를 표시했다.
- 전체 기획 관리 3장에 5명 의도 반영과 미정 유지 범위를 기록했다. 기존 유물·Figma 관리 기록은 보존했다.
- 콘텐츠 수치·ID·기존 효과 문법과 프로토타입은 변경하지 않았다.

## 검증 결과

- 주 작업자 검사: 5개 콘텐츠 모두 수치·ID·효과 코드·표 불변 검사를 통과했다. 상대 링크 검사와 `git diff --check`도 통과했다.
- 독립 정적 검수 PASS, 필수 수정 0건. 원본 사용자 설명·정리문의 총 118문단을 대조해 누락 없음을 확인했다. 5개 콘텐츠 2~4장은 HEAD와 동일하며 상대 링크·관리대장 일치와 `git diff --check`를 통과했다.
- 문서 작업이며 코드 검사·빌드·플레이테스트는 수행하지 않았다. 재미·밸런스 검증이나 잔여 미결정 승인을 뜻하지 않는다.
- 참고한 문서 관리 및 검수 규칙 자체는 `[제안]` 상태다.

## 미결정과 다음 행동

1. 아이작 콘텐츠 1.1절 적용 메모와 5장을 읽고 아군 오사 위험의 현행 판정 연결 및 치명타 피해율 강화 수단·수치를 논의한다.
2. 아이작 일반 스킬·궁극기 관통 분류의 기존 `[작성 필요]`와 안젤리카 연속 사격 대상 판정의 기존 미정을 유지한다. 의도 문장만으로 구현을 확정하지 않는다.
3. 후속 규칙이 결정되면 해당 시스템의 단일 원본을 먼저 갱신하고 콘텐츠를 연결한다. 현재 작업은 의도 이관이며 규칙 설계 완료가 아니다.
4. 기존 유물 콘텐츠 제안과 Figma 드래그·실제 재생 검증 후속은 이전 기록대로 유지한다.
