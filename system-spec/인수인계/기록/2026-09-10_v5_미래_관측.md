# v5 미래 관측 구현 기록

> 작성일: 2026-09-10 (Asia/Seoul)
> 구분: 사용자 요청에 따른 v5 프로토타입 구현 기록
> 범위: v5만 변경 · 확정 기획 변경 없음

## 목표와 사용자 결정

사용자는 설계한 작전을 실행하기 전에 미리 관측하고 같은 계획으로 되돌아오는 기능을 요청했다. `작전 개시` 아래의 `미래 관측` 버튼으로 진입하며, 암전 뒤 시계가 커져 미래 방향으로 한 바퀴 돌고, 화면이 밝아지면 약한 지지직 효과와 필터를 통해 미래임을 표현한다. 캐릭터 행동은 전투 화면 효과 없이 간단히 재생한다. 관측 종료 후 다시 암전하고 시계가 뒤로 한 바퀴 돌아 계획 단계로 복귀한다. 사용자는 관측 후에도 그려 둔 작전이 그대로 남아야 한다고 명시했다.

- 결정(2026-09-10): 사용자는 현재 로컬 변경 전체가 최신이라고 확인했으며, 이 작업 전체를 Git에 반영해 원격 브랜치로 푸시하도록 요청했다.

## 실제 구현

- `src/game/engine.ts`: 콘텐츠·유물 배치·전투 상태·첫 이동 유물 사용 상태·적 AI 설정을 복사하는 관측용 엔진을 생성한다. 실제 엔진과 관측 엔진의 이벤트·상태를 분리한다.
- `src/main.ts`: 미래 관측 버튼, 진입·복귀 시계 연출, 관측 진행 문구, 입력 잠금, 오류 시 정리와 계획 화면 복귀를 추가했다.
- `src/future-observation.css`: 버튼, 암전, 확대 회중시계, 미래 필터, 주사선·약한 지지직 효과를 추가했다.
- `src/phaser/BattleScene.ts`: 관측 사본으로 위치·HP·상태를 재생한다. 기존 타격 연출 이벤트를 연결하지 않고, 관측 중 먼지·시간대 불꽃·연결 링 전환도 차단한다. 종료 후 원래 엔진과 계획 표시로 돌아온다.
- `scripts/test-observation.mjs`: 관측 실행 후 원본 상태·전투 기록 불변과 반복 관측 시작 상태를 검사한다.
- `scripts/build-standalone.mjs`: 생성 HTML의 CRLF/CR 혼합을 LF로 통일하고 행 끝 공백을 제거해 재생성 때마다 Git 형식 검사가 안정적으로 통과하도록 보강했다.
- `standalone/index.html`: 최신 변경을 포함해 재생성했다.
- 인수인계는 이 기록과 `../CURRENT.md`를 갱신했다. 새 기획 문서를 생성한 작업이 아니므로 전체 기획 관리대장은 변경하지 않았다.
- 구현 코드·독립 실행본·검사와 당시 인수인계를 `a091c88 feat: add v5 future observation`으로 커밋하고 `origin/codex/time-system-combat`에 푸시했다.

## 검증 결과

아래 실행·브라우저 검증은 주 작업자 결과를 전달받았으며, 기록관은 실제 코드 diff와 검사 파일을 대조했다.

- TypeScript 검사와 Vite 빌드 통과.
- 독립 실행본 생성은 일시적인 파일 잠금으로 한 차례 실패했으나 재실행에 성공했다.
- `node scripts/test-observation.mjs`에서 계획·승리·패배 3개 경우를 통과했다. 각각 원본 전체 상태 불변, 실제 전투 기록 이벤트 수 불변, 반복 사본이 원래 계획에서 시작함을 검사했다.
- `1280×720` 브라우저에서 배치 후 아이작 스킬 확정, 미래 관측 필터 화면, 복귀 역회전 시계, 계획 복귀를 스크린샷으로 확인했다. 복귀 후 1턴·시간 파편 0·설정 완료·스킬 범위가 유지됐다.
- 독립 검수 결과 주요 결함은 없었다. 잔여 먼지·불꽃·연결 링 전환 효과 지적을 관측 상태 분기로 비활성화했다.
- 실제 아군 이동 1칸과 방향 일반공격 계획을 포함하도록 검사를 보강한 뒤 3개 경우를 재검사해 통과했다. 브라우저 콘솔 오류는 0개였다.
- 잔여 연출 수정 후 독립 재검수 PASS, 잔여 결함 없음. 독립 실행본 바깥 HTML 개행·공백 정리 후 `git diff --check` 통과(LF→CRLF 경고만).
- 출력 정규화 보강과 독립 실행본 재생성 후 `npm.cmd run build:standalone`이 통과했다. 대형 청크 경고만 있었고 빌드 오류는 없었다.
- 같은 상태에서 `node scripts/test-observation.mjs`의 계획·승리·패배 3종 검사가 모두 통과했고, `git diff --check`도 통과했다. 출력은 LF→CRLF 전환 경고만 포함했다.
