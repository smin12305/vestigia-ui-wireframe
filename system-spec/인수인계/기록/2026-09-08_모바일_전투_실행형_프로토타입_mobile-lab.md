# 모바일 전투 실행형 프로토타입 `mobile-lab`

> 작성일: 2026-09-08
> 기준 브랜치: `codex/time-system-combat`
> 기준 커밋: `5cc58be`
> 상태: `[실험]`·리뷰 진행 중

## 목표

- 모바일에 맞지 않아 기각된 Figma 시안을 바로 다듬지 않고, 실제 전투 입력과 표시 크기를 확인할 수 있는 독립 실행형 브라우저 프로토타입을 만든다.
- 수집한 캐릭터·범위 표현을 실제 전투 흐름에서 검토해 후속 Figma 모바일 재설계의 근거로 사용한다.

## 완료한 일

- `도구/전투 프로토타입/실험버전/mobile-lab/`에 아래 9개 파일을 생성했다.
  - `model.js`
  - `app.js`
  - `style.css`
  - `index.html`
  - `server.cjs`
  - `build.cjs`
  - `tests.cjs`
  - `package.json`
  - `README.md`
- 서버 없이 실행할 수 있는 `standalone/index.html`을 생성했다.
- 플랫 `6×6` 보드, 아군 3명·적 3명과 v5 SD 이미지, 이동 경로·도착 잔상·범위 표시를 구성했다.
- 실제 HP, 일반 공격, 스킬, 공유 쿨다운, 기절·띄워짐·밀치기·반격을 계산한다.
- 적 AI, 아군 행동 순서 조정, 적 행동 예고, 턴 진행, 기록, 배속·일시정지와 승패를 구현했다.
- 현재 시간대의 파편 획득, 비용 100의 과거·미래 즉시 전환, 2턴 유지 후 현재 복귀, 과거 이동력 `+1`, 미래 일반 공격력 `+3`을 구현했다.
- 명령 작성 중에도 별도 시간 이동 창 없이 과거·미래를 즉시 선택할 수 있게 했다.

## 검증 결과

- 순수 전투 모델 자동 테스트 11개가 통과했다. 파편·시간 복귀, 범위, 경로 검증, 공격 보너스, 쿨다운, 반격, 순서, 치명타·승패, AI 완주와 유닛 중첩을 포함한다.
- `844×390` 모바일 UI에서 아이작 이동 후 `지진`을 실행해 적 HP `50→42`, 공유 쿨다운 `2`, `2턴` 진입을 확인했다.
- 명령 작성 중 과거로 즉시 전환해 파편 `0`, 남은 `2턴`, 이동력 `4`, 강화 자기 중심 `5×5` 표시를 확인했다.
- `standalone/index.html` 생성 상태를 확인했다.

## 범위와 한계

- `mobile-lab`은 전투·시간·턴을 실제 계산하는 독립 브라우저 프로토타입이다.
- 기존 v5와 확정 기획을 대체하지 않으며, 확정 규칙 전체 동등성을 구현한 것은 아니다.
- 유물, 배치 편성, 캠페인, 지형 효과, 아군 오사와 전체 v5 세부 규칙은 포함하지 않았다.
- 초기 배치와 단일 전투 시나리오는 실험용 가정이다.
- Figma는 이번 작업에서 수정하지 않았다. 기존 모바일 Figma 시안은 승인된 디자인이 아니며 재설계가 필요하다.

## 진행 중·다음 작업

1. 진행 중인 독립 검수관 리뷰 결과를 반영한다.
2. 실제 모바일 기기 또는 동일 화면 크기에서 입력 영역, 텍스트 크기와 전장 가독성을 검증한다.
3. 사용자 요소 검토 후 모바일 실제 표시 크기 기준으로 Figma 전투 화면을 처음부터 재설계한다.
4. 확정 규칙 전체 동등성이 필요하면 누락 범위를 별도로 정의하고 구현·회귀 검증한다.
