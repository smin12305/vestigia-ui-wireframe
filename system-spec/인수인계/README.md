# Waredo 2.0 인수인계 기록

이 폴더는 서로 다른 컴퓨터와 Codex 작업 사이에서 프로젝트 맥락을 이어가기 위한 공유 기억 저장소다.

## 파일 구성

- `CURRENT.md`: 새 작업이 가장 먼저 읽는 최신 상태
- `기록/`: 완료된 주요 작업의 날짜별 스냅샷

## 사용 명령

- `작업 시작`: 원격 변경을 가져오고 현재 상태를 복원한다.
- `작업 기록`: 현재 대화의 결정과 진행 상태를 인수인계 문서에 반영한다.
- `작업 마무리하고 GitHub에 올려`: 변경과 인수인계 기록을 함께 검증·커밋·푸시한다.

## 기록 원칙

- 대화 전문이 아니라 다음 작업에 필요한 결정과 상태만 남긴다.
- 사용자 결정, 에이전트 제안, 미결정 사항을 구분한다.
- 실제 파일과 Git 상태를 확인하지 않은 내용을 완료로 기록하지 않는다.
- 인증 정보와 민감한 개인정보는 기록하지 않는다.
