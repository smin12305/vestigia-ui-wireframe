- 시간 파편 50개 이상이 필요한 세 시간 조작의 실제 사용은 이번 브라우저 확인에서 반복하지 않았다. 엔진 연결과 UI 상태는 빌드로 검증했다.
- 치명타 사살·반격 사살 전용 결과 연출은 코드와 빌드까지 검증했으나 이번 브라우저 전투에서 해당 조건을 강제로 만든 반복 시나리오는 수행하지 않았다.
- 시간 조작 v2는 v3 실험본에만 적용했다. 별도 v2 원본과 `[제안]` 문서는 변경하지 않았다.
- v3는 `[실험]` 상태다. 루트 프로토타입과 `확정/` 기획 반영에는 별도 사용자 승인이 필요하다.
- 문서 관리 및 검수 규칙은 현재 `[제안]` 상태다.
- 신규 `프로토타입 2.0` 폴더는 사용자 검토에서 기각된 보류 산출물이다. 다음 작업에서 이를 현재 구현으로 오인하거나 v3에 구조째 병합하지 않는다.

## 마지막 확인 Git 상태

- `main`은 새 원격 커밋 `a025d23`보다 1커밋 뒤에 있다. 로컬 수정 보호를 위해 전체 pull/merge 대신 충돌 없는 v2 신규 경로만 복원했다.
- 이번 안정화 수정과 인수인계 문서는 로컬에서 수정된 상태이며 커밋·푸시하지 않았다.
- GitHub의 시간 조작 v2 실험은 로컬에 내려받았으나, 기존 v3 로컬 수정은 아직 GitHub에 동기화되지 않았다.
