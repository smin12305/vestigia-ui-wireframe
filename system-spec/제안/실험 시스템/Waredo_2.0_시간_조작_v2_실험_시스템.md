## 1. 실험 목적

기존 프로토타입의 시간 억제를 제거하고, 플레이어가 시간 파편을 사용해 시침을 직접 가속·정지·역행하는 능동적인 시간 조작을 검증한다.

본 실험은 기존 `도구/전투 프로토타입/`과 분리한 `실험버전/v2/`에서만 동작한다. 본 문서와 구현 결과는 `[제안]`이며, 사용자 승인 전에는 기존 프로토타입이나 `확정/` 기획의 기준으로 사용하지 않는다.

## 2. 시간의 기본 진행

- 전투는 현재 시간대의 첫 번째 눈금에서 시작한다.
- 회중시계는 12개의 눈금을 사용한다.
- 1~2번째 눈금은 현재, 3~4번째 눈금은 미래, 5~6번째 눈금은 과거다.
- 7~12번째 눈금에서도 현재·미래·과거가 같은 순서로 한 번 더 반복된다.
- 시간 조작을 사용하지 않으면 턴 종료 시 시침이 한 칸 앞으로 이동한다.
- 12번째 눈금 다음에는 다시 1번째 눈금으로 이동한다.

## 3. 시간 파편

- 전투 시작 시 보유 시간 파편은 0이다.
- 시간 파편의 최대 저장량은 80이다.
- 아군이 적에게 유효 피해를 주면 시간 파편을 20 획득한다.
- 기절 또는 띄워짐 상태인 적에게 유효 피해를 주어 콤보가 성립하면 시간 파편을 추가로 30 획득한다.
- 승패가 결정되지 않은 턴이 끝나면 시간 파편을 10 획득한다.
- 최대 저장량을 초과한 파편은 저장하지 않는다.

## 4. 시간 조작 공통 규칙

- 시간 조작은 계획 단계에서만 사용할 수 있다.
- 한 턴에는 시간 조작을 한 번만 확정할 수 있다.
- 시간 조작의 최초 비용은 시간 파편 50이다.
- 시간 조작을 확정할 때마다 다음 시간 조작 비용이 5 증가한다.
- 시간 조작 비용은 최대 저장량 80과 별도로 증가한다.
- 보유 파편이 현재 비용보다 적거나 현재 비용이 최대 저장량보다 크면 시간 조작을 사용할 수 없다.
- 이번 실험본에는 과열 비용을 낮추는 냉각 기능이 없다.
- 조작 버튼을 선택하는 것만으로는 파편을 소모하거나 실제 시간을 변경하지 않는다.
- 확정 버튼을 누르는 즉시 파편을 차감하고 실제 시침과 시간대를 변경한다.
- 조작 화면을 닫거나 확정하지 않으면 시간 상태와 파편은 유지된다.

## 5. 시간 가속

- 시간 가속을 선택하면 가상 시침이 현재 위치에서 한 칸 앞으로 이동한다.
- 확정하면 실제 시침이 가상 시침의 위치로 한 칸 이동한다.
- 이동한 눈금이 다른 시간대에 속하면 확정 즉시 해당 시간대로 변경한다.
- 시간 가속을 사용한 턴도 전투 행동이 끝나면 일반 시간 진행이 발생하므로 시침이 다시 한 칸 앞으로 이동한다.

## 6. 시간 정지

- 시간 정지를 선택하면 가상 시침은 현재 위치에 머문다.
- 확정해도 실제 시침의 위치와 현재 시간대는 즉시 바뀌지 않는다.
- 시간 정지를 확정한 턴에는 전투 행동이 끝난 뒤 발생하는 일반 시간 진행을 한 번 막는다.
- 정지된 시간대의 연속 체류 횟수는 다음 턴에 1 증가한다.
- 시간 정지 상태는 해당 턴 종료 후 해제된다.

## 7. 시간 역행

- 시간 역행을 선택하면 가상 시침이 현재 위치에서 한 칸 뒤로 이동한다.
- 확정하면 실제 시침이 가상 시침의 위치로 한 칸 이동한다.
- 1번째 눈금에서 역행하면 12번째 눈금으로 이동한다.
- 이동한 눈금이 다른 시간대에 속하면 확정 즉시 해당 시간대로 변경한다.
- 시간 역행을 사용한 턴도 전투 행동이 끝나면 일반 시간 진행이 발생한다.

## 8. 시간대 효과

시간대 효과는 기존 프로토타입의 임시 규칙을 그대로 사용한다.

### 현재

- 각성자 타입의 일반 공격과 스킬 피해가 연속 체류 횟수에 따라 `1.2^횟수`만큼 증가한다.
- 모든 캐릭터의 치명타 피해율이 20%p 증가한다.

### 미래

- 기술자 타입의 일반 공격과 스킬 피해가 연속 체류 횟수에 따라 `1.2^횟수`만큼 증가한다.
- 모든 캐릭터의 이동력이 1 증가한다.

### 과거

- 계승자 타입의 일반 공격과 스킬 피해가 연속 체류 횟수에 따라 `1.2^횟수`만큼 증가한다.
- 모든 캐릭터의 일반 공격 피해가 5 증가한다.

시간대 효과는 아군과 적군 모두에게 적용한다.

## 9. 전투 HUD

- 일반 전투 화면의 시간 관련 HUD에는 회중시계와 현재 시간 파편량만 표시한다.
- 기존 시간 억제 버튼과 억제 예약 표시는 제거한다.
- 회중시계를 누르면 전투 화면을 어둡게 처리하고 중앙에 확대 회중시계를 표시한다.
- 시간 조작 화면이 열려 있는 동안 전투판 입력을 차단한다.
- 시간 조작 화면에는 확대 회중시계, 현재·최대 파편, 현재 조작 비용, 시간 가속·정지·역행 버튼과 확정 버튼을 표시한다.
- 파편이 부족하거나 이번 턴에 이미 시간 조작을 확정했다면 조작 버튼을 비활성화한다.

## 10. 조작 미리보기와 연출

- 시간 가속·정지·역행 중 하나를 누르면 실제 시침과 구분되는 가상 시침을 표시한다.
- 가상 시침은 선택한 조작의 도착 눈금과 도착 시간대를 미리 보여준다.
- 시간 가속과 시간 역행의 가상 시침은 한 칸 이동하는 방향으로 움직인다.
- 시간 조작 버튼을 누를 때 확대 회중시계가 가볍게 흔들린다.
- 확정 버튼을 누르면 회중시계 주변에 마법 오라가 발생한다.
- 오라가 재생되는 동안 실제 시침, 현재 시간대, 보유 파편과 다음 조작 비용을 갱신한다.
- 조작 확정 연출이 끝나면 시간 조작 화면을 닫고 전투 계획 화면으로 돌아간다.
- 동작 감소 설정이 활성화된 환경에서는 흔들림과 오라 재생 시간을 줄인다.

## 11. 이번 실험에서 제외한 기능

- 시간 파편 획득량 증가 유물
- 시간 파편 최대 저장량 증가 유물
- 과열 비용 감소 또는 초기화
- 시간 조작 비용의 상한
- 시간 조작 전후의 아군·적군 피해 결과 비교
- 시간대별 배경과 BGM 전환
- 기존 프로토타입 및 확정 기획으로의 병합

## 12. 현재 구현상 한계

- 조작 비용은 50에서 시작해 확정할 때마다 5씩 계속 증가한다.
- 최대 저장량은 80으로 고정되어 있으므로 조작 비용이 85가 되면 더 이상 시간 조작을 사용할 수 없다.
- 가속과 역행은 확정 즉시 현재 턴의 시간대를 바꾸지만, 해당 턴 종료 시 정지가 아니라면 일반 시간 진행도 추가로 발생한다.
- 시간대 효과와 파편 획득량은 실험용 임시 수치이며 확정 기획 수치가 아니다.

## 13. 검증 상태

- TypeScript 검사와 Vite 프로덕션 빌드를 통과했다.
- 단일 파일 실행본 `standalone/index.html`을 생성했다.
- 브라우저에서 6×6 전투 계획 화면까지 진입했다.
- 일반 HUD에 시계와 `0/80` 파편량만 표시되는 것을 확인했다.
- 시계 클릭 시 배경 딤 처리와 중앙 확대 시계가 표시되는 것을 확인했다.
- 테스트 중 임시로 파편을 채워 시간 가속 선택, 가상 시침 미리보기, 확정 후 파편 50 차감과 다음 비용 55 적용을 확인한 뒤 시작 파편을 0으로 복구했다.
- 시간 정지와 시간 역행의 다회차 실전 사용은 추가 플레이테스트가 필요하다.

## 14. 실험 판정 기준

- 플레이어가 유리한 시간대를 만들기 위해 시간 파편을 실제로 사용하는가.
- 가속·정지·역행이 서로 다른 전술적 목적으로 선택되는가.
- 가상 시침만 보고 확정 후 적용될 시간대를 이해할 수 있는가.
- 최대 저장량 80과 5씩 증가하는 비용이 사용 시점을 고민하게 만드는가.
- 비용이 80을 넘은 뒤 영구적으로 사용할 수 없게 되는 구조가 전투 길이에 적합한가.
- 확대 시계가 전투 계획을 방해하지 않으면서 중요한 선택으로 느껴지는가.
