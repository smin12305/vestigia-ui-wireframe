## 1. 유물 작성 문법

- [공통 자료형 규칙](Waredo_2.0_기획_조정값_통합표.md#공통-자료형-규칙): 유물 ID·효과 번호는 int, 이름·설명은 string, 등급·면역 태그·트리거·연산은 enum, 보정 수치는 float다. 유물 ID와 효과 표의 참조 ID는 같은 정수를 사용한다.

- 콘텐츠 기획이 필요한 경우 아래 문법에 따라 기획한다.

```text
유물: <relicName>
ID: <relicId:int>
등급: <일반 | 희귀 | 영웅 | 전설>
설명: <relicDescription>
효과: <공격력 | 이동력 | 최대체력 | 쿨타임 | 상태이상면역태그 | 충돌데미지 | 시간파편획득량 | 최대시간파편저장량> | 공격력적용: <일반공격 | 스킬 | 둘다 | 없음> | 면역태그: <상태이상 태그 enum 또는 없음> | 트리거: <허용 트리거 또는 없음> | 발동단위: <사건당 | 행동당 | 대상당 | 타격당 | 없음> | 적용: <즉발 | 시간대유지 | 시간대상시 | 전투고정> | 연산: <더하기 | 곱하기 | 빼기 | 비율 | 태그추가> | 수치: <relicEffectValue 또는 없음> | 최대중첩: <maxStackCount:int 또는 없음>
```

- 작성 규칙:

- 시간대유지 효과는 `최대중첩`에 1 이상의 int를 반드시 작성한다. 다른 적용 방식은 `없음`으로 작성한다. 동작·상한·연산·초기화의 단일 원본은 유물 4-3-3-1이다. 현재 중첩 수는 전투 상태이므로 콘텐츠에 입력하지 않는다.
- Instant 신규 작성·사용을 보류하지 않는다. 적용계산·적용시점·종료시점을 작성하고 미결정 시 [FSM 정의 후 결정]으로 남긴다. 수치 4종의 시간대유지는 작성 권장안이며 Instant 금지나 의무가 아니다.

- `유물`, `ID`, `등급`, `설명`, `효과`를 작성한다.
- `등급`은 `일반`, `희귀`, `영웅`, `전설` 중 하나만 작성한다.
- 한 유물에 효과가 여러 개라면 `효과` 줄을 반복한다.
- `효과`는 `공격력`, `이동력`, `최대체력`, `쿨타임`, `상태이상면역태그`, `충돌데미지`, `시간파편획득량`, `최대시간파편저장량` 중 하나를 작성한다.
- `공격력` 효과는 `공격력적용`에 `일반공격`, `스킬`, `둘다` 중 하나를 작성하며 각각 `NormalAttack`, `Skill`, `Both`에 대응한다. `스킬`은 일반 스킬과 궁극기를 모두 포함한다.
- 공격력 이외 효과는 `공격력적용: 없음`으로 작성한다.
- `상태이상면역태그` 효과는 `면역태그`에 추가할 상태이상 태그 enum를 작성하고 `연산: 태그추가 | 수치: 없음`으로 작성한다.
- 상태이상 면역 태그 이외 효과는 `면역태그: 없음`으로 작성한다.
- 수치 효과의 `연산`은 `더하기`, `곱하기`, `빼기`, `비율` 중 하나를 작성하며 각각 `Add`, `Multiply`, `Subtract`, `Percent`에 대응한다.
- 유물 콘텐츠에는 `시간대`, 캐릭터 시간대 태그, `relicTimeTag`, `relicTimeTags`를 작성하지 않는다.
- 적용 시간대는 콘텐츠가 아니라 유물 배치 관계와 가방 칸 시간대가 결정한다.
- `최대시간파편저장량` 효과는 `트리거: 없음 | 발동단위: 없음 | 적용: 전투고정`으로 작성한다. 배치 칸의 시간대와 관계없이 모든 시간대에 공통 적용하며, 전투 시작 후 종료까지 같은 값을 유지한다.
- `상태이상면역태그`, `충돌데미지`, `시간파편획득량` 효과는 `트리거: 없음 | 발동단위: 없음 | 적용: 시간대상시`로 작성한다. 현재 시간대에 활성화된 동안 원본 시스템이 실제 판정 또는 계산 직전에 효과를 조회한다.
- 충돌데미지 효과는 가방·유물 4-3-4에 따라 Ally가 Enemy 캐릭터에게 주는 요청에만 적용한다.
- 양 진영에서 발생할 수 있는 트리거는 `아군피격`·`적군피격`, `아군공격`·`적군공격`, `아군치명타`·`적군치명타`, `아군기절`·`적군기절`, `아군띄워짐`·`적군띄워짐`처럼 나누어 작성한다. 이외 허용값은 `시간대진입`, `적사망`, `아군사망`, `환경요소파괴`다. `환경요소파괴`는 `EnvironmentDestroyed`에 대응한다.
- 일반 효과의 `발동단위`는 `사건당`, `행동당`, `대상당`, `타격당` 중 하나를 작성한다.
- `적용: 즉발`은 트리거가 성립한 순간 결과를 처리한다.
- `적용: 시간대유지`는 공격력·이동력·최대 체력·쿨타임의 트리거형 효과에 사용하며 해당 시간대에서만 유지한다. 시간대를 벗어나면 제거하고 같은 시간대로 돌아와도 이전 발동 상태를 복원하지 않는다.
- `적용: 시간대상시`는 상태이상 면역 태그, 충돌 데미지, 시간 파편 획득량 효과에만 사용하며 현재 시간대에서 원본 시스템이 판정·계산 직전에 조회하는 효과로 유지한다.
- `적용: 전투고정`은 최대 시간 파편 저장량 효과에만 사용하며 전투 시작 전에 계산한 값을 전투 종료까지 유지한다.
- 캐릭터 대상 유물 효과는 `currentHp > 0`인 전체 아군에게 적용하므로 콘텐츠에 별도 캐릭터 대상 필드를 작성하지 않는다.
- 시간 파편 획득량 효과는 기존 획득 사건의 수치만 변경하며 새 획득 사건을 만들 수 없다.
- 동일 유물은 중복 보유할 수 없지만 서로 다른 유물의 효과는 같은 변경 요소에도 중첩한다. 연산은 유물 시스템 4-3-4의 합연산 후 곱연산 규칙을 따른다. 같은 유물의 유지형 반복 중첩은 유물 시스템 4-3-3-1을 따른다.


### 1.1 표기 기준

- 이 문서 1장은 유물 작성 문법의 단일 원본이다. 동작·예외·판정은 유물 시스템이 소유한다.
- 꺾쇠 안은 작성할 값, 세로선은 항목 구분 또는 허용값 택일이다. 실제 입력에 꺾쇠를 남기지 않는다.
- `없음`은 적용하지 않는 항목이다. 미정 값은 `[작성 필요]`로 구분하고 0이나 없음으로 대체하지 않는다.
- 한 유물은 기본 정보 한 행, 효과는 효과 관리표에 한 줄당 한 행으로 작성한다. 유물 ID로 서로 연결한다.
- 효과 번호는 같은 유물 안에서 줄을 구별하는 작성 번호다. 연산 우선순위가 아니다. 어느 줄에 썼든 합연산 후 곱연산을 따른다.
- 문법은 기획 의미를 통일하기 위한 표기이며 저장 방식·자료구조·기술 명세가 아니다.

### 1.2 트리거 허용값

| `relicTriggerType` | 표시명 |
|---|---|
| `TimePeriodEntered` | 시간대 진입 시 |
| `AllyDamaged` | 아군 피격 시 |
| `EnemyDamaged` | 적군 피격 시 |
| `EnemyDied` | 적 캐릭터 사망 시 |
| `AllyDied` | 아군 캐릭터 사망 시 |
| `AllyAttackPerformed` | 아군 공격 시 |
| `EnemyAttackPerformed` | 적군 공격 시 |
| `AllyCriticalOccurred` | 아군 치명타 발생 시 |
| `EnemyCriticalOccurred` | 적군 치명타 발생 시 |
| `AllyStunned` | 아군 기절 시 |
| `EnemyStunned` | 적군 기절 시 |
| `AllyAirborneApplied` | 아군 띄워짐 시 |
| `EnemyAirborneApplied` | 적군 띄워짐 시 |
| `EnvironmentDestroyed` | 환경요소 파괴 시 |
| `None` | 트리거 없음, `StatusImmunityTag`·`CollisionDamage`·`TimeShardGain`·`MaxTimeShard` 전용 |

- 문법에는 시간대진입·아군피격·적군피격·적사망·아군사망·아군공격·적군공격·아군치명타·적군치명타·아군기절·적군기절·아군띄워짐·적군띄워짐·환경요소파괴·없음을 사용한다.
- 피격은 실제 캐릭터 피해 1 이상, 공격은 일반 공격·스킬 공격·반격을 포함한다. 충돌은 공격 트리거가 아니다.
- 환경요소는 파괴만 트리거다. 환경요소 공격·피격을 캐릭터 공격·피격으로 세지 않는다.
- 발동 단위는 사건당(Event)·행동당(Action)·대상당(Target)·타격당(Hit) 중 선택한다. 상시 효과만 없음(None)을 쓴다.
- 시간대 초기화를 최초 진입 트리거로 셀지는 보류다. 사건의 자세한 성립 조건은 유물 시스템 4-3-3을 따른다.

### 1.3 효과 조합 확인표

- [확정·FSM 후 재검토] Instant 효과 행에는 적용계산·적용시점·종료시점을 명시한다. 아직 값이 결정되지 않은 콘텐츠는 각각 [FSM 정의 후 결정]으로 작성하고 구현 준비 완료로 판정하지 않는다.
- 문법 확장: 즉발 효과 줄 뒤에 ‘적용계산: <대상 계산 또는 [FSM 정의 후 결정]> | 적용시점: <시점 또는 [FSM 정의 후 결정]> | 종료시점: <시점 또는 [FSM 정의 후 결정]>’을 작성한다. 이는 기획 항목의 추가이며 실행 enum 확정이 아니다.
- Cooldown의 적용계산은 최대 쿨타임 계산이다. 남은 쿨타임 직접 감소나 원본 데이터 변경으로 해석하지 않는다. 현재 공격 전/후 적용 여부와 소비·종료 경계는 FSM 정의 후 확정한다.
- 피격 트리거는 발동단위: 타격당으로 작성한다. 실제 피해 1 이상인 대상별 피격 횟수이며, 기타 단위와 보정 반영 시점은 유물 4-3-3을 따른다.
- 최대시간파편저장량은 감소 연산을 허용하지 않는다. Add≥0, Multiply≥1, Percent≥0만 사용하며 Subtract는 제외한다.

| 변경 요소 | 공격력 적용 | 면역 태그 | 트리거·발동 단위 | 적용 방식 | 연산·수치 |
|---|---|---|---|---|---|
| 공격력 | 일반공격 / 스킬 / 둘다 | 없음 | 허용 사건 + 발동 단위 | 즉발 / 시간대유지 | 더하기 / 곱하기 / 빼기 / 비율 + 수치 |
| 이동력·최대체력·쿨타임 | 없음 | 없음 | 허용 사건 + 발동 단위 | 즉발 / 시간대유지 | 더하기 / 곱하기 / 빼기 / 비율 + 수치 |
| 상태이상면역태그 | 없음 | 정의된 상태 태그 1개 | 없음·없음 | 시간대상시 | 태그추가·없음 |
| 충돌데미지·시간파편획득량 | 없음 | 없음 | 없음·없음 | 시간대상시 | 더하기 / 곱하기 / 빼기 / 비율 + 수치 |
| 최대시간파편저장량 | 없음 | 없음 | 없음·없음 | 전투고정 | 더하기 ≥0 / 곱하기 ≥1 / 비율 ≥0 |

- 추가 면역 태그는 캐릭터·상태이상 시스템의 Airborne·Stun·Push·Pull 정의와 연결한다. 여러 태그를 추가하려면 효과 줄을 나누어 작성한다.
- 수치 범위·반올림·최종 제한은 변경 대상의 원본 규칙을 따른다. 등급만으로 효과 수치·효과 개수·발동 확률을 자동 부여하지 않는다.

## 2. 기획 시 유의사항

- 동일 유물은 중복 획득·보유할 수 없다. 서로 다른 유물이 같은 공격력 등을 올리는 효과는 조건을 만족하면 모두 중첩한다.
- 더하기·빼기 합연산을 모두 반영한 뒤 비율·곱하기 배율을 적용하고 최종 결과만 반올림한다. Percent 20은 +20%다. 같은 계층의 비율 합산 및 원본 하한·상한은 유물 시스템 4-3-4를 따른다.
- 공격력의 일반공격·스킬·둘다를 반드시 구별한다. 스킬에는 일반 스킬·궁극기가 포함된다. 회복도 피해 보정을 받되 각 효과의 적용 조건은 유지한다.
- 캐릭터 대상 효과는 생존한 전체 아군에 적용한다. 임의로 단일 아군·적군 대상 선택 항목을 추가하지 않는다.
- 면역 태그 추가 시 해당 기존 상태이상을 즉시 제거한다. 면역 해제 시 제거했던 상태를 복원하지 않는다. 이미 처리된 강제 이동을 되돌리는 기능이 아니다.
- 충돌 피해 보정은 아군이 적 캐릭터에게 주는 요청만 변경한다. 밀치기 충돌은 시전자 진영으로 판단하며, 유물마다 이 규칙을 다르게 작성하지 않는다.
- 환경요소 파괴 기본 시간 파편 5는 시간대 시스템의 기본 보상이다. 모든 유물의 효과 행에 중복 작성하지 않는다. 시간파편획득량 효과는 기존 지급량만 보정한다.
- 유물 고유 시간대는 없다. 적용 시간대는 배치 칸에서 결정한다. 최대 시간 파편 저장량은 모든 칸의 효과를 합쳐 모든 시간대에 공통 적용하며 전투 중 바뀌지 않는다.
- 유물 배치·해제·이동은 전투 밖에서만 가능하다. 배치 상태·발동 횟수·현재 보정 결과는 이 콘텐츠 표에 입력하지 않는다.
- 시간대 유지형 효과는 시간대 이탈 시 제거하며 재진입 시 이전 발동 상태를 복원하지 않는다.
- 동일 유물 유지형 효과는 유효 발동마다 1중첩을 추가하고 효과별 최대중첩에서 제한한다. 시간대 이탈 시 초기화한다. 세부 계산은 유물 4-3-3-1을 따른다.
- 가상 전투에서는 유물 발동·면역·보정 결과도 가상 상태에만 적용한다. 실제 유물·캐릭터·파편 상태를 변경하지 않는다.
- 표시 설명과 효과 행의 대상·발동·연산·수치가 다르면 콘텐츠 검토를 완료하지 않는다.

## 5. 작성 완료 점검
