# 클로이·야나 확정 승격 및 자체 검수

> 날짜: 2026-09-13 · 검수자: 주 작업자
> 범위: 클로이·야나 콘텐츠와 연결된 공통 규칙, 신규 인덱스
> 사용자 요청에 따라 에이전트 연결 없이 자체 검수했다. 참고 문서 관리·검수 규칙 자체는 `[제안]` 상태다.

## 1. 결과

- 클로이: 콘텐츠 수치·조건·문법 자체 검수 완료. 확정 콘텐츠로 이동.
- 야나: 확정 콘텐츠로 이동. 일반 공격 전달 방식이 미정이므로 검수 상태 `[수정 필요]` 유지. 지정된 수치·회복 효과에서 사용자 결정 누락은 발견하지 않았다.
- 인덱스: 기존 작성 순서를 기준으로 캐릭터 5개·일반 공격 5개·스킬 10개에 번호를 부여했다. 기존 영문 ID를 교체하지 않았다.
- 공통 시스템 전체 QA나 실제 게임 실행·밸런스 검수가 아니다. 기존 시스템 QA의 미해결 항목은 이번 승격으로 해결 처리하지 않는다.
