## 4. 문법·조정값 정리 검토

- 문법 원본은 관리표 상단 하나로 모으고 캐릭터의 기존 절 번호는 참조 절로 유지했다.
- 캐릭터·일반 공격·스킬을 ID로 연결하고 스킬 효과는 순서별 행으로 분리했다. 궁극기를 별도 문법으로 중복 정의하지 않았다.
- 수치 효과의 피해·회복 용도를 수치 옆에 배치했다. 실제 콘텐츠 수치를 임의 입력하지 않았다.
- 현재 체력·남은 쿨타임·실제 위치·최종 보정값·시뮬레이션 결과는 콘텐츠 입력 열에서 제외했다.
- 범위·대상·발동·지속은 기능 조건이므로 삭제하지 않았다. 새로운 자유 조정값과 기존 고정 규칙을 구별했다.
- 기존 6개 원문 239개 섹션 비교는 [검토 폴더](검토/)의 최초 이력이다. 이번 검토 결과와 혼동하지 않는다.
- 후속 결정 대조: 합연산 후 곱연산은 기존 합산 비율 계층을 유지하고 Multiply 배율을 최종 반올림 전에 반영한다. 캐릭터와 유물이 동일 보정을 두 번 적용하지 않는다. 면역은 해당 상태만 제거하며 밀치기·당기기로 이미 이동한 위치는 되돌리지 않는다.
- 후속 수정 및 로컬 인수인계는 [후속 수정 기록](후속_수정_기록.md)을 따른다. 남은 항목 때문에 전체 정합성 PASS 또는 구현 준비 완료로 판정하지 않는다.
