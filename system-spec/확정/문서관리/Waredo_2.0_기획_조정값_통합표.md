# 기획 조정값 통합표

> 결정 상태: [제안] · 2026-09-12 · 임시 시스템 7종의 조정값·조건 색인
> 원본 수치·규칙은 각 시스템에 둔다. 이 표는 찾아보기용이며 두 번째 수치 원본이 아니다.
> 콘텐츠 입력: [캐릭터·스킬·공격 관리표](Waredo_2.0_캐릭터_스킬_공격_관리표.md)
> 유물 입력: [유물 문법·관리표](Waredo_2.0_유물_문법_관리표.md)

## 정리 기준

- 공격력·이동력·최대 체력·쿨타임을 구체적으로 구분한다. 같은 뜻의 이름을 새 변수로 늘리지 않는다.
- 수치뿐 아니라 발동 조건·효과 대상·범위·지속 규칙도 연결한다. 고정 규칙을 자유 선택 항목으로 바꾸지 않는다.
- 원본은 기획자가 입력할 값, 상태는 전투 중 변하는 값, 파생은 원본과 상태로 계산하는 값이다. 상태·파생은 콘텐츠 표에서 제외한다.
- 아래 수치는 현재 원본의 요약이다. 수정 시 원본을 먼저 바꾸고 이 표를 갱신한다. 미정 값·수식은 추정하지 않는다.
- 숫자 없는 효과도 불필요한 수치·확률·지속 턴을 새로 만들지 않는다. 셀 패턴 ID는 좌표 정의를 대신하지 않는다.


## 통합 범위·분류 연결

- [통합 범위 데이터](../시스템/Waredo_2.0_통합_범위_데이터_시스템.md)가 범위 ID·좌표·그림의 원본이다. ID 9는 빈 범위 데이터이며 null·0이 아니다.
- contentType·attackDeliveryType은 [작성 문법](Waredo_2.0_캐릭터_스킬_공격_관리표.md#분류와-공격-전달-방식)의 enum을 따른다.

## 공통 자료형 규칙

- 고정형 능력치 보정(flatMaxHpBonus·flatMoveRangeBonus·flatCooldownMaxBonus 포함)은 float다. int 원본 수치와 구별하고 정수 결과를 요구하는 최종 계산에서만 한 번 반올림한다. 경계값·하한 적용은 캐릭터 4-1-2-3을 따른다.

> 이 절은 2026-09-13 사용자 요청으로 정리한 자료형·ID 기준이다. 기능 수치·적용 순서·반올림 규칙은 각 시스템 원본을 따른다.

- ID의 실제 입력은 따옴표 없는 정수다. `CHARACTER 1 "아이작"`, `SKILL 3 "밀치기 사격"`, `RANGE_PATTERN 2`처럼 작성한다.
- 정의 종류가 다르면 같은 번호를 쓸 수 있다. `actionId`는 `mainActionType`과 함께 일반 공격/스킬 중 어느 정의를 참조하는지 구분한다.
- `NONE`은 태그·효과·전달 방식의 명시적인 없음 enum에 사용한다. 범위 ID의 없음은 등록 ID 9다. 범위 외 선택 ID의 기존 0 규칙은 유지하고 미정·참조 오류는 없음으로 바꾸지 않는다.
- ID가 등록돼 있어도 연결된 콘텐츠의 미정 조건은 해결되지 않는다. 필수 ID 누락·중복·참조 실패는 각 시스템의 기존 유효성 검사와 실패 처리를 따른다.
- 목록·관계 표기는 의미를 설명하며 특정 저장 자료구조를 강제하지 않는다.

### 정의 ID와 전투 개체 ID

- `characterId: int`는 캐릭터 콘텐츠 정의를 가리킨다.
- `characterInstanceId: int`는 전투에 실제 참가한 개체를 가리킨다. 같은 정의를 참조해도 참가 개체마다 구별하며 전투 중 번호를 유지한다.
- 현재 체력·상태·계획·행동 슬롯·반격 대상·점유는 전투 개체에 연결하고, 기본 능력·공격·스킬은 그 개체의 `characterId`로 조회한다.
- `effectSourceCharacterInstanceId`·`effectTargetCharacterInstanceId`·`counterTargetInstanceId`·`counterTriggeredTargetInstanceIds`는 전투 개체 ID를 사용한다.
- 시뮬레이션에서는 동일 개체 대응을 유지하면서 상태만 가상으로 처리한다. 실제 상태에 결과를 덮어쓰지 않는다.

### 남겨야 할 값과 정리한 값

- 중복 표시 인덱스를 제거한다. 콘텐츠는 int ID와 contentType(ATTACK / SKILL / ULTIMATE)으로 관리한다.
- 일반 공격력은 `normalAttackValue`, 스킬 공격력은 `numericEffectValue`가 원본이다. 회복 용도는 효과 종류로 구분한다.
- 현재 체력·남은 쿨타임·현재 위치·활성 스킬·보정 결과·면역 판정은 콘텐츠 원본 입력에서 제외한다.
- 아이작 기존 문법의 `DAMAGE`는 int 피해 수치, `CAN_CRITICAL`은 기존 호환 표기다. 이번 자료형 정리가 치명타 조건을 변경하지 않는다.
- 아직 정하지 않은 확률·지속시간·중첩 정책·콘텐츠 수치에 기본값을 새로 부여하지 않는다.

## 사용 전 확인

- 콘텐츠마다 실제 수치·범위·대상·발동을 작성하되 원본의 하한·예외를 지킨다.
- 기존 영문명은 연결 검색을 위해 유지한다. 한국어 설명을 중복 원본 변수로 추가하지 않는다.
- [연결성 검토](Waredo_2.0_연결성_검토.md)의 미해결 항목이 관련된 콘텐츠는 검토 완료로 올리지 않는다.
