## 4. 실행·기획 유의사항

- 일반 공격과 타락의 심판의 명칭·범위·피해·관통·기절·쿨타임은 v5 프로토타입 구성을 옮겼다.
- 타락의 심판은 보스 현재 셀을 중심으로 십자 범위를 펼치며 보드 밖 셀은 실제 대상에서 제외한다.
- 피해 10을 먼저 적용한 뒤 살아 있는 피격 대상에게 기절을 적용한다. 기절 면역이면 기절만 실패한다.
- 기절은 대상의 다음 행동을 취소하지만 상태 기반 치명타 조건은 아니다.
- 프로토타입의 스킬 자체 `치명타 불가`는 현재 확정 콘텐츠 문법에 대응 입력이 없다. 대상에게 띄워짐이 적용돼 있으면 공통 규칙상 치명타가 될 수 있으므로 원본 유지 방법을 검수에서 결정해야 한다.
- 별도 보스 페이즈·복수 행동은 이번 콘텐츠에 추가하지 않는다.

## 5. 작성·확인 필요

- 캐릭터·공격·스킬 ID 11·11·16의 최종 등록 여부.
- `십자폭3_3`의 정확한 상대 좌표와 신규 정수 범위 ID 등록.
- 프로토타입의 치명타 불가를 확정 시스템에 추가할지, 상태 기반 치명타를 허용할지 결정.
- 프로토타입 능력치 HP 100·이동력 5·면역 없음과 제안 능력치 HP 280·이동력 2·PUSH/PULL 면역 중 최종안 결정.
- 보스 분류에 따른 별도 행동·승패·페이즈 규칙은 보스 시스템 기획 시 결정.
