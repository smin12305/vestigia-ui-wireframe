## 시스템 브리핑

- 환경요소는 레벨디자인 테이블에서 사전에 제공한 배치에 따라 전투판의 셀을 점유하는 나무 박스와 바위다. 캐릭터가 해당 셀에 진입하려 하면 충돌 피해를 받고 이동을 멈춘다.
- 나무 박스는 피해량과 관계없이 피격 시 파괴된다. 바위는 피해를 받아도 파괴되지 않는다. 둘 다 직사 공격에 캐릭터처럼 맞는다. 비관통 직사는 박스에서 끝나지만 관통은 박스를 통과할 수 있다. 바위는 관통도 차단한다.
- 환경요소의 종류·파괴 판정은 이 문서가 소유한다. 셀 점유·충돌 피해는 전투판, 이동·공격 실행은 전투, 공격 정의는 캐릭터 시스템을 참조한다. 레벨디자인 테이블은 실제 배치 위치를 제공한다.
- 개별 환경요소와 배치 정보는 문서 하단 콘텐츠 기획 문법에 따라 작성한다. 저장 방식·기술적 처리 수단은 지정하지 않는다.

## 유의사항

- 우선순위는 이번 사용자 결정 → 임시 연계 문서 → 작성 프롬프트다. 확정 원본과 프로토타입 코드는 변경하지 않는다.
- 이 문서는 나무 박스·바위만 다룬다. 화염 지대·회복 셀·설치형 효과 등은 전투 문서에 예시가 있어도 이번 콘텐츠로 추가하지 않는다.
- 캐릭터와 같은 방식으로 직사 공격에 맞는다는 설명은 피격·차단에 한정한다. 환경요소에 캐릭터의 진영·공격력·이동력·최대 체력·쿨타임·태그를 자동 부여하지 않는다.
- 나무 박스에 임의의 체력·내구도·파괴 확률을 만들지 않는다. 바위에 무한 체력을 부여하지도 않는다. 두 종류의 차이는 피해에 대한 파괴 규칙이다.
- 전투판의 기존 내구도 참조는 이번 두 종류에 대해 이 문서의 파괴 규칙 참조로 정리한다. 충돌 기본 피해는 전투판의 `collisionBaseDamage`를 참조하며 별도 환경요소 충돌 피해를 만들지 않는다.
- 충돌 피해 유물 보정은 아군 가해 판정인 요청에만 적용한다. 밀치기 충돌의 가해 진영은 밀친 시전자 진영으로 정하며 임시 전투판·유물 문서에 함께 반영했다. 확정 원본은 변경하지 않는다.
- 이전 요청대로 사진은 넣지 않고 비교표와 번호 순서로 설명한다. 상단 미결정 항목은 관련 범위를 구현 기준으로 사용하기 전에 확인한다.

# 1. 기획 의도

- 매 판 다른 전투 환경을 통해 단조로운 전투에 변화를 준다.
- 전투판이 작아진 만큼 환경요소의 과도한 개입을 막고 맵이 답답하게 느껴지지 않도록 환경요소 배치를 최소화한다.

# 2. 개발 목적

- 레벨디자인에서 제공한 배치를 전투판의 셀 점유와 일치시킨다.
- 두 종류의 공통 차단 규칙과 서로 다른 파괴 결과를 일관되게 처리한다.
- 점유·충돌·피격·파괴의 소유 시스템을 구분하고 동일한 규칙을 중복 정의하지 않는다.

## 2.1 시스템 개요: 어떤 시스템인가

- 전투판에 미리 배치된 장애물과 캐릭터의 이동·공격이 상호작용하는 시스템이다. 사용자는 현재 남아 있는 박스와 바위를 보고 경로와 공격을 정하며, 실행 결과에 따라 박스가 사라지거나 장애물이 유지된다.

## 2.2 사용자가 한 사이클 동안 하는 일

1. 레벨디자인 테이블에 따른 나무 박스·바위 배치가 전투판에 반영된다.
2. 사용자가 환경요소의 위치를 보고 이동·공격을 계획한다.
3. 실행 중 환경요소와 이동 충돌 또는 직사 피격이 발생하면 해당 규칙을 적용한다.
4. 박스가 피격되어 파괴되면 점유를 해제한다. 바위는 계속 점유한다.
5. 이후 행동은 변경된 전투판을 기준으로 판정한다. 이미 충돌로 종료된 이동을 박스 파괴 때문에 재개하지 않는다.

## 2.3 핵심 작동 방식

- 존재하는 동안 두 종류 모두 셀을 점유하고 캐릭터 진입을 막는다. 직사는 박스에서 종료하되 관통 공격은 박스를 통과할 수 있으며, 바위에서는 관통도 종료한다.
- 충돌에서는 캐릭터의 이동 종료와 환경요소의 파괴 여부가 별도 결과다. 박스가 파괴되어도 그 충돌로 멈춘 이동은 종료된 상태다.
- 박스 파괴는 해당 요소의 점유와 차단을 해제한다. 박스를 파괴한 비관통 직사 공격은 그 박스에서 종료한다. 관통 공격은 박스를 파괴하고 계속 진행할 수 있다.
- 바위는 직사 공격을 막지만 파괴되지 않는다. 기존 전투판 충돌 규칙상 바위에는 충돌 피해를 적용하지 않고 접근 캐릭터에게만 적용한다.

## 2.4 실제 처리 예시

| 상황 | 결과 |
|---|---|
| 캐릭터가 박스가 점유한 셀로 이동 시도 | 충돌로 이동 종료. 캐릭터와 파괴 가능한 박스에 충돌 피해 요청. 박스가 피격되면 파괴·점유 해제. 캐릭터의 이동은 재개하지 않음 |
| 캐릭터가 바위가 점유한 셀로 이동 시도 | 충돌로 이동 종료. 캐릭터에게 충돌 피해. 바위는 그대로 남고 계속 점유 |
| 직사 공격이 박스에 맞음 | 박스가 공격을 받아 차단. 피격만으로 파괴·점유 해제. 비관통 직사는 그 자리에서 끝나며 관통 공격은 통과 가능 |
| 직사 공격이 바위에 맞음 | 바위가 관통 여부와 관계없이 공격을 차단하고 파괴되지 않음 |

## 2.5 시스템이 직접 정의하는 것

- 환경요소: 종류, 피격에 따른 파괴 여부, 환경요소의 존재·파괴 상태, 직사 피격·차단 성질.
- 레벨디자인 테이블: 전투별 환경요소 종류와 배치 셀. 실제 테이블은 `[작성 전]`이다.
- 전투판: 유효 좌표, 단일 셀 점유, 충돌 발생·피해 대상·기본 피해, 제거 시 점유 해제.
- 전투·캐릭터: 이동·공격 실행과 공격 정의·피해 산출. 상태이상: 강제 이동 경로·정지 셀.
- 전투 시뮬레이션: 가상 환경 변화만 재현하고 실제 환경요소·점유는 유지한다.

### 4-1-1. 배치·정의

#### 사용 변수·용어

#### 목적·입력·처리·출력

- 목적: 사전 배치를 전투판에 연결하고 각 환경요소의 종류와 상태를 제공한다.
- 입력: 레벨디자인 테이블의 배치 목록. 각 배치에는 종류와 배치 셀이 필요하다.
- 처리: 전투판이 허용하는 셀에 환경요소를 배치하고 해당 셀의 점유를 요청한다. 한 셀에 환경요소 하나가 점유하며 캐릭터와 중복 점유하지 않는다.
- 출력: 전투판의 점유 결과, 배치된 요소의 종류·존재 상태·파괴 불가 여부.
- 초기 상태: 유효하게 배치된 박스와 바위는 존재한다. 종류로 정해지는 점유·차단·파괴 성질을 배치 행마다 다시 조정하지 않는다.
- 예외: 유효하지 않거나 이미 점유된 셀에 덮어쓰지 않는다. 범위 밖 좌표·중복 점유 등 잘못된 배치만 제외하고 나머지 유효 배치로 진행한다. 기존 점유는 유지하며 이 오류만으로 전투 진입을 막지 않는다.

### 4-1-2. 피격·파괴

- 비관통 직사의 ‘박스에서 종료’는 박스를 맞힌 개별 타격에만 적용한다. 다음 피해 효과·다음 사격은 갱신된 점유와 차단을 다시 조회한다. 첫 타격으로 박스가 파괴되었다면 다음 타격은 범위 안 뒤쪽 적에게 도달할 수 있다. 바위가 남아 있으면 계속 차단한다.
- 현재 전달 방식 지원: DIRECT는 기존 직사·관통·박스·바위 차단을 적용한다. AREA는 영향 범위 내 셀에 직접 효과를 적용하고 중간 박스·바위의 사선 차단을 검사하지 않는다. 환경요소 자체가 영향 셀 안에 있으면 기존 피격·파괴 규칙을 적용한다. NONE은 공격 전달을 하지 않는다. 별도 곡사·투사체 궤적·높이·엄폐 규칙이 필요한 콘텐츠는 후속 기획 전까지 지원 대상으로 등록하지 않는다.

#### 사용 변수·용어

| 변수·용어 | 의미 | 자료형·값 형태 | 소유·성격 |
|---|---|---|---|
| `environmentType`·`environmentState` | 대상 종류와 존재 상태 | 종류·상태 | 배치·정의·참조 |
| 피격·피해 결과 | 공격이 환경요소에 닿았는지와 적용되는 피해 결과 | 판정·피해량 | 전투 > 공격·스킬 실행 또는 전투판 > 충돌·참조 |
| 파괴 | 환경요소가 사라져 더 이상 점유·차단하지 않는 결과 | 결과 | 이 모듈의 판정, 배치·정의의 상태 및 전투판의 점유 갱신으로 연결 |

#### 목적·입력·처리·출력

- 목적: 환경요소의 직사 피격·차단과 파괴 결과를 결정한다.
- 입력: 존재하는 환경요소에 대한 공격의 피격 판정 또는 충돌 피격. 피해량이 0이어도 피격이 성립하면 박스 파괴를 처리한다.
- 직사 차단: 비관통 직사 공격은 나무 박스를 파괴해도 그 박스에서 끝난다. 관통 공격은 나무 박스에 피격·파괴를 적용한 뒤 통과할 수 있다. 바위는 관통 공격도 차단하며 파괴되지 않는다.
- 나무 박스: 공격 방식과 피해량에 관계없이 피격이 성립하면 파괴한다. 피해량 0도 포함하며 체력·내구도 임계치를 두지 않는다. 충돌 피격도 같은 파괴 규칙을 따른다.
- 바위: 피해를 받아도 파괴하지 않으며 점유·차단을 유지한다. 직사 피격·차단 대상에서 제외한다는 뜻이 아니다.
- 출력: 공격 차단 결과와 파괴 여부. 파괴되면 존재 상태를 파괴로 바꾸고 전투판에 해당 환경요소의 점유 해제를 요청한다.
- 이후 판정: 파괴된 요소는 더 이상 이동 충돌·직사 차단 대상으로 취급하지 않는다. 뒤따르는 행동은 갱신된 점유 상태를 참조한다.
- 실패·예외: 이미 파괴된 요소에 다시 피해 요청이 도달해도 새 파괴나 점유 해제를 중복 발생시키지 않는다. 상태이상·강제 이동·회복 효과는 적용하지 않는다.

- 대상 지정: 나무 박스·바위는 직사뿐 아니라 근접·곡사·광역 등 일반 공격·스킬의 대상이 될 수 있다. 각 공격의 사거리·범위·지정 조건은 유지한다. 환경요소를 아군·적군 캐릭터로 간주하지 않고 환경요소 대상임을 구분한다.
- 효과별 처리: 상태이상과 강제 이동은 받지 않으며 회복은 효과가 없다. 회복·상태이상·강제 이동만 전달된 것을 박스 파괴용 공격 피격으로 간주하지 않는다. 같은 공격의 피격은 처리하되 함께 있는 무효 효과만 적용하지 않는다.
- 트리거 구분: 환경요소에 대해서는 파괴 트리거만 발생한다. 환경요소를 공격하거나 환경요소가 피격·충돌한 사실은 기존 캐릭터용 공격·피격 트리거에 해당하지 않는다. 같은 행동이 실제 캐릭터에도 영향을 주었다면 캐릭터 쪽 사건은 기존 규칙으로 별도 판정한다.
- 시간 파편: 환경요소 1개가 실제로 파괴될 때 기본 시간 파편 5를 획득한다. 지급량의 단일 원본은 [시간대 전환](Waredo_2.0_시간대_전환_시스템_기획서.md) 4-2의 `environmentDestroyedShard`다. 현재 시간대 지급·유물 획득량 보정·최대 저장량 제한은 기존 공통 규칙을 따른다. 파괴되지 않은 바위나 잘못된 배치 제외에는 지급하지 않는다.
- 파괴 사건: 존재하던 환경요소가 파괴로 바뀔 때 `EnvironmentDestroyed`(환경요소 파괴) 트리거를 전달한다. 같은 요소의 파괴는 한 번만 발생하며 바위 피격, 잘못된 배치 제외는 파괴 사건이 아니다. 유물별 발동 단위는 [가방·유물](Waredo_2.0_가방_유물_시스템_기획서.md) 4-3-3을 따른다.

### 4-1-3. 충돌 연계

#### 사용 변수·용어

| 변수·용어 | 의미 | 자료형·값 형태 | 소유·성격 |
|---|---|---|---|
| 접근 캐릭터 | 환경요소의 점유 셀로 진입하려는 캐릭터 | 캐릭터 | 전투판 > 충돌·참조 |
| `collisionBaseDamage` | 보정 전 충돌 피해 | int | 전투판 > 충돌·참조, 이 문서에서 재정의하지 않음 |
| 충돌 피해 결과 | 기본 피해와 적용 가능한 보정을 반영한 결과 | 피해량 | 전투판·가방·유물·참조 |
| `isIndestructibleEnvironment` | 바위인지에 따른 충돌 피해 제외 판정 | bool | 배치·정의에서 산출·참조 |

#### 목적·입력·처리·출력

- 목적: 환경요소 접촉 시 캐릭터 정지·충돌 피해와 환경요소의 파괴를 연결한다.
- 입력: 일반 이동 또는 강제 이동 중 발생한 환경요소 점유 셀 충돌.
- 처리 순서:
  1. 전투판이 점유 셀 충돌을 판정하면 현재 이동을 종료한다. 캐릭터는 환경요소가 있는 셀을 점유하지 않는다.
  2. 접근 캐릭터에 충돌 피해를 요청한다.
  3. 대상이 나무 박스이면 박스에도 충돌 피해를 요청하고, 피격·파괴 모듈이 피격에 따른 파괴를 처리한다.
  4. 대상이 바위이면 기존 전투판 규칙대로 바위의 충돌 피해 요청은 제외한다. 바위는 파괴되지 않고 계속 점유한다.
- 출력: 이동 종료, 캐릭터 충돌 피해와 환경요소의 유지·파괴 결과.
- 순서·예외: 캐릭터와 박스의 피해는 같은 충돌 사건의 결과다. 한쪽 파괴·전투불능이 다른 쪽 피해 요청을 취소하지 않는다. 박스가 파괴돼도 이번 이동은 재개하지 않는다.
- 정확한 정지 위치: 일반 이동은 전투의 이동·경로, 강제 이동은 상태이상의 접촉 경로·정지 셀 규칙을 따른다. ~~여기서 대각선 정지 좌표를 다시 정하지 않는다.~~
- 밀치기로 발생한 충돌의 유물 보정용 가해 진영은 **밀친 캐릭터(밀치기를 발생시킨 시전자)의 진영**으로 판정한다. 아군이 밀쳤다면 `Ally`, 적군이 밀쳤다면 `Enemy`다. 밀려난 캐릭터의 진영과 혼동하지 않는다. 가해 Ally·피해 대상 Enemy인 요청에만 유물 보정을 적용한다.
- 밀친 캐릭터가 없는 일반 이동 충돌 등은 가방·유물의 기존 가해 진영 규칙을 따른다. 이번 결정만으로 당기기까지 밀치기로 취급하지 않는다.
- 이동 이후 주 행동의 가능 여부는 전투 시스템을 따른다. 환경요소와 충돌했다는 이유만으로 주 행동까지 무조건 취소하지 않는다.

### 4-1-4. 콘텐츠 기획 문법·레벨 배치 입력

콘텐츠 기획이 필요한 경우 아래 문법에 따라 기획한다.

- 아래는 기획상의 정의 문법이며 저장 형식이나 기술 명세가 아니다.
- 환경요소 종류는 `environmentType`으로 구분한다. 나무 박스와 바위의 공통·차이 규칙은 아래 두 정의로 관리한다.
- 트리거·대상·효과는 콘텐츠 조정 항목으로 명시하되, 이번 두 종류의 값은 사용자 결정이다. 배치마다 임의로 바꾸지 않는다.
- 피해량은 전투판·공격 원본을 참조한다. 별도 체력·내구도·쿨타임·확률·스택 수는 필요하지 않아 추가하지 않는다.

| 정의 항목 | 의미·출처 |
|---|---|
| `environmentType` | 나무 박스 / 바위 |
| `collisionTriggerCondition` | 캐릭터가 일반·강제 이동 중 점유 셀에 접촉 |
| `collisionTargetRule` | 캐릭터 충돌 피해 대상과 환경요소 피해 여부. 전투판 4-3 참조 |
| `directHitRule` | 박스: 비관통 종료·관통 통과 가능. 바위: 관통도 종료 |
| `destructionTriggerCondition` | 나무 박스는 피해량과 관계없이 피격 시 파괴, 바위는 피해로 파괴되지 않음 |

```text
환경요소: 나무 박스
environmentType: 나무 박스
점유: 배치 셀 점유
대상 지정: 일반 공격·스킬의 대상 가능
효과 수용: 상태이상·강제 이동·회복 효과 없음
collisionTriggerCondition: 일반·강제 이동 중 캐릭터가 점유 셀에 접촉
collisionTargetRule: 접근 캐릭터와 나무 박스에 전투판 기준 충돌 피해
충돌 이동 결과: 캐릭터 이동 종료
directHitRule: 비관통 직사는 박스 파괴 후에도 종료, 관통은 통과 가능
destructionTriggerCondition: 피격 시 파괴, 피해량 0 포함
파괴 결과: 해당 요소 제거·점유 해제
```

```text
환경요소: 바위
environmentType: 바위
점유: 배치 셀 점유
대상 지정: 일반 공격·스킬의 대상 가능
효과 수용: 상태이상·강제 이동·회복 효과 없음
collisionTriggerCondition: 일반·강제 이동 중 캐릭터가 점유 셀에 접촉
collisionTargetRule: 접근 캐릭터에 전투판 기준 충돌 피해, 바위는 충돌 피해 제외
충돌 이동 결과: 캐릭터 이동 종료
directHitRule: 직사 공격 차단, 관통도 차단
destructionTriggerCondition: 피해로 파괴되지 않음
피격·충돌 후 결과: 존재·점유 유지
```

#### 레벨디자인 테이블의 배치 입력

| 필수 정보 | 의미 | 소유 |
|---|---|---|
| 적용 레벨·전투 | 어느 전투에 사용할 배치인지 구분. 실제 식별 체계는 작성 필요 | 레벨디자인 |
| `environmentType` | 배치할 나무 박스 또는 바위 정의 참조 | 레벨디자인 입력 → 환경요소 정의 참조 |
| `cellCoordinate` | 배치 셀. 양 축 0~5, 왼쪽 아래 원점 | 레벨디자인 입력 → 전투판 좌표 참조 |

- 배치 목록을 `environmentPlacement`로 참조한다. 한 배치 항목은 한 요소의 한 셀 배치를 뜻한다.
- 실제 개수와 좌표는 레벨디자인 테이블에서 제공한다. 예시 좌표를 임의로 정식 배치에 추가하지 않는다.

### 4-1-5. 처리 흐름·가상 전투 연결

| 단계 | 담당·처리 | 다음 결과 |
|---|---|---|
| 1. 시작 | 배치·정의가 사전 배치를 받아 전투판에 점유 요청 | 유효 배치면 존재 상태로 시작, 잘못된 배치만 제외하고 진행 |
| 2. 사건 구분 | 이동 접촉이면 충돌 연계, 공격 피격이면 피격·파괴로 연결 | 상태이상·강제 이동·회복 효과는 무효 |
| 3. 결과 판정 | 충돌은 캐릭터 정지·피해. 직사는 피격·차단. 박스의 피격은 파괴, 바위는 유지 | 파괴 또는 유지 |
| 4. 반영·종료 | 파괴 시 점유 해제, 유지 시 기존 점유 유지 | 이후 행동은 변경된 점유를 참조 |

- 사진 없이 처리 흐름을 번호 표로 제공한다. 분기 결과와 상세 규칙은 4-1-1~3과 대응한다.
- `[임시]전투 시뮬레이션`에서는 박스 파괴·점유 해제와 바위 충돌도 가상으로만 처리한다. 실제 박스·바위 상태, 점유, 사용자 계획은 변경하지 않는다. [전투 시스템](Waredo_2.0_전투_시스템_기획서.md) 4-1-9를 따른다.
- 시간대별 다른 환경요소 생성·교체·복원 규칙은 제공되지 않았으므로 추가하지 않는다.
