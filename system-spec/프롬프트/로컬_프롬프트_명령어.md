# 로컬 프롬프트 명령어

로컬 Codex에 설치하여 사용 중인 원본 프롬프트의 명령어다.

| 용도 | 명령어 | 프로젝트 보관본 |
|---|---|---|
| 작업 대화 분석·상태 기록·로컬 간 인수인계 | 프로젝트 `AGENTS.md`에서 자동 호출 | `ainus-handoff-recorder.md` |
| 시장·도메인·기술 조사 및 정규화 | `/prompts:ainus-analyst` | `ainus-analyst.md` |
| 구현 전 계약·아키텍처 준비도 검토 | `/prompts:ainus-architect` | `ainus-architect.md` |
| 게임 시스템·코어 루프·밸런스 설계 | `/prompts:ainus-game-designer` | `ainus-game-designer.md` |
| 플레이어 관점의 재미·밸런스·페이싱 QA | `/prompts:ainus-game-qa` | `ainus-game-qa.md` |
| GDD·기획 데이터 정적 품질 점검 | `/prompts:ainus-game-quality` | `ainus-game-quality.md` |
| Unity 주입 전 데이터·참조 준비도 검수 | `/prompts:ainus-injection-readiness` | `ainus-injection-readiness.md` |
| 서사·분기·세계관·캐릭터·대사 설계 | `/prompts:ainus-narrative-designer` | `ainus-narrative-designer.md` |
| 기획 단계 전체 오케스트레이션 | `/prompts:ainus-planner` | `ainus-planner.md` |
| 비개발자용 단계별 게임 기획 진행 | `/prompts:ainus-planning-lead` | `ainus-planning-lead.md` |
| 게임 레퍼런스·장르·시장 조사 | `/prompts:ainus-research` | `ainus-research.md` |
| 코드·기획서·문서 독립 검수 | `/prompts:ainus-reviewer` | `ainus-reviewer.md` |

## 사용 예시

```text
작업 시작
```

```text
작업 기록
```

```text
작업 마무리하고 GitHub에 올려
```

```text
/prompts:ainus-game-designer
시간대 전환 시스템의 코어 루프와 선택 구조를 검토하고 설계안을 제안해줘.
```

```text
/prompts:ainus-game-qa
시간대 전환 시스템을 플레이어 관점에서 시뮬레이션하고 지배 전략, 죽은 선택지, 페이싱 위험을 평가해줘.
```
