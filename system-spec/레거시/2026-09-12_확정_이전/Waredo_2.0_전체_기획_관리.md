# Waredo 2.0 전체 기획 관리

## 1. 관리 기준

| 상태 | 기준 |
|---|---|
| `[확정]` | `확정` 경로에 사용자 승인된 기준 문서가 존재함. 검수 상태와 개별 미정 항목은 해당 문서에서 별도로 확인함 |
| `[보류]` | 별도 문서는 존재하지만 현재 확정 기준과 구현 범위에서 제외되어 재검토 전까지 적용하지 않음 |
| `[제안]` | `제안` 경로에 초안·제안 문서가 존재하며 아직 확정되지 않음 |
| `[레거시]` | `레거시` 경로에 이전 문서만 존재하며 현재 기준으로 재검토가 필요함 |
| `[작성 전]` | 해당 시스템 또는 콘텐츠의 개별 기획 문서가 없음 |

관리 규칙:

1. 시스템 또는 콘텐츠 문서를 생성·이동·확정·폐기할 때 이 문서를 같은 작업에서 갱신한다.
2. 상위 항목의 상태는 하위 항목과 기준 문서의 실제 위치를 기준으로 판정한다.
3. 시스템 기획 중 새로운 콘텐츠 제작 대상이 확인되면 `3. 전체 콘텐츠 구조`에 자동으로 추가한다.
4. 콘텐츠 항목에는 실제 데이터·목록·수치·문법을 작성하는 문서만 등록한다. 시스템 처리 규칙은 콘텐츠로 중복 등록하지 않는다.
5. 기존 항목의 명칭·범위가 바뀌면 새 항목을 중복 추가하지 않고 기존 항목을 수정한다.

전투 관련 시스템 분리·통합 기준:

1. `전투 시작·선공 결정`, `행동 슬롯·행동 순서`, `설계·전투 단계`는 `전투 규칙`에서 함께 관리한다.
2. `행동 설계`와 `행동 실행`은 `행동`으로 통합하고, 행동 슬롯의 캐릭터 ID로 해당 캐릭터 플랜을 불러와 실행한다.
3. 일반 공격과 스킬의 정의·수치는 `캐릭터 시스템`이 소유하며, 전투 시스템은 계획 데이터에 따른 실행 시점의 유효성 판정과 결과 반영을 담당한다.
   - 일반 공격의 허용 지정 방식은 `Directional`, `SelfCentered`, `TileSelect`다. 스킬은 `SelfBuff`를 추가로 허용한다.
   - `TileSelect`는 절대 좌표가 아니라 시전자 기준 상대 방향·거리인 `relativeTargetOffset`을 저장한다.
   - 아군 캐릭터는 일반 스킬과 궁극기를 하나씩 보유하며, 현재 시간대와 `과거`·`미래` 태그가 일치하면 같은 스킬 슬롯이 궁극기로 교체된다. 교체 전후의 남은 쿨타임은 유지한다. 적 캐릭터는 프로토타입 기준으로 시간대 태그와 궁극기를 사용하지 않는다.
   - 시간대 태그 사이의 상성과 태그 기반 피해 배율은 사용하지 않는다.
   - 자가 버프 스킬의 `Counter` 효과 정의는 캐릭터 시스템이 소유하고, 반격 상태·범위 점유/행동 판정·대상별 발동 기록·일반 공격 피해 1건·기절/전투불능 행동 중단은 전투 시스템이 소유한다.
4. 별도의 `계획 검증·확정` 모듈과 확정 계획 사본은 사용하지 않는다. 설계 단계에서 슬롯과 캐릭터 플랜을 편집하고 전투 단계 전환 시 편집을 차단한다.
5. 이동 경로는 `전투 시스템`이 소유하고, 유효 셀·셀 점유·충돌 판정은 `전투판 시스템`이 소유한다.
6. `전투 시스템`, `전투판 시스템`, `상태이상 시스템`은 각각 독립된 확정 기획서에서 관리하고 상호 참조한다. 하나의 규칙을 둘 이상의 문서에서 원본처럼 중복 정의하지 않는다.
7. `전투 진입 및 종료 시스템`은 `[기존 유지]`로 관리하며, 변경하지 않는 기존 동작은 상세 기획 없이 해당 표기와 연계 관계만 남긴다.
8. `상태이상 시스템`은 `activeStatusEffects`와 띄워짐·기절의 수명 주기 및 밀쳐짐·당겨짐의 강제 이동 산출을 소유한다. 셀 진입·점유·충돌 결과는 `전투판 시스템`을 참조한다.
9. `전투 FSM 실행 설계`는 전투 시스템 기획서에서 분리해 `보류/시스템/Waredo_2.0_전투_FSM_기획서.md`에서 관리한다. 보류 해제 전까지 상태명·전이·효과 해결 큐를 확정 전투 규칙이나 구현 기준으로 적용하지 않는다.

10. 시간대 전환 시스템은 현재 시간대, 시간 파편의 기본 획득량·기본 최대 저장량 100·전환 비용 100, 비용 차감 후 잔여 파편 유지, 전환 입력, 체류 턴, 아군에게만 적용되는 시간대 공통 버프와 `timePeriodChanged` 이벤트를 소유한다. 적군은 시간대 공통 버프를 받지 않는다. 캐릭터 시스템은 캐릭터 시간대 태그·스킬 교체·공유 쿨타임을 소유한다. 가방·유물 시스템은 공용 가방, 가방 칸의 시간대, 유물 효과 활성 판정과 기존 시간 파편 획득 사건의 획득량·최대 저장량 보정을 소유하며, 유물 자체에는 시간대 또는 시간대 태그를 두지 않고 새 시간 파편 획득 사건도 만들지 않는다. 전투 시스템은 현재 시간대와 전환 결과만 참조하며 자체 시간대 선택·비용·버프 규칙을 만들지 않는다.
