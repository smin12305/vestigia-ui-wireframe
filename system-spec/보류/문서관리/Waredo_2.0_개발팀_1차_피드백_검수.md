## 1. 번호 대응과 판정 기준

원문의 세부 제목은 총 25개다. 사용자 답변 1~24는 등장 순서대로 대응한다. 24번은 환경요소의 잘못된 레벨 배치 안내이며, 마지막 문서 공통 정리는 25번으로 별도 관리한다. 사용자의 후속 ‘9번 문서 공통 정리’ 요청은 원문 9장을 뜻하며 검수표 25번에 반영했다. 원문 본문은 접수 이력으로 보존하고 현재 해결 내용은 이 문서와 연결된 시스템 원본에서 확인한다.

- 반영: 사용자 결정 또는 사용자가 해결을 맡긴 범위의 처리 결과를 시스템 본문에 반영했다. 처리 경위는 해결 내용·근거에 남기고 처리 상태는 동일하게 표시한다.
- 부분 반영: 해결된 부분은 적용했으나 별도 결정·선행 기획이 남았다.
- 보류·미응답: 현재 규칙을 임의 변경하지 않았다.
- 이 문서는 독립 검수 또는 개발 구현 PASS를 뜻하지 않는다.

## 3. 설명과 남은 결정

### 해결 완료 정리

- 9번 ‘강제 이동 정지 셀’: 마지막 진입 성공 셀에 정지하는 규칙으로 반영했다. 남은 항목에서 제외한다.
- 18번 ‘반복 중첩’: 규칙·최대중첩 문법 반영 완료. 개별 유물의 최대중첩 숫자는 콘텐츠 작성 시 채우는 값이며 공통 규칙의 미해결 사항이 아니다.
- 25번 ‘문서 공통 정리’: 기존 승인 상태와 현행 안내를 맞추고 과거 검토 이력을 분리했다. 남은 항목에서 제외한다.
- ‘9번 문서’는 별도 파일명이 아니라 [개발팀 피드백 원문 9장 — 문서 공통 정리](../../피드백/Waredo_2.0_개발팀_1차_피드백.md#9-문서-공통-정리)다. 검수표는 원문 세부 항목을 순서대로 세므로 25번으로 표시한다. 검수표 9번 ‘정지 셀’과 다른 항목이다.


### 6번이 의미하는 것

개발팀은 “이동력·일반 스킬/궁극기 참조·면역 목록을 예전에 제외하거나 다시 논의했는데 지금 왜 들어 있나”라는 이력 설명을 요구한다. 최신 구조를 없애 달라는 요청은 아니다.

현재 아이작 등 콘텐츠와 인수인계에는 사용자 이동력·스킬·면역 결정이 기록되어 있어 현행 구조를 유지할 근거는 있다. 예전 합의의 정확한 문서·날짜가 주어지지 않아 어느 결정을 번복한 것인지는 확인할 수 없다. 비교 대상이 확보되면 유지·추가·제외 내역만 추가한다. Google Sheets 실제 상태를 조회하거나 차이를 단정하지 않았다.

### 남은 항목

- 6: 비교 대상인 이전 합의의 출처 확인.
- 16: 추후 수정. 지연 전략의 플레이 테스트와 밸런싱은 후속 작업.
- 17: FSM 이후 Instant 적용·소비·종료 경계 확정.
- 24: 레벨 배치 문서 작성 후 오류 안내·명시적 우선순위 정의.

기존에 남아 있던 유물 최초 시간대 진입 트리거, 미작성 실제 콘텐츠, 개별 콘텐츠의 관통·연속 사격 세부 미정은 이번 피드백 처리만으로 자동 확정하지 않는다.

### 남은 항목의 해결안

현재 남은 6·16·17·24만 정리한다. 반영이 끝난 규칙은 2장의 처리 기록에서 확인한다.

| 번호 | 권장 해결안 | 구체적인 처리·완료 기준 |
|---|---|---|
| 6 | 현행 문서 기준으로 이력 요청을 정리 | 이동력·스킬 쌍·면역 목록은 최신 사용자 결정과 콘텐츠를 근거로 유지한다. 확인 가능한 Git·인수인계의 도입/변경 시점만 기록하고, 출처 없는 이전 합의는 ‘비교 근거 미확인’으로 남긴다. 과거 출처가 없어도 현행 구현 기준 확정에는 지장이 없으므로 기능 미해결과 분리한다. |
| 16 | 전투 지연 준비 전략 — 추후 수정 | 현행 수치·규칙 유지. 플레이 비교와 밸런싱은 추후 작업에서 진행 |
| 17 | Instant 적용·종료 — 부분 반영 | Instant 신규 작성·사용 허용. 수치 4종의 시간대유지는 권장일 뿐 강제가 아님. 적용계산·적용시점·종료시점을 문법에 작성하고 FSM 후 상세 확정 |
| 24 | 레벨 배치 문서에 안정적인 순서와 오류 목록 정의 | 새 문서에 레벨 ID·행 식별자·좌표·명시적 배치 순서를 넣는다. 캐릭터 배치 우선 후 환경요소를 배치 순서대로 검증하고, 이미 유효 점유된 셀의 후순위 행만 제외하는 안을 권장한다. 배치 순서 중복도 오류로 표시한다. 오류 목록에는 제외된 행·원인·충돌한 선행 행을 보여주고 보드에서 위치를 표시한다. 개발 실행은 기존대로 유효 행으로 진행하되 제작 완료 검증에서는 오류 0건을 요구한다. 실제 채택은 레벨 배치 문서 작성 시 결정한다. |

- 기존 누락 이미지 2건: 전투판 좌표 그림은 현행 6×6·좌표축 기준으로 복원하고, 대각선 충돌 그림은 현재 대각선 규칙이 취소선 상태이므로 현행 필수 자료에서 제외해 과거 자료 링크로 정리하는 안을 권장한다. 활성화되지 않은 대각선 기능을 새로 구현하지 않는다.
- 피드백 범위 밖의 기존 콘텐츠 미정: 유물 최초 진입 트리거와 개별 콘텐츠 미정은 각 원본의 후속 항목으로 계속 관리한다. 이번 해결안만으로 값을 채우지 않는다.
