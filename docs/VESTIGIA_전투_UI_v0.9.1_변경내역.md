# 전투 UI 명세서 v0.9.1 변경내역

사용자가 편집한 **v0.9.0 DOCX**를 원본으로 추가 와이어프레임과 **연출 타임라인 v1.2.2**를 반영했다. 기존 본문·표·이미지는 관련 항목만 수정하고, 새 화면 11개를 해당 절에 삽입했다. 설정창은 이번 대화 중 수정된 **적용·취소** 버전을 사용했다. 원본 v0.9.0과 Figma·타임라인은 수정하지 않았다.

페이지는 최종 v0.9.1 **Word 렌더 67쪽** 기준이다.

## 관찰과 기획 및 확인 사항

- **관찰 사실:** 자기버프 세 상태에 일부 연결이 있다. 팝업의 실제 버튼과 승리 결과 단계들은 조회 시 전환 연결이 없다. 정지 화면이 존재하는 것과 입력·전환 검증이 끝난 것을 구분했다.
- **사용자 확인:** 자기버프는 일반 공격의 새 유형이 아니라 자기버프 스킬과 반격 범위 표현이다. 설정창은 보류 후 수정되었으므로 최종 적용·취소 화면을 반영했다.
- **기존 기획 유지:** 유물 총 보유 한도 8개, 만석 보상 선택 불가, 상점 제거·가방 자체 버리기 불가, 스킬 실제 사용 성공 시 쿨타임 적용 등을 유지했다.
- **화면 보완:** 자기버프의 확정·철회가 공격 버튼 자리에 있으며, 아군 SKILL READY와 작은 스킬 정보 버튼은 새 화면에서 확인되지 않았다. B05의 기존 스킬 요구사항과 대조 대상으로 표시했다. 분홍 SKILL READY는 적 계획 표시다.
- **자료 간 차이:** TL-04-03은 캐릭터별 게이지 분할 수를 요구하지만 기존 B01-08은 3칸 유지 및 부분 채움 협의안이다. TL-08-01은 전투 UI 퇴장을 요구하지만 결과 화면에는 아군 순서 카드와 공통 메뉴가 남는다. 이번 작업에서 어느 쪽으로도 임의 변경하지 않았다.
- **UX·구현 제안:** 팝업 뒤 입력 차단, 보상 처리 중 선택·건너뛰기 중복 방지 등은 제안·협의로 표시했다.
- **미확인:** 결과 체력 확인에서 보상으로 넘어가는 입력·자동 전환, 보상 건너뛰기 목적지, 실패 화면, 도전 포기 후 목적지·정산, 설정 저장 세부 정책, 재생 중 팝업 호출·정지 범위.
