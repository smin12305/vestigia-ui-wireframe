# 전투 와이어프레임 수정 체크리스트 v0.8

이번 리뷰에 따른 변경분이다. 아래와 충돌하는 v0.7 항목은 이 문서를 우선한다. 기존 자기버프형·경고·설정·일시정지 등 후속 화면 목록은 v0.7을 유지한다.

## 명세서 반영 완료

- [x] B03-03 번호 연결선을 위쪽 도착 위치 미리보기 캐릭터로 수정.
- [x] 도착 미리보기의 스프라이트 100%와 진영색 마스크 60%를 구분. 미선택 75%는 두 레이어를 합친 묶음에 적용.
- [x] B04 BeforeSelection 최신 철회 비활성 이미지로 교체. 다른 공격·스킬 이미지는 사용자 요청에 따라 유지.
- [x] 경로선·발자국 자체를 드래그 시작점으로 보는 협의 문구 삭제.
- [x] 적 카드 개별 재생 가능 여부, 개별 재생 취소 방법, 다음 턴 배속 유지 여부를 미정 항목에서 제거.

## 이전 체크리스트의 교정

- ‘도착 미리보기 60%→45%’를 **스프라이트 100% + 마스크 60%, 합성 묶음 100%→75%**로 대체한다.
- ‘반대 행동 직접 전환’은 v0.7 규칙을 유지한다. 이번 리뷰는 해당 규칙을 변경하지 않는다.
- 철회 활성 조건은 저장된 같은 종류 계획의 유무에 따른다. 이번 B04 이미지는 저장 공격 계획이 없는 비활성 예시다.
