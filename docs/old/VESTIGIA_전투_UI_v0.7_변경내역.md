## 결정과 보완안을 구분한 부분

**확정 반영:** 공격↔스킬 지정 중 직접 전환 허용. 캐릭터 변경은 여전히 불가. 취소와 철회 구분, 같은 종류의 저장 계획이 없을 때 철회 비활성 규칙은 유지한다.

**전환 시 저장 처리 보완안:** 새 화면으로 전환할 때 확정 전 임시 방향·대상만 정리하고, 이동 계획과 기존 저장 주 행동은 유지한다. 전환한 행동을 새로 확정하면 기존 주 행동을 대체한다. 이는 이번에 허용된 전환 기능의 세부 처리안으로, 6쪽과 B04·B05 조작에 `[보완안·협의]`로 구분했다. 예를 들어 공격 계획을 저장한 뒤 스킬 지정으로 전환해도 스킬 확정 전까지 공격 계획은 남고, 스킬 철회는 비활성이다.
