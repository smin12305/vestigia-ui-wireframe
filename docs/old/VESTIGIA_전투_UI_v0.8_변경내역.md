# 전투 UI 명세서 v0.8 변경내역

사용자가 직접 수정한 **v0.7 DOCX**를 원본으로 편집했다. 이전 생성 스크립트로 문서 전체를 재작성하지 않았다. 이번 리뷰와 연결된 문단, B03·B04 선택 전 이미지, 버전 표기만 변경했다. 그 외 본문·표·서식과 다른 와프 이미지는 보존했다.

페이지는 v0.8 Word 렌더링 기준이다.

## 해석을 명확히 한 내용

- **60%와 75%:** 스프라이트 레이어 100% + 진영색 마스크 레이어 60%를 먼저 합성한다. 미선택 시 그 합성 묶음에 75%를 한 번 적용한다. 마스크만 45%로 바꾸거나 스프라이트 자체를 60%로 만드는 처리가 아니다.
- **체류 게이지:** 100→50→0은 화면 채움 비율이다. 전환 시 파편 100을 한 번 지불하는 기존 규칙을 유지하며, 매 턴 파편 50을 추가 차감하지 않는다. 체류 중 보존한 파편은 현재 복귀 후 다시 표시한다. 시스템 기획서의 남은 체류 턴 데이터와 턴 종료 시 감소 규칙에 연결했다.
- **개별 재생 판정 범위:** 이전 표현은 터치 영역이 아니라 시뮬레이션할 행동·효과의 범위를 뜻했지만 불명확했다. 해당 개체의 가상 이동·주 행동·피해 재생으로 구체화했다. 전체 미래 관측의 취소 버튼은 그대로이며, 개별 재생에만 취소가 없다.
- **철회 비활성 이미지:** 이번 이미지는 저장된 공격 계획이 없는 상태의 예시다. 기존 공통 규칙인 ‘같은 종류의 저장 계획이 있으면 철회 활성’은 유지했다. 방향 미선택 여부와 기존 계획 유무는 별개 조건이다.
