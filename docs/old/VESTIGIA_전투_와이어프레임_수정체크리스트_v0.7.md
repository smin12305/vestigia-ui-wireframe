# 전투 와이어프레임 수정 체크리스트

2026년 9월 29일 기준. UI 명세서 v0.7과 맞출 Figma 상태·연결 확인 목록이다. **B03·B04·B05 관련 원본과 연결을 읽기 전용으로 확인했다. Figma 자체는 수정하지 않았다.** 이미 표현된 항목은 재작업하지 않고 확인만 하면 된다.

## 이번 리뷰에서 추가로 점검할 사항

## 명세서 이미지 교체 대상

- 우선 교체: **B04 일반 공격 지정**, **B04 SelfCentered**, **B05 스킬 지정**, **B05 Info**. 저장 계획에 따른 철회 활성·비활성과 반대 행동 직접 전환 규칙을 반영한 이미지가 준비되면 교체한다.
- 이후 추가: B05-SelfBuff 지정/확정, B11, B12, B13, 타일선택형.
- B03 대표 이미지는 요청한 **아군 캐릭터 이동 조작 (2)**로 교체 완료. B04 4방향 선택 전 이미지도 추가 완료. 이 두 이미지를 위해 원본을 새로 만들 필요는 없다.

각 수정 완료 시 화면 ID와 변경한 상태를 알려주면 해당 부분의 스크린샷과 명세만 갱신할 수 있다.
