# 전투 UI 명세서 v0.6 변경 내역

2026년 9월 29일 리뷰 반영. 비교 기준은 v0.5이며, 아래 페이지는 v0.6의 인쇄 페이지 번호다. 이번에는 전투 명세서만 수정했다. 기획서 원본과 Figma는 수정하지 않았다.

## 질문에 대한 기획서 확인 결과

### 첫 턴 선공

현재 로컬 기획서에는 아군 선공 고정이 아니라 **첫 턴 각 50%, 이후 교대**로 적혀 있다.

- 근거: [전투 시스템 기획서](../system-spec/확정/시스템/Waredo_2.0_전투_시스템_기획서.md) **4-1-1-4 선공 규칙**. 같은 문서 4-1-2 처리표와 `firstActingFaction` 데이터 설명에도 동전 던지기가 남아 있다.
- UI 명세서는 이번 지시에 따라 **첫 턴 아군 선공**을 적용했다. 기획서의 위 항목들도 시스템 기획자가 함께 맞춰야 한다.
- 이번 변경은 첫 턴의 선공에 한정한다. 이후 턴 교대까지 폐지하는 것으로 확대 해석하지 않았다.
- 1·3·5 순번 예시는 양 진영 모두 행동 가능 캐릭터가 3명인 경우다. 인원이 다르면 기존 교차 배치·잔여 진영 연속 배치 규칙을 따른다.

### 자기버프형과 주변 범위

- [캐릭터 시스템 기획서](../system-spec/확정/시스템/Waredo_2.0_캐릭터_시스템_기획서.md) **4-1-6-3** 및 데이터 표: `SelfBuff`는 자기 자신을 확정하며 즉시 영향 셀 패턴은 범위 없음 ID 9다.
- [아르제나 콘텐츠](../system-spec/확정/콘텐츠/Waredo_2.0_아르제나_캐릭터_콘텐츠_테이블.md) **일반 스킬·각성·실행 유의사항**: `TARGETING SELF_BUFF`, `AFFECTED_CELL_PATTERN 9`이지만 `EFFECT COUNTER SELF RANGE_PATTERN 7`이다. 반격 발동 범위는 자기 중심 3×3이다.
- 따라서 **즉시 주변을 공격하지 않는다**와 **반격 범위가 없다**는 다른 말이다. 이전 문서는 이 구별을 누락했다. 반격 범위를 계획 화면에 어떤 색·선·명칭으로 보여줄지는 추가 결정이 필요하다.
- 참고로 [아이작 콘텐츠](../system-spec/확정/콘텐츠/Waredo_2.0_아이작_캐릭터_콘텐츠_테이블.md)의 주변 공격은 자기기준형 스킬이다. 사용자께서 떠올린 캐릭터가 어느 쪽인지는 단정하지 않았다.

## 검수와 사용 순서

1. 우선 3~4쪽, 6~7쪽, 10~14쪽, 16쪽, 18~19쪽을 확인하면 이번 B01까지의 리뷰 반영을 볼 수 있다.
2. 23~37쪽은 동일 규칙이 B03~B05에도 반영됐는지 확인할 때만 읽으면 된다.
3. Figma 작업은 별도 [와이어프레임 수정 체크리스트](VESTIGIA_전투_와이어프레임_수정체크리스트_v0.6.md)를 사용한다.

기존 스크린샷은 v0.5에서 확보한 화면을 유지했다. 이번에 확정된 철회 비활성·전환 차단은 본문에 먼저 반영했으며, Figma 수정본을 받으면 해당 이미지를 교체해야 한다.
