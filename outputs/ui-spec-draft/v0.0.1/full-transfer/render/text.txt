 1 문서 정보 
1.1 기획 의도 
전투 UI는 플레이어가 적의 행동 계획과 아군의 상태를 확인하고, 한 턴에 참여하는 아군 전체의 행동 순서와 
이동·공격·스킬을 설계할 수 있도록 한다. 현재 위치와 예정 이동 위치, 행동 범위와 실행 순서를 구분해 표시
하여 각 캐릭터의 계획을 함께 판단하고 조정할 수 있게 한다. 
시간대 전환은 행동 계획과 연결되는 전술적 선택으로 제시한다. 플레이어가 현재 시간대, 시간 파편과 전환 
가능 여부를 확인하고, 시간대에 따른 능력치와 활성 스킬의 변화를 읽으며 계획을 조정할 수 있도록 한다. 
선택·지정 중·확정 후에는 현재 조작 대상과 계획의 표시 변화를 명확히 전달한다. 확정 후에도 다음 조작과 
취소·철회 가능 여부를 이해할 수 있도록 하며, 적 행동 예고·미래 관측·실제 턴 실행은 표시와 입력 조건을 구
분해 현재 진행 상황을 알 수 있게 한다. 
1.2 적용 범위 
본 문서는 전투 전 캐릭터 배치를 확정한 뒤 전투에 진입하는 시점부터 전투 결과와 보상 선택까지의 UI를 다
룬다. 각 화면의 구성 요소, 표시 데이터, 화면과 UI 요소의 상태, 플레이어 입력과 연결 화면을 정의한다. 
주요 적용 범위는 다음과 같다. 
 전투 진입과 적 행동 예고 
 턴 설계, 행동 순서 편집과 캐릭터 정보 열람 
 이동·일반 공격·스킬의 지정과 확정 후 표시 
 시간대 선택과 전환, 미래 관측과 개별 미리보기 
 실제 턴 실행, 전투 결과와 유물 보상 선택 
 계획 미입력 경고, 설정과 도전 포기 확인 
전투 전 캐릭터 배치 화면은 캐릭터 배치 명세서(P)를 참조한다. 전투 보상으로 획득한 유물의 배치는 가방 UI 
명세서의 I04에서 정의한다. 
게임 규칙과 콘텐츠 정보는 관련 시스템 기획서와 콘텐츠 테이블을 참조한다. 본 문서에서는 해당 규칙과 정
보를 화면에 어떻게 표시하고, 어떤 입력과 전환으로 연결하는지 정의한다.

2.2.1 전투 진입 
전투 배치 화면에서 배치를 확정하면 B00으로 진입한다. 전장과 전투 UI 표시가 완료되면 B09에서 첫 턴의 
적 행동을 예고한다. 예고 종료와 원위치 복귀 후 B01에서 계획 입력을 시작한다. 
전투 배치 확정 → B00 전투 진입 → B09 적 행동 예고 → B01 턴 설계 
 
2.2.2 턴 설계 
B01에서 아군의 행동 순서를 편집하고, 캐릭터 선택 후 B03에서 이동 계획을 작성한다. B04·B05에서는 일반 
공격이나 스킬을 지정한다. 확정 후에는 저장된 계획을 표시하며 편집을 이어간다. 
계획 중에는 B02의 캐릭터 정보, B07의 시간대 전환, B08의 관측·미리보기로 연결할 수 있다. 각 화면에서 돌
아올 때 유지할 선택과 계획, 갱신할 표시는 해당 화면의 명세를 따른다. 
 
2.2.3 작전 개시와 턴 실행 
작전 개시를 선택하면 현재 계획으로 B06으로 진입하여 턴 실행을 시작한다. 이동 계획과 주 행동 계획이 모
두 없는 아군이 있으면 B11에서 진행 여부를 먼저 확인한다. 
 실행 조건 충족: B01 → B06 
 계획 미입력 아군 존재: B01 → B11 
 B11에서 계속 진행: B11 → B06 
 B11에서 돌아가기: B11 → B01 
B11에서 돌아가면 기존 계획을 유지하며 턴을 진행하지 않는다. 계속 진행하면 계획이 없는 아군은 이동·주 
행동 없이 자기 순서를 넘긴다. 
 
2.2.4 다음 턴 
B06에서 현재 턴의 행동 처리가 끝나고 전투가 계속되면, 다음 턴의 B09 적 행동 예고를 거쳐 B01 턴 설계
로 돌아간다. 
B06 턴 실행 → B09 적 행동 예고 → B01 턴 설계 
 
2.2.5 전투 결과와 보상 
전투가 종료되면 승리·실패에 따른 결과 화면으로 전환한다.

명세서의 I04 획득 유물 배치로 전달한다. 보상 건너뛰기를 선택하면 타일 선택 화면(ID:  )으로 이동한다. 
실패 시 B10에서 전투 실패 결과 화면을 표시한다. 해당 화면을 수 초 동안 표시한 뒤 도전 결과 화면의 실패 
결과(ID:  )로 자동 전환한다. 2.2.6 설정과 도전 포기 확인

2.4 주 행동 계획 플로우차트 
아군의 B04 일반 공격 또는 B05 스킬을 선택하고, 행동 지정 유형에 따라 범위·방향을 지정한 뒤 주 행동 계
획을 확정하는 흐름을 나타낸다. 주 행동은 일반 공격 또는 스킬을 의미하며, 이동은 포함하지 않는다. B03 이
동 계획은 생략할 수 있지만, 이동·주 행동이 모두 없는 아군이 남으면 작전 개시 시 B11에서 한 번 더 묻는
다. (2.3 플로우차트 참조) 
지정 중 취소·철회, 공격·스킬 간 전환과 계획 유지 규칙은 2.5를 참조한다. 각 행동의 지정 방식과 상태별 표
시 변화는 B04·B05의 화면별 명세에서 정의한다. 
도형과 연결선의 의미는 2.3의 범례를 따른다. 
 
 
2.5 주 행동 지정 규칙 참조 
일반 공격·스킬 지정에 공통으로 적용하는 입력 규칙은 B04 일반 공격 지정의 3.5.6에서 정의한다. B05 스킬 
지정에도 해당 규칙을 적용한다. 
3 화면별 명세 
각 화면은 화면 개요와 이미지, 구성 및 표시 정의, 데이터 정의, 화면과 UI 요소의 상태, 입력 및 동작 정의 
순서로 작성한다. 같은 화면 ID의 지정 전·지정 중·확정 후 표현은 상태로 구분한다. 요소 번호는 v0.9.1의 화면 
이미지와 동일하게 유지한다. 
표시 데이터는 고정 문구, 콘텐츠 정보, 게임 상태로 구분한다. 임시 방향·대상, 현재 선택과 재생 진행 여부는 
데이터 원본과 구분하여 상태·입력 항목에 정의한다. 같은 개체의 정보를 함께 갱신하고, 화면 전환에서 유지·
해제하는 선택과 계획을 명시한다. 
참조 자료의 기준 버전은 1.3을 따른다. 영문 데이터명은 관련 시스템 기획서의 명칭이며, 필드·리소스 연결이 
정해지지 않은 값은 임의의 영문 필드명을 만들지 않는다. 임시 표시 규격과 미확정 보완안은 확정된 게임 규
칙과 구분한다. 
3.1 B00 전투 진입 
3.1.1 화면 개요 
전투 배치 화면에서 확정한 배치를 전장에 반영하고 전투 시작 연출과 전투 UI를 표시한다. 실제 배치와 진입
